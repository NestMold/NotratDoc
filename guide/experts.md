# 专家（智能体）

跟 AI 聊久了你会发现一件事：每次都要重新交代一遍背景。

专家就是解决这个的：把「你是谁、擅长什么、按什么流程干活、能用哪些工具」打包成一个角色，下次直接叫它。

设置 → 扩展管理 → **专家（智能体）**。

![专家管理](/shots/guide/settings-agents.png)

::: tip 术语
本文里的「专家」就是「智能体」（Expert / Agent），同一个东西。

老文档里出现过「专家包」这个词，已经退休了，现在统一叫「专家」。
:::

## 从哪来

专家页顶部是两个视图：**内置专家** / **我的专家**。

| 来源 | 说明 | 能改吗 |
| --- | --- | --- |
| **内置** | 官方给的三位：**规划者**、**研究者**、**总结者**（多步任务里各管一段） | 能改配置，但不能删 |
| **自建** | 你自己创建的 | 全都能改能删 |
| **来自专家市场** | 从扩展市场装的 | 能改配置；卸载走卸载流程 |

自建与市场装的都归在「我的专家」里，同列一池；来源靠卡片上的头像底色与描边区分。

## 一个专家由什么组成

| 部分 | 作用 |
| --- | --- |
| **名称与描述** | 列表里显示什么、你按什么找它 |
| **角色定义（系统提示词）** | 它是谁、按什么风格与原则做事。运行时追加到该专家的系统提示词上 |
| **技能 / 连接器（MCP）** | 它能调用哪些能力（在工作区里读写文件、跑命令、连外部服务…） |
| **高级设置** | 提示词编排等更细的控制 |

::: tip 新手只改前两格就够
**名称 / 描述 / 角色定义**是三个最该动的字段，都摆在折叠线以上。

只写角色定义就是一个能用的专家，够解决「每次重复交代背景」这件事了。
:::

## 建一个自己的专家

在专家页点新建，填这几样：

1. **名称**：比如「技术文档审稿」
2. **描述**：一句话说清它干什么（你自己看的，列表里显示）
3. **角色定义**：系统提示词，写清它的身份与做事原则
4. **勾选技能 / 连接器**：它需要用到哪些能力

保存后就能在对话里叫它了。

![新建专家](/shots/guide/agents-new.png)

::: tip 角色定义怎么写
几条经验：

- **写身份，不写任务**。「你是一位有十年经验的技术编辑」比「帮我改文档」管用
- **写判断标准**。「术语不一致要指出，但不要改我的行文节奏」，这类约束最有价值
- **别写太长**。角色定义每次都进上下文，写 3000 字它反而记不住重点
:::

## 在对话里用专家

两种方式：

| 方式 | 范围 |
| --- | --- |
| 对话输入框旁的 **Agent 选择器** | 整段会话都由这个专家来做 |
| 输入 `@` → **专家（智能体）**页签 | 这一条消息指定（发送后清空） |

详见 [AI 对话](/guide/chat)。

## 专家的工具与技能

一个专家能用什么，取决于你给它勾了哪些：

- **技能**：固定的做事方法（[技能](/guide/skills)）
- **连接器（MCP）**：外部工具（[连接器（MCP）](/guide/mcp)）

::: warning 能力给多了反而不好
每多给一个工具，模型就多一份「要不要用它」的判断负担。专家跑偏，多半是给的选择太多，不是能力不够。

按专家的实际职责给，别一次全勾上。
:::

## 停用与卸载

| 对象 | 怎么做 |
| --- | --- |
| **停用** | 列表里的开关关掉，它不再出现在选择器里，配置保留 |
| **删除自建专家** | 直接删 |
| **删除内置专家** | 内置的删不掉，但可以停用 |
| **卸载从市场装的专家** | 走「高级设置」里的**卸载专家** |

::: tip 「卸载专家」会连技能一起拿走
从市场装的专家，除了角色本身，可能还**带了一批技能**。

普通删除只拿掉专家这一项；要把随它安装的技能也一并清掉，用**卸载专家**，按钮旁边的提示会写明会删掉哪些技能。

自建专家没有这个按钮（它本来也没有附带技能）。
:::

## 专家显示与缓存

专家列表有一层**显示注册表**：名称、图标、启用状态会缓存起来，避免每次打开设置都重新算一遍。

::: tip 列表看着不对时
理论上它会自愈，发现缓存与实际情况不一致会自动刷新。

如果你刚装/刚删了专家而列表没跟上，关掉设置再打开一次即可。
:::

::: warning 一个容易踩的点
「启用」的缺省语义是「启用」。

专家的配置里如果没有 `enabled` 这个字段，它就被当作**启用**，而不是没启用。

所以别靠「字段不存在」来判断一个专家被关掉了。看界面上的开关。
:::
