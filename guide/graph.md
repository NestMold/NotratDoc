# 图谱

活动栏的**「图谱」**把你工作空间里的文档画成一张关系图，谁引用了谁，一眼看清。

![图谱](/shots/guide/graph.png)

## 图里有什么

| 元素 | 含义 |
| --- | --- |
| **节点** | 一个文档；打开「块级」后还能展开出文档里的块 |
| **连线** | 两个文档之间有引用关系（比如 A 里写了指向 B 的链接） |
| **标签** | 文件名（不含 `.md`）；块级模式下块名是第二级小字 |

鼠标悬停在节点上会浮出提示：文档节点显示名称、连接数和路径，块节点显示块名和所属文件。

## 左栏：图谱导航

左边一栏不再只是图例，搜索、列表、统计都收在这里：

| 部分 | 作用 |
| --- | --- |
| **表头** | 当前画布有多少节点、多少条链接 |
| **工作空间** | 显示当前空间名字与根的个数；根超过一个时可切换 |
| **搜索** | 输入即筛；命中列表就排在输入框下方，点一条直接跳过去 |
| **列表** | 不搜索时列「连接最多」的前 12 个文档、行尾是连接数，点一行把它挪到画面中央 |
| **图例 / 提示** | 颜色的含义、块级下的文件配色，以及「悬停聚焦 · 拖拽平移 · 滚轮缩放」的提示 |

### 按工作空间翻看

左栏「工作空间」那一行的名字，在有多个已保存空间时**本身就是下拉**：第一行是当前打开的工作空间，下面是其它已保存的空间。选别的空间是**只读预览**——不改当前打开的工作区、不动会话归属，画布右上角会挂一枚「预览」标记；选回第一行即恢复。这个选择只在本窗口有效，重启后回到当前工作空间。

### 只看向一个工作区

窗口里有两个以上根时，下面会多一行「**范围**」下拉：可以选「全部」或某一个根，行尾写着那个根里有多少节点。收窄只影响画布和列表看到的那一份，**不改索引**；选了不存在的根会自动回到「全部」。

## 怎么用

| 想干什么 | 怎么做 |
| --- | --- |
| 看某个文档被谁引用了 | 在图里找到它，看有哪些线连进来 |
| 跳到文档 | 点节点 |
| 放大看局部 | 滚轮缩放；右下角还有 + / − / 全图适配一组按钮 |
| 平移 | 拖空白处 |
| 换个排法 | 顶部「布局」下拉：力导向 / 环形 / 网格 / 径向 / 层次 / 树状 / 拓扑 |
| 藏掉孤岛 | 右下角的**眼睛**按钮，隐藏没有任何链接的节点 |
| 让 AI 讲这张图 | 右上角「**解释图谱**」→ 全量解析，或进「选择」勾几个节点后解析选中子图 |

::: tip 图谱最实用的场景
找孤儿文档和枢纽文档。

- 一个节点没有任何连线 → 这篇孤立了，可能忘了挂到任何地方
- 一个节点连进来很多线 → 这是你的核心索引页

写了一阵之后用图谱扫一眼，比在文件树里翻快得多。
:::

## 块级：看到文档内部

顶部是「**文档 / 块级**」两档。切到「块级」后，文档里的每个标题节都变成一个挂在文件下面的**块**节点，能看到「哪一段引用了哪一段」。

块级里还有两种范围：

| 范围 | 行为 |
| --- | --- |
| **全量**（默认） | 整个工作空间（含每一个根）的块一起摊开；文件太多时会截断，并提示切到「邻域」 |
| **邻域** | 只摊当前文件附近；点文档节点逐个展开，另配「展开邻域 / 收起」两个按钮 |

- 块级模式强制用力导向布局（其它布局不知道块节点该放哪），所以布局下拉在块级下不显示
- 顶部胶囊写着「块级 · 全量 N 文件 / M 块」或「块级 · 力导向 N/上限」，摊到了什么程度一眼可见
- 块级模式下不隐藏孤立节点——块节点天然连接少

## 标签为什么不糊

图谱里的节点大小、箭头粗细、标签字号都是**屏幕恒定**的，不会因为你放大图而跟着变大。

::: tip 屏幕上恒定是什么意思
Notrat 的图谱按屏幕像素而不是图坐标来画这些元素。

如果不这么做：缩小到能看全图时（比如 8.5 倍缩小），按图坐标画的节点会挤成一个黑饼，标签完全糊在一起没法看。
:::

标签的排版规则（1.3.6 起）：

- **两级字号**：文件名 **12px**（有链接 / 选中 / 命中时加粗），块名 **11px** 常规字重
- **块名只在放大到 1× 以上才出现**；缩小看块级时每组只留文件名这一个主角
- **文字绝不盖节点**：所有节点先占位，标签只在空处落，密集处也不会把邻座的圆点压住
- **孤立文件的标签淡一档**，但仍然读得出文件名
- **当前文件的标签**与普通节点分开着色，一眼能找到「我现在写的这篇」

画布右上角的「选择」模式开启后，点节点不再打开文件，而是勾选；选中子图可以直接交给 AI 解释（「解释图谱 → 解析选中节点」），并在对话里继续追问。
