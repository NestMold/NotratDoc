# 图谱

活动栏的**「图谱」**把工作区里的文档画成一张关系图——谁引用了谁，一眼看清。

![图谱](/shots/guide/graph.png)

## 图里有什么

| 元素 | 含义 |
| --- | --- |
| **节点** | 一个文档 |
| **连线** | 两个文档之间有引用关系（比如 A 里写了指向 B 的链接） |
| **标签** | 文档标题 |

鼠标悬停在节点上会浮出提示，显示这个文档的名称与连接情况。

## 怎么用

| 想干什么 | 怎么做 |
| --- | --- |
| 看某个文档被谁引用了 | 在图里找到它，看有哪些线连进来 |
| 跳到文档 | 点节点 |
| 放大看局部 | 滚轮缩放 |
| 平移 | 拖空白处 |

::: tip 图谱最实用的场景
**找孤儿文档和枢纽文档。**

- 一个节点**没有任何连线** → 这篇孤立了，可能忘了挂到任何地方
- 一个节点**连进来很多线** → 这是你的核心索引页

写了一阵之后用图谱扫一眼，比在文件树里翻快得多。
:::

## 它怎么知道谁引用谁

靠文档里的**链接**。所以：

- 用相对路径链接另一个 `.md` → 图谱里就有线
- 只是文字里提到了名字（没做成链接）→ **没有线**

想让图谱好看，写文档时多做链接。

## 一个技术细节（图为什么不会糊成一团）

图谱里的**节点大小、箭头粗细、标签字号**都是**屏幕恒定**的——不会因为你放大图而跟着变大。

::: tip 屏幕上恒定是什么意思
Notrat 的图谱按屏幕像素而不是图坐标来画这些元素。

如果不这么做：缩小到能看全图时（比如 8.5 倍缩小），按图坐标画的节点会挤成一个黑饼，标签完全糊在一起没法看。
:::

标签是**常显**的（不是悬停才出现），所以你可以直接对着图读。
