# 主题与外观

设置 → 外观。这一页干三件事：**换主题**、**调内容宽度**、**调对话字体**。

![外观设置](/shots/guide/settings-appearance.png)

## 五套主题

在「主题」段里选：

| 主题 | 气质 |
| --- | --- |
| **极简** | 黑白灰，最安静的一套。长时间写作不累眼 |
| **日落橙** | 暖橙调，页面偏暖 |
| **紫罗兰** | 紫色系 |
| **靛蓝** | 蓝调（界面上它的主题 id 仍叫 `midnight`，但显示名是「靛蓝」） |
| **樱花粉** | 粉色系 |
| **自定义** | 打开调色板，自己配色 |

选中哪套，整个应用立刻变，编辑器、文件树、对话框、设置页、插件面板全都跟着走。

::: tip 切换是一次转场，不是硬切
1.3.5 起，换主题 / 切深浅时整页做一次约 220ms 的**颜色转场**（颜色、边框、阴影平滑过渡），不再是「顿一下、啪地跳过去」；切换过程里编辑器内容与光标保持原样，图表在转场结束后再重画。
:::

![主题选择](/shots/guide/settings-theme-picker.png)

## 深浅色

每套主题都有**浅色 / 深色**两个档。

- **暗色模式**开关在主题卡片同一段里，打开后为全部主题统一开启深色外观
- 深色是叠加在各主题之上的一个模式，不属于某一套主题

::: tip 深色档不是简单反色
每套主题的深色档单独调过，不是把浅色档的颜色取反。同一个色相在深底上要重新校对比度，尤其是：

- **Logo**：深色底上会自动反白（深蓝描线的 logo 在暗底上原本几乎看不见）
- **代码块**：深色档有专门的底色与语法高亮配色
:::

## 窗口缩放跟着屏幕走

第一次打开 Notrat 时，界面缩放不是固定值，而是**按窗口所在屏幕的宽度算**：目标是把界面版心落在约 1600 CSS 像素上，按 5% 取整，夹在 **85%–125%** 之间。

| 屏幕（工作区宽） | 落点 |
| --- | --- |
| ≥ 2000 | 125%（上限） |
| 1920 | 120% |
| 1600 | 100% |
| 1366 | 85%（下限） |

所以小屏笔记本不会出现「字大得挤成一团」，大屏也不会字小得费眼。

- 手动调过缩放（`Ctrl+=` / `Ctrl+-`）后，这个比例**只对当前这块屏**有效；窗口拖到另一块屏，会按那块屏重新自适应
- `Ctrl+0` 交回本屏的默认档，之后换屏继续跟着走
- 正文字号的单独缩放（光标在编辑器里时）见 [编辑器 → 缩放正文](/guide/editor#缩放正文)

## 内容宽度

「布局」段里的**内容宽度**控制正文最大显示宽度：

| 选项 | 效果 |
| --- | --- |
| 若干固定值（如 1024 px） | 内容居中，两侧留白 |
| **全宽** | 内容撑满编辑器 |

宽屏显示器上，固定宽度更好读（一行太长眼睛不容易换行）；但你要并排看表格、看宽代码块，全宽更实用。

::: tip 内容宽度是「上限」语义
它是**最多显示多宽**，不是「固定多宽」。窗口比这个值窄时，正文自动跟着窄，不会出现横向滚动条。
:::

## 对话字体

同一页的「对话字体」段管的是**聊天正文**的字号与字体（界面其它文字不跟着变）：

| 项 | 范围 |
| --- | --- |
| **正文字号** | 12 – 22 px，默认 **12**（与旧版本逐像素一致） |
| **字体** | 与编辑器同一份清单：默认档「跟随界面」，也可一键加载本机系统字体 |

两行各带一行**实时字样预览**，盖着设置页就能当场对比。全屏 AI 的对话正文比工作台大一档，气泡与代码块按固定偏移等比缩放；标签类的小字（胶囊、时间戳）**不跟着放大**，保持一屏的密度。

界面字号、编辑器字号、对话字号是**三套**：编辑器字号在 设置 → 编辑器 里调，界面字号见下面的「排版刻度」。

## 关于「强调色」

如果你在老版本或老教程里见过一个「强调色」取色器，它已经被下架了。

原因是那个取色器改的是一组没人读的变量，调了也没有任何地方跟着变。

现在想要自己配色，走**「自定义」主题**的调色板。

## 主题的一致性

**大面积填充一律跟随主题**：

- 卡片、面板、选中态的底色 → 跟随主题
- 语义色（成功绿、警告黄、危险红）→ 只用在**小范围的标记**上，不刷大面积背景

所以你把主题从「极简」换到「樱花粉」，界面上不会突然出现一整块突兀的绿色，因为绿色原本就只出现在一个小圆点上。

::: tip 这条规则也管插件
插件面板用的颜色 token 与主界面是同一套。跟着主题走，不会出现「主界面是深色、插件面板是纯白」这种割裂。
:::

## 悬浮器的主题

桌面悬浮球、悬浮便签这些**独立窗口**也会跟随主题。

它们在别的应用上面飘着，所以颜色是从主窗口同步过去的，换主题它们跟着变。

## 排版刻度

Notrat 的排版有一套自己的字号刻度（按 14 px 正文设计的 Ant Design 口径），和 Tailwind 默认的 16 px 基准不是一套。同名档位（如 `text-sm`）在 Notrat 里是 12 px，Tailwind 默认是 14 px：

| 用途 | 字号 |
| --- | --- |
| 正文 | 14 px |
| 说明文字 | 12 px |
| 文档标题 | 18 / 16 / 14 px（按层级） |
| 对话气泡 | 15 px |
| 状态栏与角标 | 10–11 px（辅助信息，刻意压小） |

正文与说明类文字的刻度到 12 px；状态栏、角标这类辅助信息另有 10–11 px 的档位。

编辑器的字号与行高在 **设置 → 编辑器** 里单独调（和界面字号是两回事：界面字号管 UI 控件，编辑器字号管你写的正文）；对话正文字号在 **设置 → 外观 → 对话字体** 里单独调。
