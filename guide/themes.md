# 主题与外观

设置 → 外观。这一页只干两件事：**换主题**、**调内容宽度**。

![外观设置](/shots/guide/settings-appearance.png)

## 五套主题

在「主题」段里选：

| 主题 | 气质 |
| --- | --- |
| **极简** | 黑白灰，最安静的一套。长时间写作不累眼 |
| **日落橙** | 暖橙调，页面偏暖 |
| **紫罗兰** | 紫色系 |
| **靛蓝** | 蓝调（界面上它的主题 id 仍叫 `midnight`，但显示名是「靛蓝」） |
| **樱花粉** | 粉色系 |
| **自定义** | 打开调色板，自己配色 |

选中哪套，整个应用立刻变——编辑器、文件树、对话框、设置页、插件面板，全都跟着走。

![主题选择](/shots/guide/settings-theme-picker.png)

## 深浅色

每套主题都有**浅色 / 深色**两个档。

- **暗色模式**开关在主题卡片同一段里，打开后**为全部主题统一开启深色外观**
- 也就是说：深色不是某一套主题的属性，而是一个叠加在各主题之上的模式

::: tip 深色档不是简单反色
每套主题的深色档单独调过——不是把浅色档的颜色取反。同一个色相在深底上要重新校对比度，尤其是：

- **Logo**：深色底上会自动反白（深蓝描线的 logo 在暗底上原本几乎看不见）
- **代码块**：深色档有专门的底色与语法高亮配色
:::

## 内容宽度

「布局」段里的**内容宽度**控制正文最大显示宽度：

| 选项 | 效果 |
| --- | --- |
| 若干固定值（如 1024 px） | 内容居中，两侧留白 |
| **全宽** | 内容撑满编辑器 |

宽屏显示器上，固定宽度更好读（一行太长眼睛不容易换行）；但你要并排看表格、看宽代码块，全宽更实用。

::: tip 内容宽度是「上限」语义
它是**最多显示多宽**，不是「固定多宽」。窗口比这个值窄时，正文自动跟着窄，不会出现横向滚动条。
:::

## 关于「强调色」

如果你在老版本或老教程里见过一个「强调色」取色器——**它已经被下架了**。

原因是那个控件控制了全局都没有消费者的变量，是一块**空转的 UI**：改了没有任何效果。

现在想要自己配色，走**「自定义」主题**的调色板。

## 主题的一致性

有一件事 Notrat 做得比较细：**大面积填充一律跟随主题**。

意思是：

- 卡片、面板、选中态的底色 → 跟随主题
- 语义色（成功绿、警告黄、危险红）→ 只用在**小范围的标记**上，不刷大面积背景

所以你把主题从「极简」换到「樱花粉」，界面上不会突然出现一整块突兀的绿色——因为绿色原本就只出现在一个小圆点上。

::: tip 这条规则也管插件
插件面板用的颜色 token 与主界面是同一套。跟着主题走，不会出现「主界面是深色、插件面板是纯白」这种割裂。
:::

## 悬浮器的主题

桌面悬浮球、悬浮便签这些**独立窗口**也会跟随主题。

它们在别的应用上面飘着，所以颜色是从主窗口同步过去的——换主题，它们跟着变。

## 排版刻度

Notrat 的排版有一套自己的字号刻度（按 14 px 正文设计的 Ant Design 口径），和 Tailwind 默认的 16 px 基准不是一套——同名档位（如 `text-sm`）在 Notrat 里是 12 px，Tailwind 默认是 14 px：

| 用途 | 字号 |
| --- | --- |
| 正文 | 14 px |
| 说明文字 | 12 px |
| 文档标题 | 18 / 16 / 14 px（按层级） |
| 对话气泡 | 15 px |
| 状态栏与角标 | 10–11 px（辅助信息，刻意压小） |

正文与说明类文字的刻度到 12 px；状态栏、角标这类辅助信息另有 10–11 px 的档位。

编辑器的字号与行高在 **设置 → 编辑器** 里单独调（和界面字号是两回事：界面字号管 UI 控件，编辑器字号管你写的正文）。
