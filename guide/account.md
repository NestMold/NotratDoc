# 账号、版本与数据

## 三个档位

| 档位 | 界面上的名字 | 大致能力 |
| --- | --- | --- |
| 免费 | **纯净版** | 完整的 Markdown 编辑器、文件管理、扩展管理（插件全开放）、开发者选项 |
| 基础版 | 基础版 | 加上 AI（AI 补全、对话、专家）、知识库、提示词、技能、连接器（MCP）、用量统计 |
| 专业版 | 专业版 | 加上远程助手、A2A 服务、HTTP API Bridge |

::: tip 不登录就是纯净版
**没有账号也能完整地写作。** 纯净版不是「功能残缺的试用版」——它是一个能长期用的 Markdown 编辑器。

登录的意义在于 AI 相关能力与更宽的扩展可见范围。
:::

## 登录

未登录时，这些地方都能进登录页：

- 左侧活动栏底部的**登录**（登录后这个位置变成你的头像）
- 任一被锁功能页上的**「登录 / 注册」**按钮（比如 设置 → AI、扩展管理）
- 扩展市场里的升级提示
- 首次启动的引导页主按钮

![登录页](/shots/guide/login.png)

登录页提供三种方式：

| 方式 | 怎么用 |
| --- | --- |
| **密码登录**（默认） | 账号（邮箱或手机号）+ 密码 |
| **验证码登录** | 同一栏切到「验证码登录」，向邮箱或手机号发验证码 |
| **第三方** | Google / GitHub / QQ / 微信，在**应用内弹出的授权小窗**里完成，不跳系统浏览器 |

账号体系由 **Nestmold 用户中心**统一管理，密码提交到用户中心校验，**Notrat 本地不保存你的密码**；登录态换回的是 token（存进系统加密存储），所以下次打开应用不用重新登录。

::: tip 免费套餐
登录后点活动栏底部的**头像**进入**个人中心**，在**「活动与体验」**里点「🎁 立即免费领取」，可以开通免费试用，解锁 AI 补全与对话。

试用有期限，到期后 AI 能力会关闭，但**写作功能一切照旧**。
:::

## 登录后的界面变化

| 位置 | 变化 |
| --- | --- |
| 活动栏底部 | 「登录」文字变成**你的头像** |
| 设置左栏 | AI、知识库、提示词、用量统计、远程助手等分类上的**锁消失**（按你的档位解锁） |
| 用户头像菜单 | 个人中心（账务、订阅、活动与体验、设备管理）入口 |

::: tip 档位是主进程签名下发、渲染层改不了
界面上显示的档位来自**主进程签名过的数据**，不是浏览器里可以随便改的变量。

所以「在开发者工具里改一个值解锁会员功能」是不成立的。
:::

## 管理订阅与设备

点活动栏底部的**头像** → 菜单里的入口（或直接去官网 `notrat.cn/dashboard`）：

| 页面 | 干什么 |
| --- | --- |
| **订阅** | 看当前档位、续费、升级 |
| **设备** | 看这个账号在哪些设备上登录过，踢掉不认识的 |
| **订单 / 发票** | 购买记录与开票 |
| **激活码** | 兑换授权商给你的激活码 |

::: warning 授权商与激活码
从授权商那里购买的授权是**激活码**形式。兑换入口在用户中心的「激活码」，不在应用内。

兑换时**订阅时长会正确落库**（1.3.5 修过一处时长不生效的缺陷）。详见 [授权商与激活码](/platform/reseller)。
:::

## 版本

当前版本号在**状态栏最右边**：

![状态栏版本](/shots/guide/statusbar.png)

写着 `v1.3.5 (纯净版)` 这样的形式——版本号 + 你当前的档位。

| 想知道 | 去哪 |
| --- | --- |
| 我是什么版本 | 看状态栏右下角 |
| 这版改了什么 | [版本更新记录](/changelog/) |
| 怎么更新 | 设置 → 通用里的更新区块（[详见](/guide/install)） |

::: tip 强制更新
极少数版本会被标记为**必须更新**——通常是安全修复或后端协议不兼容。

这种情况下应用会拦在使用前，要求先升级。不是坏了，是必须走这一步。
:::

## 你的数据

这是最需要说清的一件事：

| 数据 | 在哪 | 会不会上传 |
| --- | --- | --- |
| **你的笔记** | 你选的工作区文件夹 | **不会** |
| **图片** | 工作区里的 `.notrat/images/` | **不会** |
| **对话记录** | 本地工作区数据 | **不会** |
| API Key | 本地（加密） | 不会（发给 AI 服务商时才会用到） |
| 设置 | 系统应用数据目录 | 只有账号相关的偏好会与账号关联 |
| 登录状态 | 本地 + 服务端会话 | 是 |

::: warning 云端的是账号，不是你的笔记
「Notrat 有没有云端」的答案是：**账号有云端，笔记没有。**

你在 Notrat 里读写的每一个字都只存在你自己的磁盘上。想跨设备，靠的是你自己的工作区文件夹同步方式（网盘 / Git / U 盘）。

唯一会主动上报的是**匿名使用统计与错误报告**（用于改进产品），不含文档内容。你可以在设置里关掉。
:::

## 换电脑

1. 把工作区文件夹同步过去（网盘 / Git / 移动硬盘）
2. 新机器上装 Notrat → 登录同一个账号
3. 打开那个文件夹作为工作区

设置会随账号回来一部分，其余（主题、面板布局等）在新机器上重新调一次即可。
