# 编辑器进阶

## 表格

`Ctrl+T` 插入表格，或者输入 `/表格`。

![表格](/shots/guide/editor-table.png)

表格插进来之后：

| 操作 | 怎么做 |
| --- | --- |
| 加一行 / 加一列 | 右键单元格 →「表格」→ 在上/下方插入行、左/右侧插入列 |
| 删行 / 删列 | 同一个「表格」子菜单里的删除行 / 删除列 |
| 调整列宽 | 拖列之间的竖线 |
| 表头开关 | 右键单元格 →「表格」→ 切换表头行 |
| 单元格内换行 | `Shift+Enter` |
| 跳到下一个单元格 | `Tab` |

## 代码块

`` Ctrl+Shift+K `` 插入代码块，或者输入 ` ``` `。

![代码块](/shots/guide/editor-code.png)

- **语法高亮**：在代码块第一行写上语言名（`js`、`ts`、`python`、`bash`、`json`…）
- **退出代码块**：`Ctrl+Enter`（在代码块最后一行按，直接跳到块后面继续写）
- **复制**：代码块里直接选中 `Ctrl+C`（右上角那个复制角标在**对话里渲染的代码块**上）

::: tip 浅色主题下代码块用的是接近纸的底色
Notrat 的主题切到浅色档时，代码块底色会跟着变浅，但保证文字对比度，每个主题都单独校过，不会出现「浅色主题里代码看不清」。
:::

## 图表

三种图表都能直接写，写完在编辑器里就是渲染好的图：

| 类型 | 怎么用 |
| --- | --- |
| **Mermaid** | 插 Mermaid 图表 → 写 Mermaid 语法 → 出流程图 / 时序图 / 甘特图 |
| **PlantUML** | 同上，走 PlantUML 语法 |
| **HTML** | 插 HTML 渲染块，里面写的 HTML 会渲染出来 |

工具栏或斜杠命令里搜「Mermaid」「PlantUML」「HTML」都能找到。

::: tip Mermaid 图在流式输出时先占位
AI 边写边输出的过程中，**Mermaid** 图表是一个占位框；内容写完定稿才渲染成图。

这样就不会出现「画了一半的图反复重画」的闪烁。（PlantUML / HTML / SVG 是边流边渲染的。）
:::

## 图片

### 三种插法

| 方式 | 怎么做 | 结果 |
| --- | --- | --- |
| **粘贴** | 截图后直接在编辑器里 `Ctrl+V` | 图片存进工作区，正文插入引用 |
| **拖放** | 从文件管理器拖一张图进编辑器 | 同上 |
| **插入** | `Ctrl+Shift+I` 插网络图片（填 URL）；`Ctrl+Alt+I` 插本地图片（选文件） | 按你给的方式插 |

粘贴和拖入的图片统一存到：

```
<你的工作区>/.notrat/images/
```

正文里是**相对路径**引用。所以整个工作区文件夹拷到哪，图片都跟着走。

::: warning 别单独移动 `.notrat/images` 里的文件
正文按相对路径找图。你重命名或挪走图片，文档里就成裂图了。
:::

### 缩放

图片插进来是**所见即所得**的。点一下图片，四周会出现 **8 个手柄**：

| 手柄 | 效果 |
| --- | --- |
| **四角**（斜向箭头） | 等比缩放，宽高一起变 |
| **四边**（横 / 竖箭头） | 只沿这个方向**拉伸**，另一方向不动（可以把图压扁、拉宽） |
| 拖动时 | 图片顶上浮出「宽 × 高 px」徽标 |
| 双击图片 / 右上角「**恢复默认大小**」 | 清掉手动尺寸，回到原图大小 |

![图片缩放](/shots/guide/editor-image-resize.png)

不用记语法、不用手写 `width`，拖完松手就以一步撤销写回文档（存成 `<img … width="N" height="M">`）。键盘也能调：选中手柄后用 `←` `→` 调宽、`↑` `↓` 调高，按住 `Shift` 走大步；右键图片还有「**图片大小**」菜单。

尺寸会跟着文件走：导出 PDF / DOCX 时读的就是这一份宽高。

### 图片引用提示

**选中**正文里的一张图片时，图片旁边会浮出这条引用的 Markdown 源码（`![说明](路径)`）。鼠标停在这个提示上，能看到图片实际落到的**完整路径**。引用里写的是相对路径，这个提示告诉你它到底指向哪里。

路径太长时提示会随版心宽度折行，路径始终完整可见，不会横向溢出去顶出滚动条。

## 文件引用与文件嵌入

除了插图片，你还能把**工作区里其他文件**拉进当前文档：

| 按钮 | 效果 |
| --- | --- |
| **文件引用** | 插入一个指向该文件的链接卡片，点一下跳过去 |
| **文件图片** | 插入图片文件的引用 |
| **文件嵌入** | 把这个文件的内容嵌进当前文档渲染出来 |

用工具栏上那三个文件按钮（文件引用 / 文件图片 / 文件嵌入），或在正文里敲 `[[` 呼出笔记选择器。

## 高亮、脚注、其他行内格式

| 格式 | 怎么做 |
| --- | --- |
| 高亮 | 工具栏**荧光笔**图标，或选中文字后用格式菜单 |
| 脚注 | 工具栏**书签加号**图标，插入脚注标记，文末自动生成脚注区 |
| 加粗 | `Ctrl+B` |
| 斜体 | `Ctrl+I` |
| 删除线 | `Ctrl+D` |
| 下划线 | `Ctrl+U` |
| 行内代码 | 反引号 `` ` `` |
| 软换行 | `Shift+Enter`（同一段内换行） |
| 分割线 | `Ctrl+Shift+-` |

### 脚注可以来回跳

正文里的脚注上标点一下，直接跳到文末那条定义；跳过去之后光标落在定义内容起点，直接打字就是写说明。反过来，点文末定义行开头的 **`[^N]:`** 标记，就跳回正文里的引用处。

## AI 补全

写作时让 AI 接着写。默认关着，要自己开：

1. 打开编辑器右下角的**百宝箱**（工具栏 `⊞`）
2. 找到 **AI 补全** 开关，打开

![AI 补全](/shots/guide/editor-autocomplete.png)

打开后，你写到一半停一下，会浮出**灰色的续写建议**：

- `Tab` 接受
- 继续打字 = 忽略
- `Esc` 关掉

::: tip AI 补全完全是可选的
不开它，Notrat 的其他功能一个都不少。它只是「你打字时旁边有人接话」的那一层。

如果它给你的建议总是跑偏，多半是**当前文件的上下文**跟你要写的方向不一致，试试在文件里先写两句提纲再让它续。
:::

## 斜杠命令里还有什么

输入 `/` 之后，除了上面这些，菜单还按六组铺开：

| 组 | 有什么 |
| --- | --- |
| 常用 | 标题（H1–H6）、无序列表、任务列表、代码块、表格 |
| 文本 | 正文段落、引用块 |
| 列表 | 有序列表 |
| 媒体 | 图片（URL）、分割线 |
| 代码 | Mermaid 图表、PlantUML、HTML 块、SVG 图形、行内公式、块级公式、行内代码 |
| 格式 | 粗体、斜体、下划线、删除线、高亮、链接 |

打字筛选即可，中文、英文、拼音都认（输 `tubiao` 也能找到图表）。
