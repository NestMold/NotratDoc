# 编辑器进阶

这一页是编辑器里那些「不只打字」的部分。

## 表格

`Ctrl+T` 插入表格，或者输入 `/表格`。

![表格](/shots/guide/editor-table.png)

表格插进来之后：

| 操作 | 怎么做 |
| --- | --- |
| 加一行 / 加一列 | 鼠标移到表格边缘，出现 `＋`，点一下 |
| 删行 / 删列 | 用工具栏的表格菜单，或右键行/列 |
| 调整列宽 | 拖列之间的竖线 |
| 表头开关 | 表格菜单里切换 |
| 单元格内换行 | `Shift+Enter` |
| 跳到下一个单元格 | `Tab` |

## 代码块

`` Ctrl+Shift+K `` 插入代码块，或者输入 ` ``` `。

![代码块](/shots/guide/editor-code.png)

- **语法高亮**：在代码块第一行写上语言名（`js`、`ts`、`python`、`bash`、`json`…）
- **退出代码块**：`Ctrl+Enter`（在代码块最后一行按，直接跳到块后面继续写）
- **复制**：代码块右上角有复制按钮

::: tip 浅色主题下代码块用的是接近纸的底色
Notrat 的主题切到浅色档时，代码块底色会跟着变浅，但**保证文字对比度**——每个主题都单独校过，不会出现「浅色主题里代码看不清」。
:::

## 图表

三种图表都能直接写，写完在编辑器里就是渲染好的图：

| 类型 | 怎么用 |
| --- | --- |
| **Mermaid** | 插 Mermaid 图表 → 写 Mermaid 语法 → 出流程图 / 时序图 / 甘特图 |
| **PlantUML** | 同上，走 PlantUML 语法 |
| **HTML** | 插 HTML 渲染块，里面写的 HTML 会渲染出来 |

工具栏或斜杠命令里搜「Mermaid」「PlantUML」「HTML」都能找到。

::: tip 图表在流式输出时先占位
AI 边写边输出的过程中，图表是一个占位框；**内容写完定稿**才渲染成图。

这样就不会出现「画了一半的图反复重画」的闪烁。
:::

## 图片

### 三种插法

| 方式 | 怎么做 | 结果 |
| --- | --- | --- |
| **粘贴** | 截图后直接在编辑器里 `Ctrl+V` | 图片存进工作区，正文插入引用 |
| **拖放** | 从文件管理器拖一张图进编辑器 | 同上 |
| **插入** | `Ctrl+Shift+I` 插网络图片（填 URL）；`Ctrl+Alt+I` 插本地图片（选文件） | 按你给的方式插 |

粘贴和拖入的图片统一存到：

```
<你的工作区>/.notrat/images/
```

正文里是**相对路径**引用。所以整个工作区文件夹拷到哪，图片都跟着走。

::: warning 别单独移动 `.notrat/images` 里的文件
正文按相对路径找图。你重命名或挪走图片，文档里就成裂图了。
:::

### 缩放

图片插进来是**所见即所得**的，鼠标点上去会出现缩放手柄，像 Typora 那样直接拖着改大小。

![图片缩放](/shots/guide/editor-image-resize.png)

不用记语法、不用手写 `width`——拖完自动写入文档。

### 图片引用提示

在正文里引用图片（`![](路径)`）时，编辑器会给出提示：

- 路径不存在 → 明确告诉你找不到，而不是显示一个破图标
- 路径太长 → 提示**折行**显示，不撑破版面

## 文件引用与文件嵌入

除了插图片，你还能把**工作区里其他文件**拉进当前文档：

| 按钮 | 效果 |
| --- | --- |
| **文件引用** | 插入一个指向该文件的链接卡片，点一下跳过去 |
| **文件图片** | 插入图片文件的引用 |
| **文件嵌入** | 把这个文件的内容**嵌进**当前文档渲染出来 |

在工具栏的 `📎` 菜单里，或输入 `@` 选文件。

## 高亮、脚注、其他行内格式

| 格式 | 怎么做 |
| --- | --- |
| 高亮 | 工具栏 `HL`，或选中文字后用格式菜单 |
| 脚注 | 工具栏 `FN`，插入脚注标记，文末自动生成脚注区 |
| 加粗 | `Ctrl+B` |
| 斜体 | `Ctrl+I` |
| 删除线 | `Ctrl+D` |
| 下划线 | `Ctrl+U` |
| 行内代码 | 反引号 `` ` `` |
| 软换行 | `Shift+Enter`（同一段内换行） |
| 分割线 | `Ctrl+Shift+-` |

## AI 补全

写作时让 AI 接着写。**默认关着**，要自己开：

1. 打开编辑器右下角的**百宝箱**（工具栏 `⊞`）
2. 找到 **AI 补全** 开关，打开

![AI 补全](/shots/guide/editor-autocomplete.png)

打开后，你写到一半停一下，会浮出**灰色的续写建议**：

- `Tab` 接受
- 继续打字 = 忽略
- `Esc` 关掉

::: tip AI 补全完全是可选的
不开它，Notrat 的其他功能一个都不少。它只是「你打字时旁边有人接话」的那一层。

如果它给你的建议总是跑偏，多半是**当前文件的上下文**跟你要写的方向不一致——试试在文件里先写两句提纲再让它续。
:::

## 斜杠命令里还有什么

输入 `/` 之后，除了上面这些，还能快速插入：

- 日期 / 时间
- 分隔线、引用块
- 待办清单
- 当前时间戳
- **技能命令**（装了技能后，技能也可以从 `/` 里直接调）

打字筛选即可。
