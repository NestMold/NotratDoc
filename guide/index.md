# 使用教程

Notrat 是一个本地优先的 AI 工作台。你的文件都在自己的电脑上，AI 只是帮你干活的那一位。

这一节从怎么装、怎么写下第一个字讲起，一路讲到扩展、远程助手和导出，截图都来自 1.3.5 的真实界面。

![欢迎屏](/shots/guide/welcome.png)

## 挑一条路开始

不必从头读到尾，按你现在的情况挑一条：

| 你的情况 | 从这开始 | 大约要花 |
| --- | --- | --- |
| 刚下载，还没装 | [安装与首次启动](/guide/install) | 5 分钟 |
| 装好了，想赶紧用起来 | [五分钟写出第一篇](/guide/first-note) | 5 分钟 |
| 用了一阵，想找某个功能在哪 | 看下面的功能地图，或直接搜索 | |
| 想让 AI 真正接管活 | [接入 AI 服务商](/guide/ai-setup) → [AI 对话](/guide/chat) | 15 分钟 |
| 想装插件、连外部工具 | [扩展能力](/guide/plugins) 整组 | 20 分钟 |
| 想给 Notrat 写插件 | 转到 [插件开发](/plugin-dev/) | 独立一册 |

第一次打开 Notrat 时，欢迎屏底部有一条「📖 第一次用？5 分钟写出第一篇」的入口；就算关掉了欢迎屏，还没打开工作区的首页上也留着同一条。新手任务清单已暂时收起，不必逐项打勾——照着这一节走就是完整路径。

## 功能地图

下面按「你想干什么」组织，不按菜单结构排。

### 写作与文件

| 你想做的事 | 去哪 | 详见 |
| --- | --- | --- |
| 打开一个文件夹当笔记库 | 顶部标题栏的工作区菜单 → 打开工作区 | [工作区与文件管理](/guide/workspace) |
| 新建 Markdown、重命名、移动 | 左侧文件树（`＋` / 右键菜单） | [工作区与文件管理](/guide/workspace) |
| 所见即所得地写，不写标记符号 | 直接写，默认就是所见即所得模式 | [编辑器](/guide/editor) |
| 看 Markdown 源码 | 编辑器工具栏切「源码」模式，或 `Ctrl+Shift+M` 附近的分栏开关 | [编辑器](/guide/editor) |
| 插入表格 / 代码块 / 图表 | 工具栏对应按钮，或输入 `/` 呼出斜杠命令 | [编辑器进阶](/guide/editor-advanced) |
| 插图片（粘贴 / 拖入 / 从文件） | 直接 `Ctrl+V` 粘贴或拖进来 | [编辑器进阶](/guide/editor-advanced) |
| 看这篇文档的目录 | 编辑器大纲（右栏或工具栏） | [编辑器](/guide/editor) |

## 截图与版本

::: tip 关于截图
本册截图来自 Notrat 1.3.5（默认主题、浅色档、1440×900 窗口）。

界面会随版本演进，但同一个大版本内，文字标签和入口位置是稳定的。升级后如果图对不上，先按图上的文字找，一般都能找到。
:::

::: warning 开始之前
1. 没有账号也能用。不登录就是免费档，写作、编辑、管理文件全部可用；登录主要影响 AI 相关能力与扩展的可见范围。
2. 文档不会离开你的电脑。笔记以普通 Markdown 文件存在你选的文件夹里，用任何编辑器都能打开。哪天不想用 Notrat 了，把那文件夹拷走就是全部数据。
:::

## 卡住了怎么办

- 先看 [常见问题 FAQ](/guide/faq)，按现象组织，不用知道术语也能查
- 名词看不懂，翻 [术语表](/guide/glossary)
- 还是不行：应用内「设置 → 通用 → 存储与隐私 → 查看错误日志」能看到本机记录的报错，或到官网 `notrat.cn` 提工单
