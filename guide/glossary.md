# 术语表

Notrat 的术语在 1.3.5 统一过一轮。这一页是**权威口径**——文档里、界面上、插件里，都按这里的写法。

## 界面上的名字

| 术语 | 是什么 | 别叫它 |
| --- | --- | --- |
| **工作台** | 活动栏第一格：文件树 + 编辑器 + 右侧搭档 | ~~编辑器~~、~~笔记~~ |
| **工作区** | 你打开的**那个文件夹** | — |
| **搭档模式** | 整屏的 AI 协作布局 | ~~沉浸 AI~~、~~沉浸式~~ |
| **搭档** | 右侧那一栏 AI 对话本身 | ~~对话~~

> 「工作台」和「工作区」一字之差但指两件事：**工作台是界面**，**工作区是文件夹**。

| 术语 | 是什么 |
| --- | --- |
| **详情停靠栏** | 工作台右侧常驻那一栏，两个页签：**时间线** / **改动** |
| **插件箱** | 状态栏上的入口，管已装插件的开关与运行状态 |
| **插件侧栏** | 右侧那一栏里插件自己的界面（和「插件箱」不是一个东西） |
| **活动栏** | 最左边那一竖列导航 |
| **栏位** | 设置 → 面板里的第一段：活动栏 / 左右面板 / 状态栏的显示与排序 |

## 扩展体系

这是术语最密的一块。

| 术语 | 是什么 | 界面写法 |
| --- | --- | --- |
| **扩展** | 四类可安装东西的总称（技能 / 连接器 / 专家 / 插件） | 「扩展」 |
| **扩展管理** | 设置里的分类，管已装的扩展 | 「扩展管理」 |
| **连接器（MCP）** | 给 AI 接外部工具的机制 | 一律写「连接器（MCP）」，全角括号 |
| **专家（智能体）** | 一个角色：身份 + 工具 + 工作流 | 一律写「专家（智能体）」 |
| **技能** | 一套固定做事方法（一个 `SKILL.md`） | 「技能」 |
| **插件** | 给 Notrat 本体加功能的包 | 「插件」 |
| **IM 插件** | 把微信 / 飞书等接进来的功能 | 设置里的分类名叫**远程助手** |

::: tip 退休的说法
| 老说法 | 现在叫 |
| --- | --- |
| 专家包 | **专家**（智能体） |
| 网关 | **远程助手** / IM 插件 |
| MCP 连接器、MCP 服务 | **连接器（MCP）** |
| 沉浸 AI、沉浸式 | **搭档模式**（全屏） |
| 市场（指活动栏那一格） | **扩展** |
:::

::: warning 专有名词例外
官方产品名、第三方服务名、以及模型面（给 AI 看的提示词）里的英文术语**不做中文化**。

所以你会看到「MCP」「Agent」仍然出现在英文界面和模型提示词里——那是刻意的。
:::

## 档位

| 术语 | 含义 |
| --- | --- |
| **纯净版** | 免费档。完整 Markdown 编辑器 + 文件管理 + 插件 |
| **基础版** | 加上 AI 能力的档位 |
| **专业版** | 最全的档位（含远程助手、A2A、HTTP API Bridge） |
| **ux 模式** | 界面按档位切换的复杂度档（`pure` / `basic` / `pro`），与档位一一对应 |

::: tip 「纯净版」听起来像阉割，其实不是
它是完整可用的写作工具。叫「纯净」是因为**不掺 AI**——如果你就想找个干净的 Markdown 编辑器，这一档是终点而不是起点。
:::

## 编辑器

| 术语 | 含义 |
| --- | --- |
| **所见即所得 / 编辑模式** | 看到的是排版后的样子（默认） |
| **源码模式** | 看到的是原始 Markdown 文本（`Ctrl+/`） |
| **百宝箱** | 编辑器右下角的浮动面板：编写模式、AI 补全、大纲 |
| **斜杠命令** | 输入 `/` 呼出的插入菜单 |
| **大纲** | 当前文档的标题树 |

## AI

| 术语 | 含义 |
| --- | --- |
| **服务商** | AI 的来源（OpenAI、DeepSeek、本地 Ollama…） |
| **模型** | 具体调用的那个模型 |
| **参数** | 温度、最大长度等 |
| **预设** | 参数的四档打包：创意 / 平衡 / 精准 / 快速 |
| **消息级** | 只作用于**当前这一条消息**的设置（发送后清空） |
| **子 agent** | 主 agent 派出去分头干活的下级智能体 |
| **工具调用** | AI 调用一个外部能力（读文件、跑命令…）的动作 |

## 其它

| 术语 | 含义 |
| --- | --- |
| **虚拟文件** | 不在磁盘上、由应用生成的视图 |
| **工作区级 / 全局** | 配置的作用范围：只在这个工作区，还是所有工作区 |
| **台账** | 记录「装的是市场里的哪个版本」的本地账本（连接器用它判断更新） |
