# 术语表

Notrat 的术语在 1.3.5 统一过一轮。这一页是**权威口径**，文档里、界面上、插件里，都按这里的写法。

## 界面上的名字

| 术语 | 是什么 | 别叫它 |
| --- | --- | --- |
| **工作台** | 活动栏第一格：文件树 + 编辑器 + 右区 | ~~编辑器~~、~~笔记~~ |
| **工作区** | 你打开的**那个文件夹** | — |
| **工作空间** | 把一组工作区根起个名字存下来，下次整组开回 | ~~空间~~（口语可以，正式写「工作空间」） |
| **全屏 AI** | 整屏的 AI 协作布局（1.3.6 起由工作台右区的全屏键进入） | ~~沉浸 AI~~、~~沉浸式~~（界面上的全屏键提示、设置里的「搭档模式（全屏）」开关仍写「搭档模式」，是同一个东西） |
| **AI 搭档** | 活动栏上打开工作台右区对话的那一格 | ~~AI 侧栏~~ |
| **右区** | 工作台右边整块：AI 对话 + 会话栏，也能切成插件页 | ~~侧栏~~（会话栏另有其名） |
| **会话栏** | 右区右侧那条窄栏（176–400px），历史对话一行一条 | ~~会话标签条~~（已移除） |
| **运行岛** | 工作台里 AI 跑工具时编辑器顶部浮出的小条 | ~~运行状态条~~ |

> 「工作台」「工作区」「工作空间」是三个词：工作台是界面，工作区是文件夹，工作空间是一组文件夹的名字。

| 术语 | 是什么 |
| --- | --- |
| **详情停靠栏** | **全屏 AI** 里右侧常驻那一栏，两个页签：**时间线** / **改动**（工作台里对应的是运行岛） |
| **插件箱** | 状态栏上的入口，管已装插件的开关与运行状态；右键可查看日志 / 重载插件 |
| **插件侧栏** | 右区里插件自己的界面（和「插件箱」不是一个东西） |
| **插件页** | 右区切成「插件」页签后的整块；面板还能以**整页**方式占满主区 |
| **活动栏** | 最左边那一竖列导航 |
| **栏位** | 设置 → 面板里的第一段：活动栏 / 左右面板 / 状态栏的显示与排序 |

## 扩展体系

| 术语 | 是什么 | 界面写法 |
| --- | --- | --- |
| **扩展** | 四类可安装东西的总称（技能 / 连接器 / 专家 / 插件） | 「扩展」 |
| **扩展管理** | 设置里的分类，管已装的扩展 | 「扩展管理」 |
| **连接器（MCP）** | 给 AI 接外部工具的机制 | 一律写「连接器（MCP）」，全角括号 |
| **专家（智能体）** | 一个角色：身份 + 工具 + 工作流 | 一律写「专家（智能体）」 |
| **技能** | 一套固定做事方法（一个 `SKILL.md`） | 「技能」 |
| **插件** | 给 Notrat 本体加功能的包 | 「插件」 |
| **远程助手** | 把微信 / 飞书等接进来的功能 | 「远程助手」 |
| **IM 插件** | 远程助手「进阶」里的一页：装适配器、接通更多平台 | 「IM 插件」（内测） |

::: tip 退休的说法
| 老说法 | 现在叫 |
| --- | --- |
| 专家包 | **专家**（智能体） |
| 网关 | **远程助手** |
| MCP 连接器、MCP 服务 | **连接器（MCP）** |
| 沉浸 AI、沉浸式 | **全屏 AI**（「搭档模式」是界面上的旧名字，仍在用） |
| 工作空间（1.3.5 及以前指单个文件夹） | **工作区**；「工作空间」现在专指**一组根的命名组合** |
| 市场（指活动栏那一格） | **扩展** |
:::

::: warning 专有名词例外
官方产品名、第三方服务名、以及模型面（给 AI 看的提示词）里的英文术语**不做中文化**。

所以你会看到「MCP」「Agent」仍然出现在英文界面和模型提示词里，那是刻意的。
:::

## 档位

| 术语 | 含义 |
| --- | --- |
| **纯净版** | 免费档。完整 Markdown 编辑器 + 文件管理 + 插件 |
| **基础版** | 加上 AI 能力的档位 |
| **专业版** | 最全的档位（含远程助手、A2A、HTTP API Bridge） |
| **ux 模式** | 界面按档位切换的复杂度档（`pure` / `basic` / `pro`），与档位一一对应 |

::: tip 「纯净版」听起来像阉割，其实不是
它是完整可用的写作工具。叫「纯净」是因为**不掺 AI**，如果你就想找个干净的 Markdown 编辑器，这一档够用了。
:::

## 编辑器

| 术语 | 含义 |
| --- | --- |
| **所见即所得 / 编辑模式** | 看到的是排版后的样子（默认） |
| **源码模式** | 看到的是原始 Markdown 文本（`Ctrl+/`） |
| **百宝箱** | 编辑器右下角的 **⊞** 小按钮（提示语是「工具栏模式设置」）：切**工具栏样式**（含斜杠命令式）、把当前文件**当便签打开**、**AI 补全**开关 |
| **斜杠命令** | 输入 `/` 呼出的插入菜单 |
| **大纲** | 当前文档的标题树 |

## AI

| 术语 | 含义 |
| --- | --- |
| **服务商** | AI 的来源（OpenAI、DeepSeek、本地 Ollama…） |
| **模型** | 具体调用的那个模型 |
| **参数** | 温度、最大长度等 |
| **预设** | 参数的四档打包：有创意 / 均衡 / 精准 / 快速 |
| **工作场景** | AI 的做事方式：日常任务 / 自我验证 / 思维链 / 计划模式。和「推理等级」不是一回事 |
| **日常任务** | 默认工作场景，不加额外约束；只能单独使用 |
| **计划模式** | 工作场景之一：先写 `## 执行计划`，再按步骤派专家分头执行 |
| **排队发送** | `Alt+Enter`：不打断当前回答，这条等这一轮结束再发 |
| **消息级** | 只作用于**当前这一条消息**的设置（发送后清空） |
| **子 agent** | 主 agent 派出去分头干活的下级智能体 |
| **工具调用** | AI 调用一个外部能力（读文件、跑命令…）的动作 |

## 其它

| 术语 | 含义 |
| --- | --- |
| **三档范围** | 资源（技能 / 连接器 / 插件）装在哪：**全局 / 工作空间 / 当前工作区**，优先级 工作区 > 工作空间 > 全局 |
| **空间级会话** | 拖到「工作空间」组头下的对话：留在原工作区，显示在空间组里 |
| **时间分栏** | 会话栏按 今天 / 昨天 / 3 日内 / 7 日内 / 一个月内 / 很久 收拢，每栏可单独展开收起 |
| **查看差异** | AI 改完文件后的入口，在编辑器区打开「文件名 · diff」标签页（此前叫「查看修改 / 查看改动」） |
| **离线文档** | 应用内自带的一份教程副本，断网也能读 |
| **台账** | 记录「装的是市场里的哪个版本」的本地账本（连接器用它判断更新） |
