# AI 对话

AI 在 Notrat 里有两个地方可以说话，看你要干多大的活：

| | 侧边栏对话 | 搭档模式 |
| --- | --- | --- |
| 在哪 | 工作台右侧 | 活动栏「搭档」，整屏 |
| 适合 | 问一句、改一段、边写边聊 | 一次改多个文件、写代码、做调研 |
| 上下文 | 当前文件 | 整个工作区 |

两者是**同一套对话**——在侧边栏聊到一半，点「搭档」切过去，记录和进度都在。

![AI 对话侧栏](/shots/guide/chat-panel.png)

::: warning 先配 API Key
对话要用起来，得先接一个 AI 服务商。没配的话输入框会提示「升级到基础版 / 专业版后即可开聊」。

→ [接入 AI 服务商](/guide/ai-setup)
:::

## 发第一条消息

在输入框打字，回车发送（`Shift+Enter` 换行）。

输入框上方会自动带上**当前打开的文件**作为上下文——不用手动贴内容。你也能看到带上的是哪个文件，不想要就点掉。

![对话输入区](/shots/guide/chat-input.png)

## `@` 引用：四个页签

输入 `@` 呼出引用面板。它是**四个页签**，用左右方向键 `←` `→` 直接切：

| 页签 | 内容 | 作用 |
| --- | --- | --- |
| **文件** | 工作区所有文件与文件夹 | 把文件内容加进本次上下文 |
| **专家（智能体）** | 内置专家 + 你自己建的 + 从市场装的 | 这一条消息（或这个会话）由谁来做 |
| **技能** | 内置 / 你的（工作区 / 全局 / 插件） | 本条消息指定用哪些技能 |
| **连接器（MCP）** | 你已启用的连接器 | 本条消息允许用哪些外部工具 |

![@ 引用面板](/shots/guide/mention-panel.png)

::: tip 技能和连接器是「本条消息」级的
在 `@` 面板里勾选技能或连接器，作用范围是**你正在写的这一条消息**——发送后自动清空，下一条不受影响。

已勾选的在面板里标着「**本条**」，再点一下取消。

面板里能同时勾多个。想在整段会话里一直用某个技能，用 `/` 命令那种方式，或者把专家固化到专家设置里。
:::

## `/` 命令

输入 `/` 呼出命令菜单，和编辑器里的斜杠命令是同一套思路：

- **技能命令** —— 直接调用某个技能
- **自定义命令** —— 你在设置里定义过的提示词片段
- **内置动作** —— 比如总结当前文件、解释选中内容

选中的技能会以 **chip** 的形式插到光标处，你能看到这条消息带了哪些技能。

![技能 chip](/shots/guide/chat-skill-chip.png)

## 让它动你的文件

这是 Notrat 跟「网页版聊天框」最大的区别：**AI 能真的改你的文件**。

当它决定写文件时，你会看到：

1. 对话里出现一个**工具调用卡片**，写明它要改哪个文件
2. 改动以 **diff** 形式展示（加的行绿、删的行红）
3. 你点允许，它才动

![AI 改文件 diff](/shots/guide/chat-diff.png)

::: warning 权限别关
默认每一次写操作都要你确认。设置 → 权限里可以放宽，但放宽意味着 AI 可以在没问你的情况下改文件。

**建议保留默认。** 真要放宽，也先确认工作区在版本控制下（有 Git 就能回退）。
:::

改完之后，被改动的文件会**自动在编辑器里打开**，不用自己去文件树里找。

## 右侧的「改动」页签

工作台右侧有一栏常驻的**详情停靠栏**，两个页签：

![详情停靠栏](/shots/guide/details-dock.png)

| 页签 | 内容 |
| --- | --- |
| **时间线** | 这次会话里发生的每一步（问了什么、调了什么工具、改了哪个文件） |
| **改动** | 所有被改过的文件清单，点一个看那个文件的 diff |

「改动」页在 AI 干完一段活之后最好用——一眼看清它总共动了哪些地方，而不是在对话里往回翻。

## 它正在干什么

AI 干活时，对话里会实时显示它当前的动作：

- 读哪个文件
- 跑什么命令
- 搜索结果
- 调到第几个工具

**一次调用很多个** 时，列表只铺一窗（当前那条上下各三条），滚动可以看到全部——不会因为一次读了 50 个文件就把屏幕撑爆。

正在跑的那一条永远在视野里，底下还有渐隐提示「下面还有」。

::: tip 子 agent
复杂任务里，AI 会派**子 agent** 分头去干（一个查资料、一个写代码）。

主 agent 可能先给你答复，但页面状态会跟着还在跑的子 agent 走。点停止会**明确地**把所有还在跑的 agent 都停掉。
:::

## 中间可以插话

AI 正在回答时，输入框依然可用。你可以：

- 补充一句要求（它会读进去，调整正在做的事）
- 直接叫停（发送按钮变成停止）

不用等它说完。

## 选模型

输入框右下角有模型选择器：

![模型选择器](/shots/guide/model-selector.png)

点开可以换模型、看每个模型的特点（上下文长度、是否支持推理等）。切换只影响之后的对话。

旁边还有**权限模式**（默认 / 更宽松）和文本 / 图片附件按钮。

详见 [模型与参数](/guide/ai-models)。

## 对话记录

对话记录存在工作区里，切换文件、切换窗口都不会丢；关掉应用重开还在。

侧栏顶部可以新建对话、切换历史对话。**历史对话支持多条并行**——让一个去查资料，另一个改代码，互不干扰。

## 让 AI 记住你的偏好

三种由轻到重的办法：

| 想让它记住 | 怎么做 | 范围 |
| --- | --- | --- |
| 就这一次 | 直接在消息里说 | 本条 |
| 这一类活都这么干 | 建一个[技能](/guide/skills) | 你调用时 |
| 永远这么说话 | 设置 → 提示词，写自定义指令 | 全局 |
