# AI 对话

AI 在 Notrat 里可以从两个大小说话，看你要干多大的活：

| | 工作台右区 | 全屏 AI |
| --- | --- | --- |
| 在哪 | 工作台右边（活动栏「AI 搭档」/ 状态栏「AI 对话」都能开） | 右区头部的全屏键；常用可点亮活动栏「AI 全屏」 |
| 适合 | 问一句、改一段、边写边聊 | 一次改多个文件、写代码、做调研 |
| 上下文 | 当前文件（发送时自动带上） | 同一套上下文 |

两者是同一套对话：在右区聊到一半，点全屏键切过去，记录和进度都在；从全屏里打开文件会自动切回工作台。

![AI 对话侧栏](/shots/guide/chat-panel.png)

::: warning 两件事，缺一聊不起来
1. **档位**：纯净版（免费）的输入框是锁着的，提示「升级到基础版 / 专业版后即可开聊」
2. **服务商**：档位够了还得接一个 AI 服务商，否则没人在那头回话

两件事都办完才聊得起来 → [接入 AI 服务商](/guide/ai-setup)
:::

## 发第一条消息

在输入框打字，回车发送（`Shift+Enter` 换行）。

发送时会自动把当前打开的文件带进上下文，后台静默完成，不用手动贴内容，界面上也不会多出一个 chip。想精确控制带哪些文件，用下面的 `@`。

想把文件或图片主动塞给它，用输入框右下角的附件键，或者直接把文件拖进输入框。`@` 引来的文件和附件在输入框里都是以标签形式占位，**标签之后可以直接接着打字**，光标不会被锁在末尾。

![对话输入区](/shots/guide/chat-input.png)

## 工作场景

输入框工具栏里有一个「工作场景」按钮（默认显示「日常任务」）。点开是四张整块可点的卡：

| 场景 | 作用 | 选择规则 |
| --- | --- | --- |
| **日常任务** | 默认场景，不加额外约束，按模型自身能力直接回答 | **只能单独使用**；勾别的场景时它自动让位，再点一次 = 不用任何场景 |
| **自我验证** | 按思考、行动、观察的循环逐步推进，适合需要验证的任务 | 可多选 |
| **思维链** | 展示更完整的中间推理过程，适合复杂逻辑推理 | 可多选 |
| **计划模式** | 先写详细执行计划，再按步骤派专家分头执行 | 可多选 |

按钮上直接写当前选的是哪个场景；选了多个时显示「N 个场景」。工具条和面板里都叫「工作场景」，和模型下拉里的「推理等级 / 思考程度」不是一回事——后者调的是模型想多久，前者决定 AI 用哪种做事方式。

### 计划模式怎么跑

勾上「计划模式」后，AI 会先把 **`## 执行计划`** 完整写在回复正文里：

- 每一步做什么、动哪些文件、怎么算做完、哪些步骤能并行
- 写完**直接开工**，不用再确认一次，也不用另外打开什么开关
- 能独立完成的步骤交给对应的专家分头做，互不依赖的同时派出；AI 自己负责拆解、验收和汇总
- 每完成一步回一行「✓ 第 N 步」
- 计划和进度都在对话正文里，按停止随时打断

::: tip 场景不是越多越好
「日常任务」适合绝大多数问答；只有任务确实需要验证或长链条推理时，才勾「自我验证」「思维链」「计划模式」。多选时 AI 会按任务挑最合适的那个。
:::

## GOAL：让它自己往下推

输入框工具条上还有一个 **GOAL** 按钮（火箭图标，全屏 AI 里也在同一行）。打开之后就不用一句句「继续」了：每轮回复结束，AI 会按上一条回复里写明的「下一步」自己再发一条，接着往下做。开关状态跟着这条对话存，切走再回来还在。

它会自己停下来，只有三种情况：

| 停下来的原因 | 判据 |
| --- | --- |
| **目标已完成** | 回复里单独一行写了「目标已完成」（或「所有任务完成」「目标已达成」「已无更多可执行步骤」） |
| **连续几轮推不动** | 连着 3 轮既没调用工具、正文又很短 |
| **到了上限** | 最多 15 轮 |

停下来时按钮会自动关掉，并弹一条提示写清原因。点停止也立刻停，而且不会自己再续跑——等你亲手发下一条才解封。

GOAL 和「工作场景」不是一回事：工作场景决定 AI **怎么**做事，GOAL 决定这件事**要不要一路做到底**。你排队中的消息永远优先于 GOAL 的续跑。

## `@` 引用：四个页签

输入 `@` 呼出引用面板。它是四个页签，用左右方向键 `←` `→` 直接切：

| 页签 | 内容 | 作用 |
| --- | --- | --- |
| **文件** | 工作区所有文件与文件夹 | 把文件内容加进本次上下文 |
| **专家（智能体）** | 内置专家 + 你自己建的 + 从市场装的 | 这一条消息（或这个会话）由谁来做 |
| **技能** | 内置 / 你的（工作区 / 全局 / 插件） | 本条消息指定用哪些技能 |
| **连接器（MCP）** | 你已启用的连接器 | 本条消息允许用哪些外部工具 |

![@ 引用面板](/shots/guide/mention-panel.png)

::: tip 技能和连接器是「本条消息」级的
在 `@` 面板里勾选技能或连接器，作用范围是你正在写的这一条消息，发送后自动清空，下一条不受影响。

已勾选的在面板里标着「**本条**」，再点一下取消。

面板里能同时勾多个。想在整段会话里一直用某个技能，用 `/` 命令那种方式，或者把专家固化到专家设置里。
:::

## `/` 命令

输入 `/` 呼出命令菜单，和编辑器里的斜杠命令是同一套交互，但内容是内置命令 + 插件命令，按类别平铺（通用 / 文件 / 编辑 / 连接器（MCP）/ 终端 / AI / 搜索 / 分享 / 导出 / 工作区）。

比如 `/summarize` 总结当前文档、`/compress` 压缩当前对话历史。和技能相关的几条是管理命令：

```
/skill list      列出可用技能
/skill use       这条会话用某个技能
/skill add       装一个技能
```

::: tip 想让这条消息带上技能，走 `@`
`/` 菜单里不铺具体技能。技能要用 chip 形式插进当前消息，走 `@` → **技能**页签。

![技能 chip](/shots/guide/chat-skill-chip.png)
:::

## 让它动你的文件

这是 Notrat 跟「网页版聊天框」最大的区别：AI 能真的改你的文件。

当它决定写文件时，你会看到：

1. 对话里出现一个**工具调用卡片**，写明它要改哪个文件
2. 默认每次写操作都要你点**「允许」**，它才动你的文件（见下面那个 warning）
3. 动完之后卡片上多出**「查看差异」**，点开在编辑器区多一个「文件名 · diff」标签页：页头写着**已新建 / 已修改 / 已删除**和 **+N / −N**，正文是行级 **diff**（加的行绿、删的行红），还能一键「打开文件」

终端里跑的脚本改了文件，也会开同样的 diff 标签页，来源一样写清楚。

想整段回退，diff 页头有「**撤销这次修改**」：会先确认文件自那次改动后没被别的操作改过，能对上才恢复；撤销之后这份 diff 仍留着，方便对照看撤掉了什么。

![AI 改文件 diff](/shots/guide/chat-diff.png)

::: warning 权限别关
默认每一次写操作都要你确认。想放宽只有一处开关：输入框工具条上的**「完全访问」**（灰盾形对勾 = 默认权限，点一下变红盾 = 不再逐步确认）；同一件事在设置里叫「自动授权连接器（MCP）工具」（设置 → 扩展管理 → 连接器（MCP））。开启时要过一个确认弹窗。

放宽意味着 AI 可以在没问你的情况下改文件。

建议保留默认。真要放宽，也先确认工作区在版本控制下（有 Git 就能回退）。
:::

改完之后，被改动的文件会**自动在编辑器里打开**，不用自己去文件树里找。

## 全屏 AI 右侧的「改动」页签

点右区头部的全屏键，进入**全屏 AI**（原来的搭档模式）后，聊天区右边有一条常驻的**详情停靠栏**，两个页签：

![详情停靠栏](/shots/guide/details-dock.png)

| 页签 | 内容 |
| --- | --- |
| **时间线** | 这次会话里发生的每一步（问了什么、调了什么工具、改了哪个文件） |
| **改动** | 这轮被 AI 动过的文件清单，点一条展开看 diff |

「改动」页在 AI 干完一段活之后最好用，一眼看清它总共动了哪些地方，不用在对话里往回翻。

（工作台里不用切全屏：AI 开始跑工具后，编辑器顶部会浮出**运行岛**，点开就是本轮详情；侧栏收起时岛还在。详见 [活动栏与面板](/guide/panels)。）

## 它正在干什么

AI 干活时，对话里会实时显示它当前的动作：

- 读哪个文件
- 跑什么命令
- 搜索结果
- 调到第几个工具

一次调用很多个时，列表只铺一窗（当前那条上下各三条），滚动可以看到全部，不会因为一次读了 50 个文件就把屏幕撑爆。

正在跑的那一条永远在视野里，列表底下有渐隐，并配一个「**展开全部（N）**」按钮，想看全就点它。

::: tip 子 agent
复杂任务里，AI 会派**子 agent** 分头去干（一个查资料、一个写代码）。

主 agent 可能先给你答复，但页面状态会跟着还在跑的子 agent 走。点停止会**明确地**把所有还在跑的 agent 都停掉。
:::

## 中间可以插话：打断或排队

AI 正在回答时，输入框依然可用，不用等它说完。这时发送有两种：

| 方式 | 怎么做 | 结果 |
| --- | --- | --- |
| **直接打断** | 回车 / 点发送 | 结束当前回答，立刻发这条 |
| **排队** | `Alt+Enter`，或输入框旁的排队键 | 不打断当前回答，这条连同附件、消息级连接器一起排进队列，等这一轮结束再按顺序发 |

输入框上方会出现队列横幅：

- 「当前回复结束后发送（N 条）」
- 「压缩完成后发送（N 条）」
- 「已暂停：N 条排队消息」（按过停止之后）

点开横幅能看每条内容，也可以手动点「发送」或「取消」。

按停止之后，队列里的自动条目会丢掉，用户排队的消息只暂停、不自动发；只有你亲手发下一条消息，或手动点队列里的「发送」，才会解封。

## 停止就是停到底

点停止不只停住眼前这条流：后台子任务晚一步回传、截断续写、空回复重试这几条自动续跑路径也会全部拦住，不会出现「明明停了还在输出」。用户新发一条消息才会解封。

## 选模型

输入框工具条的最左端（左下角第一位）就是模型选择器：

![模型选择器](/shots/guide/model-selector.png)

点开可以换模型、看每个模型的特点（上下文长度、是否支持推理等）。切换只影响之后的对话。

旁边还有**权限开关**（「默认权限」↔「允许完全访问」，就是上面那个红盾/灰盾）、以及文本 / 图片附件按钮。

详见 [模型与参数](/guide/ai-models)。

## 对话记录

对话记录存在本机的应用数据里（`~/.notrat/sessions/`，每个工作区一份索引、每个会话一个文件），切换文件、切换窗口都不会丢；关掉应用重开还在。1.3.6 起启动只读索引和当前正在看的那个会话，其余对话打开时才补正文，所以工作区很大也不会一启动就吃掉几百 MB 内存。它不写进你的工作区文件夹，所以跟着工作区一起拷走的是笔记，不是聊天记录。

侧栏顶部可以新建对话、切换历史对话，历史对话可以并存很多条。**新建对话的标题由 AI 起**：发送那一刻先落一条摘要式标题（列表立刻可读，模型没连上也有名字），随后模型生成的短标题（12 字以内）异步替换——你自己改过的名字不会被覆盖。

**自己发出去的话也归你管**：鼠标移到消息气泡上，下沿会出现「时间 · 编辑 · 复制」——**编辑**改的是自己那条话（改完重新发送），**复制**拿到的是消息里真正显示的文字（`@` 专家、文件标签都在）；工作台右区与全屏 AI 是同一套。默认状态这一行不显示，鼠标扫过才露，不挡着读。

会话栏和全屏左栏都是**一行式**：一行一条，只显示标题，预览挪到悬停提示。列表按**工作区**分组，组的先后跟文件树里的根顺序一致，切换当前工作区不会让列表重排；当前工作区打「当前」，组头写着这一组共有多少条、可以整组收起。

列表还按**今天 / 昨天 / 3 日内 / 7 日内 / 一个月内 / 很久**分栏，点栏目标题展开或收起；全部展开装得下时保持全开，装不下只展开首屏里的栏，搜索时自动全部展开。

## 多会话并行与会话栏

**多会话并行（后台续流）是本版新增的能力，默认开着**：她在跑的时候你切到别的会话、或者新建对话，在途的回复不会被掐断——它**转到后台继续跑**，跑完自己落盘：

- 在别的会话里发消息、新建对话，都不会打断正在输出的那条回复
- 会话列表里能看到运行状态：正在跑的会话行尾有个转圈，跑完变对勾、之后回到时间；后台跑完但你还没点开的会话留一个实心点，点开即消

### 新建对话时会先问你一句

开着并行时，新建对话的那一刻如果还有回复在跑，Notrat 不会替你闷头决定，而是先弹一个三选一：

| 选项 | 含义 |
| --- | --- |
| **后台继续并新建** | 那条回复转后台继续跑（完成自动保存），同时给你一个新对话 |
| **停止并新建** | 现在停止那条回复（已经吐出来的内容照常保存），再新建对话 |
| **取消** | 什么都不做 |

勾上弹窗里的「不再提醒」，以后就不再问了——新建对话默认走「后台继续」。想改回「每次都问」：设置 → 面板 → 对话与启动 → 打开「**新建对话时先询问**」（它和弹窗里那个勾选框是同一个开关）。

不想并行：设置 → 面板 → 对话与启动 → 关掉「**多会话并行（后台续流）**」。关掉后同一时间只有一个 AI 干活，切走即中断当前回复。

### 会话栏

工作台的会话列表在**右区右侧一条窄栏**里（全屏 AI 在左栏），176px 起步：

| 元素 | 行为 |
| --- | --- |
| **拖左缘** | 在 176–400px 之间调宽；编辑器低于 420px 时自动收起 |
| **输入框旁的历史按钮** | 开合会话栏；收起后整栏归 0 宽 |
| **工作区组头** | 写着这一组条数，可整组收起；悬停露出 `＋` 在该工作区新建对话（在别的工作区时先切过去再建） |
| **拖动一条对话** | 拖到另一个工作区组头 = 连同历史搬过去；拖到「工作空间」组头 = 变成空间级 |
| **运行标记** | 正在跑的会话行尾有转圈；跑完变对勾，后台跑完但你还没点开的会话留一个实心点，点开即消 |

旧的「会话标签条」已在 1.3.6 移除，切会话走会话栏。

::: tip 「空间级会话」是什么
把一条对话拖到**「工作空间」组头**上，它就归这个工作空间所有，但**仍然留在原来的工作区**里——会话栏和欢迎屏「对话」页签里会按「工作空间 → 工作区」两级收起，它单独显示在空间组下。适合「这组项目共同相关的事」。

再拖回某个工作区组头，它就退回成那个工作区的普通对话。
:::

### 搜索聊天内容

右区头部的搜索框搜的不只是标题：**第一句用户消息**和**最后一条回复**里的词也能命中。打开会话后正文里会标黄，按回车逐个跳。搜索时时间分栏自动全部展开，命中项不会藏在收起的栏里。

### 在对话里划词引用

在侧栏或全屏的对话正文里选中文字，选区旁会浮出「引用到聊天」：点一下就把选段钉到输入框上方，随下一条消息发给 AI，来源标为「对话」。选中文字后右键，还有「复制 / 引用到聊天 / 全选」；没有选中文字时右键保持原样。

::: tip 万一遇到异常
并行开着时如果切来切去遇到空白、状态不对这类异常，先把 设置 → 面板 → 对话与启动 里的「多会话并行」关掉——退回「同一时间只跑一个对话」，最稳。
:::

::: tip 刷新 / 重载不丢草稿
AI 调用刷新时，会先给所有有未保存改动的文件拍一份快照，再等主对话、子任务和待发送队列都清空，才真正重载；等待期间回复继续流，不会在半句话时被切断。刷新、热更新、AI 重载后，草稿会自己回到编辑器里。
:::

## 让 AI 记住你的偏好

三种由轻到重的办法：

| 想让它记住 | 怎么做 | 范围 |
| --- | --- | --- |
| 就这一次 | 直接在消息里说 | 本条 |
| 这一类活都这么干 | 建一个[技能](/guide/skills) | 你调用时 |
| 永远这么说话 | 设置 → 提示词，写自定义指令 | 全局 |
