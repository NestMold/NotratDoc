# 工作空间：把几个项目组合成一个

「工作空间」是**给一组工作区起的名字**。它不是磁盘上的新目录，也不复制任何文件——存下来的只有两样东西：这几个文件夹的路径，以及上次停在哪个根。

文件还在原地，会话还是各自的，只有「整组一起打开」这件事被记住了。

| 词 | 指的是 |
| --- | --- |
| **工作台** | 界面：文件树 + 编辑器 + 右区 |
| **工作区** | 一个文件夹（也可以是一整个仓库） |
| **工作空间** | 几个工作区存成的一个名字，下次一键整组开回 |

## 什么时候值得建一个

- 一个产品拆成 `前端` / `后端` / `文档` 三个仓，AI 要跨仓改一处接口
- 同系列的几个项目共用一套技能、连接器（MCP）或插件
- 每天开工都打开同样的几组目录，不想每次一个个点

只是临时想同时看两个目录，用「附加到当前窗口」就够了（见 [工作区与文件管理](/guide/workspace#同时开多个工作区)），不必先存成空间。

## 三条建法

| 起点 | 怎么做 | 名字 |
| --- | --- | --- |
| 窗口里已经有两个以上根 | 根的数量稳定约 1.5 秒后，会自动弹出「**这组工作区已经成为一个工作空间**」的命名框；当时跳过了也别急，「最近」里会多出一条带「**未保存**」标记的行，点它就是同一个命名框 | 默认是各根名字用「 + 」连起来，回车即用；最多 80 字 |
| 一次选了好几个目录 | 「打开工作区…」时按住 `Ctrl` / `Shift` 多选 → 确认「合并成工作空间」 | 同上，可以改 |
| 已经存了两个以上空间 | 空间行的「⋯」→「**合并工作空间…**」→ 勾两个及以上 | 新的名字 |

命名框里点「取消」不等于存下来了：这个多根窗口仍是临时的，关掉就散；下次再附加一个根、根数重新稳定后，会按新的整组再问一次。

合并的规则：

- 根会**去重**，同一个目录只留一份
- **原空间保留**，不会因为合并就消失
- 磁盘上的文件一个都不动
- 一个空间最多 32 个根；存满 50 个空间后，再存新的会挤掉**最久没打开**的那个

::: tip 空间名不是文件夹名
改名只改你看到的那个名字，磁盘上的目录名、路径、文件都不变。两个空间甚至可以指向有重叠的目录。
:::

## 打开一个工作空间

| 入口 | 怎么走 |
| --- | --- |
| 工作区菜单 →「**全部工作空间…**」 | 带搜索框的空间列表，点一行 →「当前窗口 / 新窗口」 |
| 空间行的「⋯」→「**在新窗口打开**」 | 直接在新窗口整组打开 |
| 欢迎屏「最近」 | 工作区与工作空间在**同一条时间轴**上（层叠图标区分），点一下按原来的动线打开 |

新窗口打开时，整组根一起带过去；重启应用后窗口、根、当前根、大小位置都原样恢复。

![全部工作空间：带搜索框的清单，点一行即可打开](/shots/guide/spaces-all.png)

## 打开之后是什么样

一个工作空间打开后，就是一个**多根窗口**：

| 行为 | 说明 |
| --- | --- |
| **文件树** | 所有根并列，工作区根用「层叠」图标；点根名切当前根，当前根的名字高亮成主题色 |
| **标题栏** | Notrat 下面写着这个空间的名字（没起名时用各根名字拼起来） |
| **会话栏** | 按工作区分组，组的先后跟文件树里的根顺序完全一致 |
| **拿掉一个根** | 右键根名 →「**从窗口移除**」。只从当前窗口撤下，**磁盘文件与已有会话都不会删** |
| **重启** | 全部根、当前根、文件树顺序原样开回 |

![一个工作空间打开后的样子：标题栏写着空间名，文件树里两个根并列](/shots/guide/spaces-overview.png)

::: warning 根打不开时会明说
某个空间里保存的目录如果被删了、移走了，或者所在的盘没插，Notrat 不会假装打开成功。全都打不开时会告诉你「这个工作空间里的目录都打不开了」，不会只给你一个空窗口。
:::

## 改名、删除、合并

这些都在空间行的「⋯」菜单里：

| 操作 | 结果 |
| --- | --- |
| **重命名** | 只改名字，不动路径与磁盘文件 |
| **删除** | 只删这份「根清单 + 名字」，**不删任何文件、不删会话** |
| **合并工作空间…** | 选两个及以上，去重合成一个新的；原来的空间都还在 |
| **在新窗口打开** | 整组在新窗口打开 |

![空间行右侧的「⋯」菜单](/shots/guide/spaces-group-menu.png)

![合并工作空间：勾选两个及以上，名称可以另起](/shots/guide/spaces-merge.png)

「删除」和「从窗口移除」是两件事：前者删掉存下来的这个组合，后者只是把某个根从当前窗口暂时撤下。

## 空间级会话

一条对话可以属于某个工作空间，而不只是某个工作区：

- 在会话栏里把一条对话拖到顶部**「工作空间」组头**上 → 它变成**空间级**
- 它**仍然留在原来的工作区**，只是显示在空间组下；会话栏和欢迎屏「对话」页签里按「工作空间 → 工作区」两级收起
- 再拖回任意工作区组头，就退回成那个工作区的普通对话

适合「这组项目共同相关的事」：比如一条跨前后端梳理接口的对话，放在空间下比塞给某一个仓更合适。

::: tip 会话归属不会因为打开空间而改变
每条对话仍然只属于它创建时的那个工作区。打开一个空间只是同时把几个根摆进窗口，不会把历史对话搬来搬去。
:::

## 空间里的资源：三档范围

技能、连接器（MCP）、插件、专家附带的技能，都可以装在三个范围：

| 范围 | 谁能用 | 落在哪 |
| --- | --- | --- |
| **全局** | 所有窗口、所有空间 | `~/.notrat/` 下对应目录 |
| **工作空间** | 这个空间里的每个工作区根 | `~/.notrat/spaces/<空间 id>/` |
| **当前工作区** | 只认当前打开的那个根 | `<工作区>/.notrat/` |

优先级从近到远是「**当前工作区 > 工作空间 > 全局**」，同名的就近生效。

所以：一组项目共用的评审规范、这套系统专用的数据库连接器、只在内部项目里出现的插件，装到**工作空间**一次就够——换当前根不会消失，切到别的空间也不会串味。

已装的东西想换范围，用卡片 **⋯** 菜单里的「迁移到全局 / 迁移到工作空间 / 迁移到当前工作区」。详见 [扩展管理](/guide/extensions)。

## 在空间之间翻看

图谱左栏的「工作空间」那一行，在有多个已保存空间时**本身就是下拉**：第一行是当前打开的空间，下面是其它空间。

选别的空间是**只读预览**——不改当前打开的工作区、不动会话归属，画布右上角会挂一枚「预览」标记；选回第一行即恢复。这个选择只在本窗口有效，重启后回到当前空间。详见 [图谱](/guide/graph#按工作空间翻看)。

## AI 正在回复时切空间

如果当前窗口里 AI 还有一条回复在写，这时去打开别的工作区或工作空间，Notrat 会先拦一下，因为切换会把这条回复停在半路（已写出的部分会留在历史里，但不会继续写）。

弹窗给三个出口：

| 选项 | 含义 |
| --- | --- |
| **把「X」附加进来，对话不断** | 不动当前对话，把目标目录并进这个窗口；两个根一窗就是一个临时组合，AI 可以同时处理两边 |
| **仍然切换** | 明确结束那条回复，再切过去 |
| **取消** | 什么都不做 |

勾上「**不再提醒**」后，这台机器上以后切换就直接执行，不再弹这张卡；想恢复「每次都问」得清掉应用的本地数据（换台电脑默认也是每次都问）。附加出来的临时组合如果想长期用，切完之后等根数稳定，命名框会自己弹出来；错过了就点「最近」里那条「未保存」行。

## 这些数据存在哪

| 数据 | 位置 |
| --- | --- |
| 空间清单（名字、根列表、当前根） | 应用数据目录里的 `workspace-groups.json`。Windows 是 `%APPDATA%\Notrat\`，macOS 是 `~/Library/Application Support/Notrat/` |
| 空间级资源（技能 / 连接器 / 插件） | `~/.notrat/spaces/<空间 id>/` |
| 会话 | `~/.notrat/sessions/`，按工作区归档，不随空间走 |

::: warning 空间清单不跟着工作区走
空间清单存在应用数据目录里，**不在任何一个工作区的 `.notrat/` 里**——因为一个空间可能横跨好几个仓，它属于「这台机器上的 Notrat」，不属于其中某一个文件夹。

把工作区文件夹拷到另一台电脑，笔记和图片都在，但**空间要重新存一次**。空间级资源目录 `~/.notrat/spaces/<id>/` 想带走的话手动拷过去。
:::

## 写给插件作者

插件面板能拿到当前空间：`props.ctx.space`（不在空间里时为 `null`），服务器子进程能读 `NOTRAT_SPACE` / `NOTRAT_SPACE_ID` / `NOTRAT_SPACE_WORKSPACES`。字段表与注意事项见 [面板与界面扩展](/plugin-dev/panels) 和 [MCP 服务器](/plugin-dev/mcp-servers#标准环境变量)。

## 常见问题

**命名框为什么没弹出来？**
窗口里得有两个以上根，而且根的数量要稳定下来（约 1.5 秒内没再变化）。只有一个根时，它本身就是工作区，不需要再起名字；刚才点过「取消」的话，也要等下一次根数变化才会再问——不想等就直接点「最近」里那条「未保存」行。

**「合并工作空间…」为什么没出现？**
至少要已经存了两个空间。只有一个空间时没什么可合并的。

**打开空间后少了一个根？**
那个目录被删、被移走，或者所在盘没挂载。Notrat 会明确提示路径不存在，不会静默跳过。

**删除空间会删掉项目文件吗？**
不会。删除的只是「名字 + 根清单」，磁盘上的文件、`.notrat` 目录、历史会话都还在。

**工作空间和「附加到当前窗口」是什么关系？**
「附加」是临时的多根窗口，关掉就没了；给这组根起个名字（命名框或「未保存」行）才是把它记下来，下次一键开回。前者是动作，后者是存档。
