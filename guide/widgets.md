# 悬浮便签与桌面悬浮器

两个「不占主窗口位置」的小工具。

## 悬浮便签

活动栏底部的**「便签」**打开一个**独立的小窗口**——它能飘在别的应用上面。

![悬浮便签](/shots/guide/floating-note.png)

**最适合的场景**：看视频、开会、对着别的软件时，随手记一笔，不用切回 Notrat 主窗口。

### 怎么用

- 窗口可以拖到屏幕任何位置，**位置会被记住**
- 标题栏可以拖动
- 内容自动保存
- 关掉窗口，内容还在（下次打开接着写）

### 从桌面右键直接开

在 Windows 上，桌面空白处右键菜单里可以有一项「用 Notrat 记便签」，不用先进应用。

::: tip 这一项默认没有，要先去打开
**设置 → 通用** 里有一项「**桌面右键打开便签**」，点**添加到桌面右键**才会注册到系统里（不想用了点「移除」）。
:::

::: warning 点了它会拉起便签窗
桌面右键那一项拉起的是 Notrat 的**便签窗口**。Notrat 没在跑时，它会先启动应用，然后直接开这个窗（不会把主窗口抢到前面来）。
:::

::: tip 便签窗有自己的缩放
便签是一个独立窗口，它有自己的**页面缩放**设置。

这带来一个副作用：如果你在这个窗口里拖内容，**坐标是按缩放后的算的**——所以拖动类操作由主进程按实际显示尺寸换算，不会出现「鼠标在这、窗口跑那儿」的错位。
:::

## 桌面悬浮器

**悬浮器**是一个**悬浮球**——停在桌面上，点开有菜单。

它**不在活动栏**（活动栏里那个叫「便签」，是便签窗口）。三个入口：

- **托盘图标**菜单 →「🪐 悬浮器」
- 快捷键 `Ctrl+Alt+F`
- **设置 → 通用** 里的悬浮器卡片（显隐、透明度等）

![桌面悬浮器](/shots/guide/float-widget.png)

| 元素 | 说明 |
| --- | --- |
| 球 | 常驻的一个小圆点，可以拖到屏幕任意位置 |
| 菜单 | 点球展开，里面是常用动作 |

### 跟随主题

悬浮球与它的菜单颜色**跟随你的主题**——你换主题，它们跟着变。

::: warning 悬浮球为什么用了「带兜底值」的颜色
悬浮器是独立窗口，渲染时机与主窗口不同步。如果某个颜色 token 在主窗口还没就绪，球可能整个**隐形**。

所以球面与菜单用到的颜色都带了兜底值——取不到就用一个安全色，不会变成一个看不见的洞。
:::

### 全局只有一个球

悬浮器是**单例的全局窗口**——不管开几个主窗口，桌面上就只有这一个球，位置也只有一份（所以不存在「两个窗口的球位置不一样」这种事）。

会**实时同步**的是**插件状态**：你在主窗口里启用 / 停用 / 安装 / 迁移插件，悬浮器的菜单立刻跟着变，不用重开。
