# IM 插件（远程助手）

把你的聊天软件接进来，让 AI 在里面回话。

设置 → 远程助手。

![远程助手](/shots/guide/settings-gateway.png)

::: tip 术语
这个功能在 1.3.5 里叫 **IM 插件**，设置里的分类名是**远程助手**，活动栏那一格也是「远程」。

三个名字指同一件事。
:::

## 能接什么

| 平台 | 需要什么 |
| --- | --- |
| **微信**（个人号） | 手机扫码 |
| **飞书** | 去飞书开放平台申请，填两个值 |
| **企业微信** | 填两个值 |
| **QQ 机器人** | 填两个值 |
| **Discord** | 填一个值 |
| **Slack** | 填两个值 |

连接表单会按你选的平台，只问那个平台真正需要的东西，不会让你对着一堆看不懂的字段发懵。

![添加连接](/shots/guide/gateway-add-bot.png)

## 接上之后能干什么

| 场景 | 怎么做 |
| --- | --- |
| 在外面用手机问 Notrat | 给自己发条消息，AI 在微信里回你 |
| 让 AI 主动通知你 | 任务跑完发消息到你的 IM |
| 群里当助手 | 把机器人拉进群，@ 它 |

设置项里可以配：回答风格、是否自动发送、高级设置等。

## 「已连接」是什么意思

这是最容易误解的地方，界面上有两种状态，含义不同：

| 状态 | 含义 |
| --- | --- |
| **适配器已注册** | 这个平台的连接配置存在，但那只是本地的登记 |
| **真的连上了** | 凭据有效、能收发消息 |

::: warning 「已连接」必须是真的登录
Notrat 修过一个这样的问题：微信在没有凭据的情况下也能「启动成功」，界面上显示成已连接，实际上根本没连上，发消息没反应。

现在「已连接」的判定走的是真实登录状态。

**如果你看到已连接但消息发不进来：**

1. 先确认凭据/扫码是真的（微信重新扫一次）
2. 去看日志，远程助手的日志会写清楚连接过程
:::

## 定时任务

远程助手旁边（活动栏「定时」）是**定时任务**。它和 IM 无关，跑的是本机的定时引擎。

| 能定时跑什么 | 说明 |
| --- | --- |
| 提示词 | 到点让 AI 做一件事（总结今天的笔记、生成日报） |
| MCP 工具 | 到点调一个外部工具 |
| 脚本 | 到点跑本机命令 |

::: tip 为什么它单独占一格
原先它藏在「远程助手 → 设置 → 进阶」里面，没连聊天软件的用户根本不会往那儿找。

但它跟 IM 渠道没关系，所以单独放出来一格。
:::

定时任务配合 IM 插件是最实用的组合：到点让 AI 干活，干完把结果发到你微信。

## 故障排查

| 现象 | 先看这里 |
| --- | --- |
| 显示已连接但收不到消息 | 上面的「已连接」一节 |
| 手机扫码后没反应 | 重新扫码；检查是否用了需要代理的网络 |
| 需要代理才能访问的平台 | 见下 |

::: warning 代理相关的坑（WhatsApp 一类）
有些平台的接入依赖外部服务的连通性，这里出过几个典型问题：

- WebSocket 不认系统的代理环境变量，配了代理也可能不走
- 版本探测失败会静默退回内置的旧版本，表现为「连上了但接口报错」
- 日志里「地址解析成功」不等于「代理可用」

如果你在用这类平台，遇到连不上时把这几条考虑进去。
:::

## 日志

远程助手的连接过程有实时日志：

- 面板里的日志抽屉
- 文件：应用数据目录下的日志目录
- 命令行：`yarn log`（Notrat 的日志工具，支持 `--json`）

详见 [调试与日志](/plugin-dev/debug)。

## 对外接口（A2A 服务）

远程助手里还有一块 **A2A 服务**，让其他程序来调用 Notrat。

::: warning 这是专业版功能
A2A 服务的入口在 **设置 → 开发者 → 第四个板块页签**（1.3.5 从左栏搬过去的），门槛是专业版。

「让别的程序调用我」属于对外接口，配置需要理解网络与鉴权，所以没有放在新手容易误点的地方。
:::
