# 快捷键

这一页是 Notrat 内置快捷键的**完整清单**（共 59 条），直接来自应用的快捷键定义表，不是手抄的。

::: tip `Ctrl` 在 macOS 上是 `Cmd`
表里的 `Ctrl` 在 macOS 上一律对应 `⌘`。
:::

## 编辑器：Markdown 格式（27 条）

最常用的一组。选中文字按，或者在空行直接按。

### 列表

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+[` | 有序列表 |
| `Ctrl+Shift+]` | 无序列表 |
| `Ctrl+Shift+X` | 任务列表 |
| `Tab` | 列表缩进（光标在列表中时） |
| `Shift+Tab` | 减少缩进 |

::: tip 列表这两个键反直觉，记一下
`[` 是**有序**列表、`]` 是**无序**列表，和很多编辑器的习惯相反。

记不住就输入 `/列表` 从菜单里选。
:::

## 编辑器：模式与编辑（11 条）

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+/` | 切换编辑 / 源码模式（工具栏 `?` 菜单里露出的就是它） |
| `Ctrl+S` | 保存文件 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |
| `Ctrl+F` | 查找 |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+X` / `Ctrl+A` | 复制 / 粘贴 / 剪切 / 全选 |
| `↑` | 恢复上一条历史消息（输入框为空或光标在开头时） |
| `↓` | 向新方向翻看历史消息（光标在末尾时） |

::: tip 源码模式目前只有一个键
`Ctrl+/`（工具栏 `?` 里露出的那个），或者点标题栏的「编辑 | 源码」开关。

定义表里还登记着 `Ctrl+Shift+M`、`Ctrl+E` 两个候选键，但**没有接上**，`Ctrl+E` 实际是「行内代码」（见上一节）。
:::

## 导航（2 条）

| 快捷键 | 作用 |
| --- | --- |
| `←` | 上一个分支（侧边栏聚焦时） |
| `→` | 下一个分支（侧边栏聚焦时） |

::: warning 定义表里有、但没接上的键
下面这几个键在应用的快捷键定义表里存在，但**没有绑定到原定功能**，按了不会打开那个功能（有的会执行别的动作）：

| 快捷键 | 定义表里写的 | 实际按下会怎样 |
| --- | --- | --- |
| `Ctrl+I` | 切换预览模式 | 切换**斜体**（见上一节） |
| `Ctrl+P` | 快速打开文件 | 变回**正文段落** |
| `Ctrl+,` | 打开设置 | 无反应（设置点左下角的齿轮） |
| `Ctrl+Q` | 退出应用 | 无反应 |

写在这里是为了让你别在按了没反应之后怀疑自己。用界面上的按钮就行。
:::

## 在应用里查

不想翻文档时，在应用里两个地方能看：

1. 编辑器工具栏最右边的 **`?`**：展开当前可用的编辑操作与快捷键
2. 活动栏 **帮助** → **快捷键** 页签：完整的分类清单

::: tip 快捷键分类 1.3.5 退出设置左栏
原来「设置 → 快捷键」这一项已经不在左栏了。

页面本身没删，从活动栏「帮助」面板的**快捷键**页签进，是同一个组件。
:::
