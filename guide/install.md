# 安装与首次启动

从下载到看着欢迎屏亮起来，大约 5 分钟。

## 系统要求

| 平台 | 版本 | 安装包格式 |
| --- | --- | --- |
| Windows | Windows 10 及以上（64 位） | `.exe`（NSIS 安装程序） |
| macOS | macOS 11 及以上 | `.dmg`（推荐）/ `.zip` |
| Linux | 主流发行版（x86_64） | `.AppImage`（推荐）/ `.deb` / `.rpm` / `.tar.gz` |
| 鸿蒙（HarmonyOS NEXT） | HarmonyOS 5.0.3(15) 及以上 · 手机 / 平板 / 2in1 | `.hap`（需要在电脑上用 `hdc` 安装，见下） |

内存建议 8 GB 起步；如果你打算跑**本地模型**（Ollama / LM Studio），按那个模型本身的要求另算。

## 下载

打开官网 **`notrat.cn`**，页面上的下载区会自动识别你的操作系统，直接给出对应安装包。

![官网下载区](/shots/guide/install-download.png)

- **Windows**：下载 `.exe` 直接双击。
- **macOS**：`.dmg` 拖进「应用程序」；`.zip` 解压后同样是拖进「应用程序」。
- **Linux**：默认给 AppImage，可以在平台标签下切成 deb / rpm。
- **鸿蒙（HarmonyOS NEXT）**：给的是 `.hap`。**它不能像桌面版那样双击安装**，需要一台电脑用 `hdc` 装进去，见下。

::: tip 下哪个版本？
下载区列的是**最新稳定版**。如果你在别人的教程里看到某个功能而自己这版没有，先去 [更新记录](/changelog/) 对一下那个功能是哪个版本引入的。
:::

## 安装

### Windows

双击 `.exe` 走安装向导（不是一键装，中途可以改安装位置）。

Windows 版默认是 **per-machine 安装**：装进 `Program Files`，会弹 UAC 要管理员权限。

::: warning 关于 UAC
- **安装时**：默认路径在 `Program Files` 下，所以要管理员权限
- **更新时**：per-machine 安装的自动更新会再弹一次 UAC，这是 Windows 的限制，不是 bug

想避开：在安装向导里把目录改到当前用户目录（比如 `%LOCALAPPDATA%\Programs\Notrat`），就是 per-user 安装，之后更新不会再弹。
:::

首次运行 Windows 可能弹「Windows 已保护你的电脑」（SmartScreen）。点「更多信息」→「仍要运行」。这是因为安装包刚发布、信誉还没攒够，与文件安全性无关。

### macOS

打开 `.dmg`，把 Notrat 拖进「应用程序」。

::: warning 首次打开被拦下
未签名的版本会被 Gatekeeper 拦下，提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」。

处理方式：在「访达」里**右键** Notrat → 「打开」→ 再点一次「打开」。以后就不会再拦了。（直接双击不行，必须是右键菜单里的那个「打开」。）

如果这台 Mac 是 Apple 芯片，别用「终端里 `xattr` 曲线救国」那类偏方，直接用上面的右键方式。
:::

::: details 为什么 macOS 上偶尔会弹「notrat 想要使用您存储在钥匙串中的机密信息」？
Notrat 用系统钥匙串给**登录令牌**（以及技能里存的密钥）做加密落盘，这本该由系统信任的开发者签名担保。未签名/未公证的版本每次都算「不认识的应用」，系统就要问你一遍。

- **不想每次输密码**：在弹窗里选「始终允许」，输入一次系统密码即可。
- **拒绝了会怎样**：加密写不进去，Notrat 会退回弱加密（base64）把令牌存下来，功能不受影响，安全性降低。

设置里的各家 API Key 不走这条路径（它们只存在本机应用数据里），所以这个弹窗与你的 API Key 无关。

正式解决要靠苹果开发者签名与公证，那是发布流程的事，不是你这边的配置问题。
:::

### Linux

**AppImage（推荐，免安装）**

```bash
# 文件名里的版本号以你实际下载到的为准
chmod +x Notrat-<版本>-x86_64.AppImage
./Notrat-<版本>-x86_64.AppImage
```

**deb / rpm**

```bash
# Debian / Ubuntu
sudo dpkg -i notrat_<版本>_amd64.deb

# Fedora / RHEL
sudo rpm -i notrat-<版本>_x86_64.rpm
```

::: tip
部分桌面环境（GNOME + Wayland）下 AppImage 需要额外装 `libfuse2` 才能运行：

```bash
sudo apt install libfuse2
```
:::

### 鸿蒙（HarmonyOS NEXT）

鸿蒙上没有「未知来源安装」这个开关。把 `.hap` 下载到手机上、在文件管理里点它，**不会有任何反应**——安装必须由电脑上的命令行工具 `hdc` 完成。

所以这一步比桌面版麻烦，它本质上是开发者安装，不是「装个软件」那类操作。

::: warning 先确认这条路适合你
接下来要开开发者模式、在电脑上装命令行工具、敲三条命令，任何一步没做包都装不上。如果你只是想先在手机上试试，建议用 Windows / macOS / Linux 版；鸿蒙版是窄版本，功能比桌面版少，而且没有自动更新。
:::

**第一步：设备开开发者模式**

1. 设置 → 关于本机 → 连续点击「版本号」7 次（部分机型叫「软件版本」），按提示输入锁屏密码
2. 回设置 → 系统 → **开发者选项** → 打开「USB 调试」

**第二步：电脑上拿到 hdc**

`hdc` 是鸿蒙的设备调试命令行，随 SDK 一起发，不单独下载：

- 装过 DevEco Studio：在 `sdk/default/openharmony/toolchains/hdc`（Windows 是 `hdc.exe`）
- 没装过：从华为开发者官网下载 **Command Line Tools**，解压后同样在 `toolchains/` 下

把 `toolchains/` 加进 PATH，或者在终端里用完整路径调用。

**第三步：连上并安装**

用 USB 线把设备连到电脑。手机第一次会弹「是否允许调试」，点**允许**（勾上「始终允许」就不用每次都点）。然后在电脑终端里：

```bash
hdc list targets
# 有输出（一串设备序列号）= 连上了；输出 [Empty] = 没连上

hdc app install -r notrat-<版本>-arm64.hap
# -r 是覆盖安装，以后升级也用这一条

hdc shell aa start -a EntryAbility -b cn.notrat.hmos
```

前两步在 `Notrat-<版本>-arm64.hap` 所在目录执行，或者把路径换成绝对路径。

::: details 在鸿蒙 PC（2in1）上装
鸿蒙 PC 本身就是那台「电脑」，不用再另找机器。本机开了开发者模式、本机也装了 `hdc` 时，`hdc list targets` 会把**本机自己**列出来（形如 `127.0.0.1:34953`），后面的安装命令与上面一字不差。

本机没有 `hdc`，就照上面的做法用另一台电脑通过 USB 连过来装。

另外注意：鸿蒙 PC 上装的是这个 `.hap`，桌面版的 `.exe` / `.dmg` / `.AppImage` 在鸿蒙上装不了。
:::

::: details ▶ 视频版：用图形工具装（社区方法，非官方）
有社区工具把上面这套包成了图形界面——「小白调试助手」（Auto-Installer），拖进 `.hap`、连上设备就能装，不想碰命令行可以看这个视频（演示的是鸿蒙电脑；手机、平板一样，用另一台电脑跑它）：

<div class="video-embed"><iframe src="https://player.bilibili.com/player.html?bvid=BV1m6TizjEKt&page=1&danmaku=0" scrolling="no" frameborder="no" allowfullscreen="true" loading="lazy"></iframe></div>

视频打不开就看 [哔哩哔哩原页](https://www.bilibili.com/video/BV1m6TizjEKt/)。注意两点：它是**闭源**的第三方工具，而且自带证书、**会把安装包重签成它自己的签名**——所以用它装的和照本文命令装的不算同一个应用，换方法前请先卸载干净（本地数据会丢）。介意就走上面的命令行，效果一样。
:::

::: details 不想插线：无线调试
开发者选项 → 无线调试 → 打开，设备上会给出 IP 和端口，电脑端 `hdc tconn <IP>:<端口>` 连上之后，装包命令与插线时完全一样。
:::

::: details 装不上？先对一下现象

| 现象 | 原因与处理 |
| --- | --- |
| `hdc list targets` 输出 `[Empty]` | USB 调试没开；数据线只供电不传数据；或手机上的授权弹窗没点「允许」 |
| `hdc: command not found` | `toolchains/` 没进 PATH，用完整路径调用 |
| 安装报 `9568297` | 设备系统版本低于 5.0.3(15)——先把系统升级，再装 |
| 安装报 `9568289` | 包的签名或受限权限与设备策略不符——重新下载官网的完整包，别用被改过名/改过的文件 |
| 传到一半失败、超时 | 换根数据线或换个 USB 口，尽量别走 USB 集线器 |
| 空间不足 | `.hap` 本身约 400 MB，安装后还要再占一份，设备至少留 2 GB |
| 装上了但白屏 | 鸿蒙版仍在适配中，先看 [常见问题](/guide/faq) |
:::

**更新和卸载**

- **没有自动更新**：鸿蒙版不走应用市场，也就没有桌面版那套后台下载安装。有新版本时回官网下新的 `.hap`，`hdc app install -r` 覆盖安装，设置和数据都保留。
- **卸载**：桌面长按图标 → 卸载；或 `hdc shell bm uninstall -n cn.notrat.hmos`。

::: tip 为什么鸿蒙版要这么装
正常的途径是把应用上架华为应用市场，由市场负责安装、更新和用户授权。Notrat 目前没有上架鸿蒙市场，所以只能走开发者安装这条路——这也是下载区把鸿蒙排在最后、不主动推荐的原因。
:::

## 第一次启动

启动时会先看到一个**封面**：品牌标记呼吸、进度条推进、下面一行字说明正在做什么。

![启动封面](/shots/guide/boot-cover.png)

这一步在加载界面与检查设置，通常几秒。它从第 15 秒起会自己复查一次，60 秒还没加载出来就会给出失败提示（建议重启 Notrat）。真到这一步，重启一次通常就好。

::: tip 初始字号会按你的屏幕自动选档
Notrat 建窗时按屏幕工作区宽度算一档默认缩放（小屏笔记本不会再把 14px 正文放大成 17px 左右）。之后用 `Ctrl` + `+` / `-` 调的是整个窗口；`Ctrl+0` 回到「当前屏幕的默认档」，不是固定 100%。
:::

启动完成后是**欢迎屏**。

![欢迎屏](/shots/guide/welcome.png)

欢迎屏上有四样东西：

| 位置 | 是什么 |
| --- | --- |
| 上方左 | Notrat 标志 |
| 上方右 | 问候语 + 一句标语。问候语按早上 / 中午 / 下午 / 晚上变化；标语每次启动从「当前时段的 4 句 + 1 句品牌句」里抽一句 |
| 中间 | **「最近」与「对话」两个页签**。「最近」把工作区和工作空间混排在同一条时间轴上（层叠图标区分，当前那个打「当前」徽章），最多 50 条、首屏 10 条，往下滚自动加载更多；「对话」一行一条，每个工作区最多三条 |
| 下方 | 输入框，不打开任何文件也能直接问 AI |

欢迎屏最下面还有一条文字链：「📖 第一次用？5 分钟写出第一篇」，点开直达这一册的入门教程。还没打开工作区的首页上也常驻同一条入口。

## 你的数据存在哪

Notrat 有两类数据，位置完全不同：

**① 你写的文件**：在你自己选的工作区文件夹里，永远是普通 Markdown 文件。

```
你选的任意文件夹/
├── 笔记.md
├── 会议记录/
└── .notrat/          ← Notrat 的工作区元数据（图片、索引等）
```

::: warning 备份就是拷贝这个文件夹
把工作区文件夹拷到 U 盘或网盘，你的笔记就备份好了，不依赖 Notrat，不依赖任何服务器。
:::

**② 应用数据**：分两个地方，别找错。

| 位置 | 里面是什么 |
| --- | --- |
| **用户主目录下的 `.notrat/`**（Windows 即 `C:\Users\<你>\.notrat`） | `settings.json`（你的设置）、`plugins/`（全局插件）、`logs/`（日志）、`sessions/`（对话记录） |
| **系统应用数据目录**（Windows `%APPDATA%\notrat`，macOS `~/Library/Application Support/notrat`，Linux `~/.config/notrat`） | 界面本地状态（含登录凭据的加密存储、你在设置里填的各家 API Key） |

卸载应用不会自动删这两处，想彻底清干净，手动删掉它们（笔记文件夹不在此列，永远不受影响）。

## 更新

Notrat 启动时会自己检查有没有新版本（启动后几秒，静默进行）。发现新版本后会在**后台自动下载并显示百分比**，不打断你手上的写作；下载校验完成后，你点「重启并安装」才真正替换。

- **手动检查 / 安装**：设置 → 通用 → **软件更新**。它和用户中心顶部的「检查更新」是同一套：检查 → 后台下载 → 进度 → 「重启并安装」
- **安装过程看得见**：应用内先显示安装状态，安装器窗口接着显示真实的文件替换进度；装好会自动重新打开 Notrat（Windows 需要管理员权限时会提示一次）
- **强制更新**：极少数情况下（安全修复、后端协议不兼容），某个版本会被标记为必须更新。此时应用会盖一层不可关闭的全屏提示，列出更新说明并自动下载；下载失败或安装包缺失时会给出安装器直链
- **每个版本改了什么**：[版本更新记录](/changelog/)

状态栏右侧的版本号只是显示，点它没有反应；更新入口在设置里。

::: tip 更新会保留什么
设置、API Key、插件、最近工作区列表全部保留。唯有工作区索引会在必要时重建（大工作区第一次打开会稍慢）。
:::

## 卸载

- **Windows**：设置 → 应用 → Notrat → 卸载
- **macOS**：从「应用程序」拖到废纸篓
- **Linux**：`sudo apt remove notrat` / `sudo rpm -e notrat`（AppImage 直接删文件）
- **鸿蒙**：桌面长按图标 → 卸载；或电脑上 `hdc shell bm uninstall -n cn.notrat.hmos`

卸载后如果还想彻底清干净，按上表删掉应用数据目录。你的笔记文件夹不受影响，一直都在。
