# 导出与分享

活动栏底部的**「导出」**把文档变成能给别人的东西。

![导出](/shots/guide/export.png)

::: tip 1.3.5 起导出不再占设置左栏
导出的配置页原本是设置里的一个分类。1.3.5 从设置左栏撤掉了，入口统一走活动栏的「导出」按钮。

页面本身没删，点活动栏那个按钮就是拉起它。
:::

## 导出范围

三种粒度：

| 范围 | 说明 |
| --- | --- |
| **当前文件** | 只导你正在编辑的这一篇 |
| **选择文件** | 勾几个文件，一次导出 |
| **目录批量** | 指一个目录，把它里面的文档批量导出 |

## 导出格式

| 格式 | 适合 |
| --- | --- |
| **HTML** | 网页格式：保留排版，能直接在浏览器打开、能发给人 |
| **PDF** | 打印 / 分享：版式固定，任何设备打开都一样 |
| **DOCX** | Word 文档：要交给还在用 Word 的人改时 |

![导出格式](/shots/guide/export-formats.png)

## 图片会跟着走

这是导出最容易出错的地方：文档里的本地图片能不能一起带出去。

Notrat 的处理方式是把本地图片**内联**进导出产物，图片引用会解析成实际内容嵌进去，而不是留一个指向你磁盘的路径。所以导出的文件发给别人，对方能看到图，不需要你把图片一起发过去，也不需要对方机器上有同样的目录结构。

| 格式 | 本地图片 | 远程图片（`http(s)://`） |
| --- | --- | --- |
| **HTML** | 内联，自包含 | 保留原链接（对方要联网） |
| **PDF** | 内联 | 保留原链接 |
| **DOCX** | 内联，按你调过的大小嵌入 | 跳过（Word 文档不能直接嵌外链图） |

::: tip 1.3.6 起 DOCX 不再是纯文本
Word 导出现在按结构还原：标题、粗斜体、列表、表格、代码块、引用都在，图片也会嵌进去（png / jpg / gif / bmp，webp 会先转成 png）。

你在编辑器里拖过的图片大小也会带过去——本地图片先内联，再按文档里的 `width` / `height` 嵌入；没设过大小的按原图尺寸，超过版心宽度时等比缩小。
:::

## 导出的文件在哪

导出会问你存到哪，不会偷偷写到某个目录。通常建议：

- **HTML / PDF** → 桌面或工作区外的临时目录（它们是一次性产物）
- 想长期保留的 → 建一个 `导出/` 目录

::: warning 导出的产物不会自动更新
导出是一次性快照。你在 Notrat 里改了文档，之前导出的那份不会跟着变，要重新导一次。
:::

## 分享的几种做法

| 你想 | 建议 |
| --- | --- |
| 发给同事看（要排版） | 导 **PDF** |
| 发到网页 / 公众号 | 导 **HTML** |
| 给别人继续改 | 导 **DOCX**（本地图片会带上；远程图片不嵌） |
| 对方也在用 Notrat | 直接把 `.md` 文件发过去 |
| 全工作区带图带走 | 直接拷整个工作区文件夹 |
