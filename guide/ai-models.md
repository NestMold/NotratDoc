# 模型与参数

配好服务商之后，你要回答两个问题：**用哪个模型**、**它该多保守**。

## 换模型

对话输入框工具条**最左端**（输入框左下角）就是模型选择器，点开直接换：

![模型选择器](/shots/guide/model-selector.png)

列表来自你配好的服务商。切换**只影响之后的对话**，已经聊过的部分不受影响。

下拉右上角有个 ↻，用来**重读配置**：如果你在别处改过服务商配置（比如让 AI 帮你加了一家、或在另一个窗口里改的），而这里的列表还是旧的，点一下 ↻ 就跟着更新——不用重启应用，也不用绕去设置面板。

列表里每个模型会标出它的特点：

| 标记 | 含义 |
| --- | --- |
| 上下文长度 | 一次能记住多少内容 |
| 推理 / 思考 | 支持深度思考，回答更慢但更准 |
| 识图 | 能看图片 |

::: tip 也可以按对话单独设
不同的对话可以挂不同的模型，让一个用快模型批量改写，另一个用强模型做架构设计。

对话内的选择不会改掉全局默认。
:::

## 参数

参数在 设置 → AI 模型配置的**「回答风格」**卡里，全局一份，不管你配了几家服务商，这组值大家共用：

| 参数 | 管什么 |
| --- | --- |
| **随机度（Temperature）** | 越高越发散，越低越稳 |
| **回复长度上限（Max Tokens）** | 单次回答最多生成多少 |

### 四档预设

不想自己调数字，选一个预设：

| 预设 | 随机度 | 长度上限 | 适合 |
| --- | --- | --- | --- |
| **有创意 Creative** | 0.9 | 4096 | 创作、头脑风暴，要它敢想 |
| **均衡 Balanced** | 0.7 | 4096 | 默认推荐，准确与灵活之间 |
| **精准 Precise** | 0.3 | 8192 | 代码、技术文档，要它别乱发挥 |
| **快速 Fast** | 0.5 | 1024 | 快问快答 |

### 自定义模式

预设不够用时切到**自定义模式**，直接填温度和长度。

::: tip 长度上限对已知模型是「跟随规格表」
对于 Notrat 认识的主流模型，长度上限会跟随该模型自己的规格，不用你操心。

预设里的数字只是**未知模型**的回落值。
:::

### 按模型单独覆盖

全局参数之外，你可以给**某个具体模型**单独设一份。比如让做架构的那个模型用精准档，日常问答的模型用创意档。

覆盖是按模型 ID 挂的，所以换个服务商只要模型同名，覆盖照样生效。

## 推理等级

支持思考的模型会多出一个**推理等级**（或「思考」开关）：

![推理等级](/shots/guide/model-reasoning.png)

- 档位越高，模型想得越久，回答越准，也越慢越贵
- 日常问答用低档，架构设计、复杂排错用高档

对话里也能看到模型的**思考过程**，它想什么会展示出来，可以折叠。

::: tip 想让它别想
有些场景（改写、翻译、格式转换）根本不需要思考，开高档纯属浪费。调到最低档。
:::

## 怎么选

按活选，不按排行榜选：

| 你要干的活 | 建议 |
| --- | --- |
| 长文写作、结构梳理 | 长上下文 + 平衡档 |
| 代码、配置、技术文档 | 精准档 + 代码特化模型 |
| 头脑风暴、起名字、想标题 | 创意档 |
| 快速改写、翻译、格式转换 | 快模型 + 快速档 |
| 让它改你的文件、跑多步任务 | 强模型 + 高推理档（Agent 类任务吃能力） |

::: tip 省钱的实用做法
**同一次会话里换模型**是允许的。一个常见路数：

1. 用强模型做规划和关键判断
2. 切到便宜的快模型做批量改写

Notrat 不做用量限制，花的是你自己账号的额度，怎么切由你。
:::

## 用量

想知道自己用了多少，看 设置 → **模型用量统计**（基础版起可用）。
