# 五分钟写出第一篇

这篇不解释原理，只带你走一遍最短路径：**打开工作区 → 建文件 → 写字 → 让 AI 帮一手**。

全程五个动作，每个动作不超过一分钟。

## 第 1 分钟 · 打开一个工作区

「工作区」就是你要放笔记的那个文件夹。Notrat 不建自己的库、不用专有格式——它只是打开一个你已有的文件夹。

点**顶部标题栏左侧的工作区菜单按钮**：

![工作区菜单按钮](/shots/guide/workspace-menu-button.png)

在弹出的菜单里选**「打开工作区」**：

![工作区菜单](/shots/guide/workspace-menu.png)

- 想用现成的文件夹（比如「我的文档 / 笔记」）→ 选「打开工作区」，挑那个文件夹
- 想从零开始 → 选「新建工作区」，输入名字，Notrat 会建好文件夹并打开

打开后，左边会出现**文件树**，里面是这个文件夹里的所有文件。

![打开后的工作台](/shots/guide/workspace-overview.png)

::: tip 标题栏那个按钮会记住你
下次启动，Notrat 会自动打开上次的工作区；欢迎屏的「最近工作区」列表也会列出来（最多 50 条）。
:::

## 第 2 分钟 · 新建一个 Markdown

在左侧文件树里，把鼠标移到任意文件夹上，点出现的 **`＋`** 按钮：

![文件树的加号](/shots/guide/filetree-new.png)

菜单里选 **「Markdown」**：

![新建菜单](/shots/guide/filetree-new-menu.png)

输入文件名（比如 `我的第一篇.md`），回车。

文件建好并且自动打开了，光标已经在正文里等着你。

::: tip 也可以不建文件
欢迎屏下面那个输入框，或者右侧边栏的对话框，不打开任何文件也能直接问 AI。想让 AI 把答案**写进文件**时，才需要先有文件。
:::

## 第 3 分钟 · 写下第一个字

直接打字就行。Notrat 默认是**所见即所得**模式——你打 `#` 出来的就是标题的样子，不是符号本身。

![编辑器](/shots/guide/editor.png)

几个马上用得上的：

| 想做什么 | 怎么做 |
| --- | --- |
| 一级标题 | 行首输入 `# ` 再打空格，或者用工具栏的「标题」下拉 |
| 加粗 | 选中文字按 `Ctrl+B` |
| 斜体 | `Ctrl+I` |
| 列表 | `Ctrl+Shift+[`（无序）/ `Ctrl+Shift+]`（有序） |
| 任务清单 | `Ctrl+Shift+X` |
| 引用 | `Ctrl+Shift+Q` |
| 撤销 | `Ctrl+Z` |

完整的看 [快捷键](/guide/shortcuts)。

::: tip 忘了快捷键？
输入 **`/`** 会呼出**斜杠命令菜单**——所有能插入的东西都在里面，打字筛选。这是最不用记的入口。

![斜杠命令菜单](/shots/guide/slash-menu.png)
:::

写完了，`Ctrl+S` 保存（其实 Notrat 会自动保存，这个键是给你安心的）。

## 第 4 分钟 · 让 AI 看见这篇文件

先确认 AI 能说话——如果还没配过，去 [接入 AI 服务商](/guide/ai-setup) 加一个（选云端服务商 + 贴 API Key，两分钟）。

然后打开右侧的 **AI 对话**。有三种打开方式，挑顺手的：

- 点**右侧边栏**顶部
- 编辑器工具栏上的对话按钮
- 选中一段文字后右键 → 让 AI 处理

![AI 对话侧栏](/shots/guide/chat-panel.png)

现在做一件最有用的事：**把当前文件给 AI 看**。

在对话输入框里输入你的问题，比如：

```
帮我看看这篇的结构有没有问题，给出三条改进建议
```

输入框上方会自动带上**当前打开的文件**作为上下文。发送后，AI 的回答里如果提到要改哪里，你可以直接让它动手——它能真正改文件，改动会在对话里显示成 diff。

::: warning AI 改文件前会问你
默认情况下，AI 对文件的写操作需要你确认。你会看到一个带改动的确认卡片，点允许它才动。这个开关在 设置 → 权限 里，不要关着玩。
:::

## 第 5 分钟 · 试一次全屏的搭档模式

侧栏那块地方小。想认真跟 AI 干一段活时，用**搭档模式**：

点左侧活动栏的**「搭档」**：

![活动栏](/shots/guide/activity-bar.png)

界面会变成全屏的对话工作区——左边是你的文件与内容，右边是 AI，中间是它正在做的事（改哪个文件、跑什么命令、进度到哪）。

![搭档模式](/shots/guide/partner-mode.png)

再点一次「搭档」就切回工作台。

::: tip 工作台 vs 搭档模式
- **工作台**（活动栏第一格）：文件树 + 编辑器 + 右侧 AI 侧栏。日常写作、改文件用这个。
- **搭档模式**：整屏都交给 AI 协作。让它一次改多个文件、写代码、做调研时用这个。

两者看到的是**同一个工作区**，随时切换不丢状态。
:::
