# 界面总览

Notrat 的主界面分成五块，每一块的职责都很清楚。认清这五块，你就能在任何页面里判断「我现在在哪、想去的那个东西应该去哪找」。

![界面总览](/shots/guide/interface-overview.png)

## 五块区域

```
┌──────────────────────────────────────────────────────────────┐
│ ① 标题栏   工作区菜单 · 窗口控制 · 新手任务                    │
├────┬─────────────────────────────┬───────────────────────────┤
│ ②  │ ③ 主区域                     │ ④ 右侧边栏                 │
│ 活 │   文件树 / 编辑器 /          │   搭档（AI 对话）          │
│ 动 │   图谱 / 终端 / ...          │   或 时间线 / 改动         │
│ 栏 │                             │                           │
├────┴─────────────────────────────┴───────────────────────────┤
│ ⑤ 状态栏   字数 · 路径 · 插件箱 · 行列 · 编码 · 版本            │
└──────────────────────────────────────────────────────────────┘
```

### ① 标题栏

![标题栏](/shots/guide/titlebar.png)

| 元素 | 作用 |
| --- | --- |
| Notrat 标志 | — |
| **工作区菜单** | 打开 / 新建 / 切换 / 关闭工作区（[详见](/guide/workspace)） |
| 窗口控制 | 最小化 / 最大化 / 关闭 |
| **新手任务 N/7** | 上手清单的进度，点开看还差哪几项 |
| 编辑器右侧的 **编辑 / 源码** | 编辑器的两种模式（[详见](/guide/editor)） |

### ② 活动栏

最左边那一竖列，是**导航**——每一格切一个界面。

![活动栏](/shots/guide/activity-bar.png)

按钮下方带**可见文字**（4 个字以内），不用悬停猜图标。悬停有完整名称的提示。

### ③ 主区域

当前那一格对应的工作区。可能是文件树 + 编辑器，也可能是图谱、终端、扩展市场。

### ④ 右侧边栏

工作台模式下，右侧是**搭档**——AI 对话。同时它也能切到**时间线 / 改动**两个页签（[详见](/guide/chat)）。

拖左边缘可以调宽度。

### ⑤ 状态栏

最下面一行。字数、路径、编码、行列、版本——写作时通常只瞟一眼字数。

## 活动栏上有什么

活动栏是**全量可配置**的：哪些按钮显示、什么顺序，都由你定（[详见](/guide/panels)）。

出厂顺序是这样：

| 按钮 | 切到哪 |
| --- | --- |
| **工作台** | 文件树 + 编辑器 + 右侧搭档（日常待最久的地方） |
| **搭档** | 全屏的 AI 协作模式 |
| **远程** | 远程助手（微信 / 飞书等 IM 接入） |
| **定时** | 定时任务 |
| **自进化** | 自进化实验室 |
| **图谱** | 工作区的关系图谱 |
| **扩展** | 扩展市场（技能 / 连接器 / 专家 / 插件四个货架） |
| **帮助** | 常用功能帮助（含快捷键、日志等页签） |
| **终端** | 内置终端 |
| ─── 分隔 ─── | 下面这组固定在底部，不会被挤走 |
| **导出** | 导出当前文档 |
| **便签** | 悬浮便签 |
| **公告** | 公告铃铛（有新公告会有红点） |
| **登录 / 头像** | 未登录时是「登录」文字入口，登录后是头像 |
| **设置** | 设置页 |

::: tip 分隔线上下的区别
分隔线**上面**是「导航组」——窗口变窄装不下时，多出来的会被折进「更多」菜单。

分隔线**下面**是「身份区」——永不折叠、永不被顶出屏幕。

所以「设置」和「登录」永远够得着，不管窗口多小。
:::

::: tip 插件也能往活动栏加按钮
装了插件之后，活动栏上可能多出按钮（比如示例插件的「🕸️ Flow 节点画布」）。

它们的显示与排序和内置按钮一样可配。
:::

## 窗口能有多小

Notrat 是「窄到一定程度就不该再窄」的应用——窗口有**系统级的最小尺寸**约束，不会缩成一条缝。

窗口拉窄后，各部分自己让位：

| 部分 | 让位方式 |
| --- | --- |
| 活动栏 | 装不下的导航按钮折进「更多」 |
| 状态栏 | 只有中间的文件路径会缩短，文件名永远保留 |
| 对话工具条 | 装不下的按钮折进溢出菜单 |

## 来路与去向

界面里出现**外部链接**时（公告里的链接、插件面板里的 URL），Notrat 不会把整个窗口跳走——它会在内置浏览器标签里打开，或者交给系统默认浏览器。你随时能返回。

## 三种「场」

同一个应用，界面会随你干的事变形。认清这三种，不会迷路：

| 场 | 长什么样 | 什么时候 |
| --- | --- | --- |
| **欢迎屏** | 没有工作区时的首页：问候语 + 最近工作区 + 输入框 | 刚启动、或关闭了工作区 |
| **工作台** | 文件树 + 编辑器 + 右侧搭档 | 日常写作、改文件 |
| **搭档模式** | 整屏对话，左右分栏 | 让 AI 一次干一票大的 |

三者之间随时互切，状态都不丢。
