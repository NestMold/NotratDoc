# 界面总览

Notrat 的主界面分成五块。认清这五块，你就能在任何页面里判断「我现在在哪、想去的那个东西应该去哪找」。

![界面总览](/shots/guide/interface-overview.png)

## 五块区域

```
┌──────────────────────────────────────────────────────────────┐
│ ① 标题栏   Notrat · 工作空间名 · 工作区菜单 · 窗口控制          │
├────┬─────────────────────────────┬───────────────────────────┤
│ ②  │ ③ 主区域                     │ ④ 右区                     │
│ 活 │   文件树 / 编辑器 /          │   AI 对话 + 会话栏         │
│ 动 │   图谱 / 设置 / ...          │   或 插件页                │
│ 栏 │                             │                           │
├────┴─────────────────────────────┴───────────────────────────┤
│ ⑤ 状态栏   终端 · 字数 · 路径 · 行列 · 编码 · 版本 · AI 对话     │
└──────────────────────────────────────────────────────────────┘
```

### ① 标题栏

![标题栏](/shots/guide/titlebar.png)

| 元素 | 作用 |
| --- | --- |
| Notrat 标志 | 下面一行写着当前**工作空间**的名字（没起名时用各根目录名拼起来） |
| **工作区菜单** | 打开 / 新建 / 附加 / 关闭工作区，最近打开，以及工作空间的保存、合并、全部工作空间（[工作区](/guide/workspace) · [工作空间](/guide/spaces)） |
| 窗口控制 | 最小化 / 最大化 / 关闭 |
| 编辑器右侧的 **编辑 / 源码** | 编辑器的两种模式（[详见](/guide/editor)） |

### ② 活动栏

最左边那一竖列，是**导航**，每一格切一个界面。

![活动栏](/shots/guide/activity-bar.png)

按钮下方带**可见文字**（4 个字以内），不用悬停猜图标。鼠标停上去会浮出一枚气泡：第一行是完整名称，第二行用一句人话说明它做什么，中英文跟着界面语言走。

> 上面这张图是在**未登录**（纯净版）下截的，所以带档位门槛的按钮不在场（下面表里标了「基础版 / 专业版」的那几格）。插件加的格子也只在装了对应插件后才出现。

### ③ 主区域

当前那一格对应的界面。可能是文件树 + 编辑器，也可能是图谱、设置、扩展市场，或一个以「整页」方式打开的插件面板。

### ④ 右区

工作台模式下，右侧是一整块**合并右区**：左边是 **AI 对话**，右边是**会话栏**，头部右上角两枚图标在「**对话 / 插件**」之间切换。

| 部分 | 默认宽 | 怎么调 |
| --- | --- | --- |
| AI 对话 | 随窗口 | 拖右区左缘 |
| 会话栏 | **176px**（也是最小宽） | 拖左缘，176–400px；收起后整栏归 0 宽 |

- 会话栏在**编辑器低于 420px** 时会自己收起；窗口重新变宽、且多出余量才自动放回。手动收起后不会自己弹回，开合入口是输入框旁的历史按钮。
- 停在**插件页**时会话栏隐藏但宽度保留，编辑器不会跟着抖；插件页占满整块右区。
- 设置、扩展市场、远程助手等普通页也用同一块右区，不再各摆一套。
- 右区头部的**全屏键**进入整屏 AI 工作区（界面提示写「进入全屏搭档模式」，就是它）；从全屏里打开文件会切回工作台并退出全屏。

### ⑤ 状态栏

最下面一行，从左到右：

| 位置 | 内容 |
| --- | --- |
| 最左 | **终端**开关（1.3.6 起从活动栏搬到这里） |
| 左 | 字数 / 词数 / 行数 |
| 中 | 当前文件完整路径 |
| 右 | 行列 → 文件编码 → 版本号与当前档位 |
| 最右 | **AI 对话**开关（开合整个右区；插件页是右区的一页，切页走右区头部的「对话 / 插件」页签，底部不再单设插件侧栏开关） |

工作台里 AI 正在跑时，这枚按钮会变成「● AI 运行中 · 12s」；停在插件页时点它先回到对话页，已在对话页才收起。

## 活动栏上有什么

活动栏是**全量可配置**的：哪些按钮显示、什么顺序，都由你定（[详见](/guide/panels)）。

出厂顺序是这样：

| 按钮 | 切到哪 | 档位 |
| --- | --- | --- |
| **工作台** | 文件树 + 编辑器 + 右区（日常待最久的地方） | 免费 |
| **AI 搭档** | 在工作台右边打开 AI 对话 | 基础版 |
| **AI 全屏**（默认收起） | 直接进入整屏 AI 工作区；去 设置 → 面板 → 活动栏按钮 点亮 | 基础版 |
| **远程** | 远程助手（微信 / 飞书等 IM 接入） | 专业版 |
| **定时** | 定时任务 | 专业版 |
| **自进化** | 自进化实验室 | 专业版 |
| **图谱** | 工作区的关系图谱 | 免费 |
| **扩展** | 扩展市场（技能 / 连接器 / 专家 / 插件四个货架） | 免费 |
| **帮助** | 常用功能帮助（左栏三站：使用手册 / 对话 Slash 命令 / 快捷键） | 免费 |
| ─── 分隔 ─── | 下面这组固定在底部，不会被挤走 | |
| **导出** | 导出当前文档 | 免费 |
| **便签** | 悬浮便签 | 免费 |
| **公告** | 公告铃铛（有新公告会有红点） | 免费 |
| **登录 / 头像** | 未登录时是「登录」文字入口，登录后是头像 | — |
| **设置** | 设置页 | 免费 |

（「插件箱」那一格只在设置里把插件箱入口放在左侧活动栏时才显示。）

::: tip 终端不在活动栏了
1.3.6 起活动栏的「终端」整格撤掉，开关挪到**状态栏最左端**。老版本存下的活动栏布局里如果还有它，读档时会被自动滤掉，不用手动重置。
:::

::: tip 分隔线上下的区别
分隔线**上面**是「导航组」，窗口变窄装不下时，多出来的会被折进「更多」菜单。

分隔线**下面**是「身份区」，永不折叠、永不被顶出屏幕。

所以「设置」和「登录」永远够得着，不管窗口多小。
:::

::: tip 插件也能往活动栏加按钮
装了插件之后，活动栏上可能多出按钮。它们的图标和本体系统一成 lucide 线性图标，显示与排序和内置按钮一样可配。
:::

## 窗口能有多小

Notrat 是「窄到一定程度就不该再窄」的应用，窗口有**系统级的最小尺寸**约束，不会缩成一条缝。

窗口拉窄后，各部分自己让位：

| 部分 | 让位方式 |
| --- | --- |
| 活动栏 | 装不下的导航按钮折进「更多」 |
| 文件树 / AI 列 | 按比例缩，到各自下限为止（文件树 160px、AI 列 180px）；你拖定的宽度是「上限」 |
| 会话栏 | 编辑器低于 420px 时自动收起 |
| 状态栏 | 只有中间的文件路径会缩短，文件名永远保留 |
| 对话工具条 | 装不下的按钮折进溢出菜单 |

## 来路与去向

界面里出现**外部链接**时（公告里的链接、插件面板里的 URL），Notrat 不会把整个窗口跳走，它会在内置浏览器标签里打开，或者交给系统默认浏览器。你随时能返回。

## 四种「场」

同一个应用，界面会随你干的事变形。认清这几种，不会迷路：

| 场 | 长什么样 | 什么时候 |
| --- | --- | --- |
| **欢迎屏** | 没有工作区时的首页：问候语 + 最近 / 对话 + 输入框 | 刚启动、或关闭了工作区 |
| **工作台** | 文件树 + 编辑器 + 右区 | 日常写作、改文件 |
| **全屏 AI** | 整屏对话，左侧会话栏、右侧详情停靠栏 | 让 AI 一次干一票大的 |
| **整页** | 设置 / 扩展市场 / 图谱 / 远程助手 / 定时任务，以及「打开方式 = 整页」的插件面板 | 配置、浏览、看全局 |

它们之间随时互切，状态都不丢。
