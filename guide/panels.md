# 活动栏与面板

左侧活动栏是一个**全量可配置**的导航栏：显示哪些按钮、按什么顺序排，都由你决定。

## 调整活动栏

进入 **设置 → 面板**，找到「栏位」段里的**活动栏按钮**：

![面板设置](/shots/guide/settings-panels.png)

这里列着所有可用按钮（内置的 + 插件加的），拖拽调整顺序、开关控制显隐。

### 也可以在栏上直接改

不想进设置？在活动栏按钮上**右键**，弹出：

| 项 | 作用 |
| --- | --- |
| **上移 / 下移** | 调整顺序 |
| **隐藏此按钮** | 从活动栏拿掉 |

![活动栏右键菜单](/shots/guide/activity-bar-context.png)

改动立刻生效，也立刻存盘，不用点确定。

## 哪些按钮能被隐藏

全部都能，包括分隔线以下那组和插件加上来的按钮。

「导出 / 便签 / 公告 / 登录 / 设置」这一组是**身份区**，区别在**布局行为**：它们永远不会被折叠、不会被顶出屏幕，也不参与「更多」折叠（你得手动右键隐藏它才会消失）。

::: tip 为什么这么设计
导航按钮是「今天想干哪类活」，会随心情变；身份按钮是「我是谁、要去哪配置」，任何时候都得够得着。

所以把它们放在分隔线以下，视觉上和上面的导航列自然分开，行为上也不同。
:::

## 「更多」折叠

窗口拉窄、导航按钮装不下时，多出来的会折进一个**「更多」按钮**里（在导航组末尾）。点开是一个竖排菜单。

装得下几个就显示几个，不会出现按钮被压扁或者半截在屏幕外的情况。

## 面板宽度

| 部分 | 最小宽 | 怎么调 |
| --- | --- | --- |
| **文件树** | 160px | 拖右边缘 |
| **右区（AI 对话 / 插件页）** | 编辑器保底 420px | 拖右区左缘 |
| **会话栏** | 176px | 拖左缘，176–400px |

你拖定的宽度是**上限**：窗口变窄时，文件树与 AI 列按比例缩，缩到各自下限为止，不会把编辑器挤没。宽度都会被记住，下次打开还是这个值。

## 左栏的四个页签

左侧那一栏（文件树那一栏）顶部并排四个页签，快捷键是 `Ctrl+Shift+1` ~ `Ctrl+Shift+4`：

| 页签 | 快捷键 | 内容 |
| --- | --- | --- |
| **文件** | `Ctrl+Shift+1` | 工作区的文件树 |
| **大纲** | `Ctrl+Shift+2` | 当前文档的标题树，点一下跳过去 |
| **反向链接** | `Ctrl+Shift+3` | 哪些文档引用了当前这一篇 |
| **搜索** | `Ctrl+Shift+4` | 全工作区的内容搜索（`Ctrl+Shift+F` 直接落进搜索框） |

四个页签**共用左侧这一栏**，同时只显示一个，它们是这一栏的不同内容，不是编辑器里浮出来的面板。

![左栏页签](/shots/guide/editor-panels.png)

## 右区：对话、会话栏、插件页

工作台的右区是一整块，不是两列各管各的：

- **左边 AI 对话**，**右边会话栏**，头部右上角两枚图标在「对话 / 插件」之间切换
- 插件页占满整块，会话栏隐藏但宽度保留，编辑器不会跟着抖
- 设置、扩展市场、远程助手等普通页也用同一块右区
- 底部状态栏只留一枚「AI 对话」开关，负责整块右区的开合：收起时点它先回到对话页；停在插件页时点它先切回对话

### 会话栏

历史对话默认只占 **176px**，一行一条、只显示标题。

| 操作 | 行为 |
| --- | --- |
| 拖左缘 | 在 176–400px 之间调宽（编辑器低于 420px 时自动收起） |
| 输入框旁的历史按钮 | 开合会话栏；收起后整栏归 0 宽，正在跑的会话标记也挂在按钮上 |
| 再点历史按钮 | 放得下就放回常驻栏；屏幕右边还有位置就先扩窗，都没有才从右缘拉出抽屉（盖住聊天，不改列宽） |
| 工作区组头 | 一个窗口里有多个工作区时按工作区分组；组头写着条数，可整组收起，悬停露出 `＋` 在该工作区新建对话 |
| 拖动一条对话 | 拖到另一个工作区组头 = 连同历史搬过去；拖到「工作空间」组头 = 变成空间级（见 [工作空间](/guide/spaces#空间级会话)） |

列表按**今天 / 昨天 / 3 日内 / 7 日内 / 一个月内 / 很久**分栏，点栏目标题展开或收起；搜索框在头部，搜的是标题、第一句用户消息和最后一条回复里的词。

## 状态胶囊

AI 开始跑工具后，编辑器顶部浮出一条**状态胶囊**，不用切页就能看到当前在做什么：

- 结束后停留 8 秒，显示「已完成 · N 个文件已改 · 26s」或「运行失败」
- 点胶囊展开 380px 浮层，直接看这一轮的步骤、工具、改动与耗时；浮层里可以停止，`Esc` 或点外面关闭
- 改动照旧一键打开 diff 标签页
- 侧栏收起时胶囊还在；从状态栏展开侧栏只展开右区，不会自动把胶囊弹开

## 详情停靠栏（全屏）

在**全屏 AI** 那一屏里，聊天区右边还有一条常驻栏，两个页签：

| 页签 | 内容 |
| --- | --- |
| **时间线** | 当前会话里发生的每一步 |
| **改动** | 这一轮被 AI 改过哪些文件 |

![详情停靠栏](/shots/guide/details-dock.png)

「改动」页分两种条目：

- **AI 写盘改的文件**（通过写文件 / 追加 / 新建），每条都能**展开看 diff**（+N / −N，展开是全文对比）
- **终端命令动过的文件**：只记路径、不记内容（命令改了什么它看不到），点开文件自己看

在全屏里点某一轮的「运行详情」，详情会直接在右侧停靠栏展开，不会退出全屏、也不会跳去编辑器标签页。工作台里则走上面的状态胶囊，或从「查看差异」打开编辑器标签页。

## 终端面板

1.3.6 起，终端开关在**状态栏最左端**（活动栏的「终端」格已撤掉）。点一下从底部拉起，可以拉高拉低，也可以开多个：

![终端](/shots/guide/terminal.png)

- 顶部有一排**常用命令**快捷按钮（`ls` / `pwd` / `git status` / `npm run dev` / `python` / `cd ~`）
- 标签页管理多个终端会话
- 终端的工作目录默认是当前工作区

::: tip 终端相关的设置搬到「面板」页了
1.3.5 起，Shell 选择与输入补全两项从原先的「终端」分类**整块搬进 设置 → 面板**。

设置里不再有独立的「终端」分类，面板页里找。
:::

## 悬浮便签

活动栏底部的「便签」打开的是**独立悬浮窗**，不是面板，它能在其他应用上面飘着。

详见 [悬浮便签与桌面悬浮器](/guide/widgets)。

## 插件侧栏与插件页

装了带界面的插件后，右区头部会多出「对话 / 插件」两枚页签（没有插件面板贡献时整条不显示）：

- **对话页**：AI 对话 + 右侧会话栏
- **插件页**：插件面板占满整块右区，会话栏隐藏但宽度保留；插件数量压在页签角标上

工作台底部**只有一枚「AI 对话」开关**管整块右区的开合，不再有单独的「插件侧栏」按钮——切到插件页走右区头部的「对话 / 插件」页签。

插件面板的**位置与打开方式**由插件声明，也可以由你改：

| 操作 | 怎么做 |
| --- | --- |
| **换位置** | 面板右键 →「面板位置」二级菜单。位置可以**多选**，例如同时保留活动栏按钮、右侧停靠栏和桌面窗口；父行显示「首个位置 +N」 |
| **换打开方式** | 同一菜单 →「打开方式」：跟随位置 / 标签页 / **整页**。只在有触发位时出现，常驻面板、悬浮窗和桌面窗口没有这一问 |
| **整页打开** | 面板像设置、图谱、定时任务一样占满主区、没有编辑器标签栏，活动栏对应插件按钮高亮为当前页；整页面板如果自带侧栏，再点一次活动栏图标即可开合它 |
| **恢复默认** | 菜单里的「恢复默认位置」 |

::: tip 「插件侧栏」和「插件箱」是两个东西
- **插件侧栏**：右区里的插件页，装插件自己的界面
- **插件箱**：状态栏上的入口，管理已装插件的开关与运行状态；右键任一插件可以直接「重载插件」

名字像，位置和职责完全不同。
:::

## 「面板」设置页里有什么

设置 → 面板 这一页按**界面从上到下的顺序**分成三段：

| 段 | 一句话说明 | 里面有什么 |
| --- | --- | --- |
| **栏位** | 活动栏、左右面板与状态栏的显示与排序 | **活动栏按钮管理**（拖拽排序 + 逐项显隐，含插件按钮）；「AI 全屏」一键直达整屏的入口默认收起，在这里点亮 |
| **内置终端** | 终端使用的 Shell 与输入辅助 | **Shell 选择**（自动 / Git Bash / PowerShell / WSL）、**输入补全** |
| **对话与启动** | 对话侧的系统行为 | **启用对话 Slash 命令**、**多会话并行（后台续流）**、**新建对话时先询问**等 |

::: tip 1.3.5 把散落的面板设置收成了这一页
原先这些项分散在「外观」（活动栏按钮）、「终端」（Shell）两个分类里。1.3.5 起：

- 「终端」分类**整体退休**，内容搬进面板页
- 活动栏按钮管理从「外观」**迁到**面板页「栏位」段

所以你现在只在**一个地方**调界面布局。设置左栏不再有独立的「终端」分类。
:::

::: tip 「多会话并行」（本版新增）就在这一页，默认开着
它没有单独的左栏分类——在 设置 → 面板 → 对话与启动 段里。开着时，在别的会话里发消息 / 新建对话不会打断正在输出的那条回复（它转到后台继续跑、跑完自己落盘）；新建对话时若还有回复在跑，会先弹一个三选一问你。不想并行就把它关掉，切走即中断。

用法与右区右侧的会话栏见 [AI 对话](/guide/chat)。
:::
