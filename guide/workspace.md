# 工作区与文件管理

「工作区」是 Notrat 里最重要的一个概念：它就是你的一个文件夹。Notrat 不建自己的库、不用专有格式，打开一个文件夹就是打开一个工作区。

## 打开、新建、关闭

工作区的所有操作都在**顶部标题栏的工作区菜单**里：

![工作区菜单](/shots/guide/workspace-menu.png)

| 菜单项 | 作用 |
| --- | --- |
| **新建工作区…** | 输入一个名字，Notrat 建好文件夹并打开；窗口里已经开着工作区时，还会问「当前窗口 / 附加到当前窗口 / 新窗口」 |
| **打开工作区…** | 挑一个已有的文件夹。可以按住 `Ctrl` / `Shift` **多选**，选完会问要不要合成工作空间 |
| **打开文件** | 不切换工作区，单独打开一个文件（比如桌面上的 `待办.md`） |
| **关闭工作区** | 回到欢迎屏，文件树清空 |
| **最近** | 工作区与工作空间混在同一条「最近打开」时间轴上（层叠图标区分），点一下按原来的动线打开 |
| **全部工作空间…** | 只列已保存的工作空间，带搜索框；点一行按「当前窗口 / 新窗口」打开 |
| **最近里的「未保存」行** | 窗口里有两个以上根、还没起名时出现：点一下就是命名框，起好名字下次一键开回 |
| **合并工作空间…** | 有两个以上已保存空间时出现（在空间行的「⋯」或右键菜单里）：勾选两个及以上去重合成一个新的命名空间 |

工作空间行的「⋯」里还有**重命名**、**删除**和**在新窗口打开**；删除只删名字，不动磁盘上的任何文件。

::: tip 两处「最近」的展开方式不同
- **标题栏菜单里**：默认只列 4 条，底下有「查看更多」可以铺开
- **欢迎屏上**：首屏 10 条，往下滚自动补一页，最多记 50 条；「最近」页签里工作区与工作空间同列，「对话」页签一行一条、每个工作区最多三条
:::

### 同时开多个工作区

每个工作区默认在自己的窗口里。已经开着一个工作区时，再去菜单里选另一个，Notrat 会先问你三选一：

| 选项 | 含义 |
| --- | --- |
| **在当前窗口打开** | 换掉当前窗口的工作区 |
| **附加到当前窗口** | 保留当前工作区，把新目录作为**同一窗口里的另一个根**（这就是「多根窗口」） |
| **在新窗口打开** | 原来那个窗口原样留着 |

如果你正在等 AI 写东西，切走前还会多问一句「这条回复要不要留着」：可以选「把「X」附加进来，对话不断」，也可以明确选「仍然切换」。左下角勾一次「以后切换工作区时不再提醒」就不再弹。

::: tip 关掉应用再打开，全部窗口会原样回来
打开过的工作区、窗口顺序、窗口个数、每个窗口的大小和位置都会被记住，下次启动一起恢复；多根窗口里的**全部根和当前根**也一起恢复。

如果某个工作区的文件夹被删掉或移走了，Notrat 不会假装打开成功，它会明确告诉你这个路径已经不存在（右下角弹提示），不会让你以为已经打开了。
:::

## 一个窗口装多个工作区

在「打开工作区」对话框里选**「附加到当前窗口」**，新目录不会替换当前工作区，而是作为同一窗口里的另一个根加进来。

![附加工作区](/shots/guide/workspace-overview.png)

| 行为 | 说明 |
| --- | --- |
| **文件树** | 所有根同时列出，按添加顺序排列；工作区根用「层叠」图标，普通文件夹保持原样 |
| **当前根** | 点根名切换；你正在看哪个根里的文件，哪个根的名字就高亮成主题色 |
| **拿掉一个根** | 右键根名 →「**从窗口移除**」。只把它从当前窗口撤下，**磁盘文件与已有会话都不会删**，确认框里会再写一遍 |
| **标题栏** | Notrat 下面写的是这个工作空间的**名字**（没起名时用各根名字拼起来） |
| **对话列表** | 按工作区分组，组的先后跟文件树里的根顺序完全一致 |
| **跨根拖文件** | 会先问一句「这会把 N 个项目移出当前工作区，放入「X」」，确认才动 |
| **重启** | 全部根、当前根、文件树顺序原样开回 |

::: tip 点别的组的会话会先切工作区
会话栏里点另一个工作区组里的对话，Notrat 会先切到那个工作区再打开它——只切工作区，不会把正在跑的对话一起搬过去。
:::

### 对话也能换工作区

在会话列表里按住一条对话：

- 拖到另一个**工作区组头**上松手 → 这条对话连同完整历史搬到那个工作区
- 拖到顶部**「工作空间」组头**上 → 它变成**空间级**对话（留在原工作区，显示在空间组下）
- 再拖回工作区组 → 退回成工作区级

拖动时组头会亮起；当前正在看的这条拖去别的工作区会提示先切走，只改空间归属则不受限。

## 工作空间：给一组根起个名字

窗口里有两个以上根、并且数量稳定下来（约 1.5 秒）时，Notrat 会自己弹出命名框告诉你「这组工作区已经成为一个工作空间」：起个名字（最多 80 字，默认是各根名字拼起来），这组根和当前根就被记下来了，下次从「全部工作空间…」或欢迎屏一键整组开回。当时跳过了也没关系，「最近」里会留着一条带「未保存」标记的行，点它就是同一个命名框。

名字、合并、空间级会话、空间里的资源（技能 / 连接器 / 插件）、在别的空间之间预览——这一整套单独讲：

→ [**工作空间（多项目组合）**](/guide/spaces)

::: warning 目录都打不开时会明确提示
工作空间里保存的目录如果全被删了或移走了，打开时会告诉你「这个工作空间里的目录都打不开了」，不会只给你一个空窗口。
:::

### 一次选多个目录

在「打开工作区」的系统目录框里按住 `Ctrl` / `Shift` 多选，选了不止一个，应用会停下来问：

> 检测到您选择了多个工作区，需要合并成工作空间吗？

确认页可以先给这个空间起名（默认用各目录名拼起来，如 `docs + src`）。合并只是把这几个目录记成一个工作空间，磁盘上的文件一个都不动；之后照常按「当前窗口 / 新窗口」打开整组。只选一个目录时和以前完全一样，直接打开。

## 文件树

左边那一列就是当前窗口里所有工作区根的文件树；窗口里只有一个根时，就是你熟悉的单工作区文件树。

![文件树](/shots/guide/filetree.png)

### 新建

文件树顶部的**工具栏**上有一个 **`＋`** 按钮（鼠标悬停就会弹出菜单，点一下也一样）：

![文件树的加号](/shots/guide/filetree-new.png)

菜单里有三项：

| 项 | 说明 |
| --- | --- |
| **文件** | 建一个空文件，名字自己写全（含扩展名） |
| **Markdown** | 建 `.md`，名字不用带扩展名 |
| **文件夹** | 建目录 |

这三项都建在**当前工作区根目录**下（多根窗口里就是当前根）。想直接建进某个子文件夹里，用下面说的悬停快捷按钮。

把鼠标移到**任意文件夹**这一行上，行尾会出现四个快捷按钮：**新建文件 / 新建文件夹 / 重命名 / 删除**，比展开菜单快。

在文件树的**空白处**右键，能拿到同样的新建菜单，外加两项：

| 项 | 说明 |
| --- | --- |
| **粘贴**（`Ctrl+V`） | 把剪切/复制的文件粘贴到当前位置 |
| **全选**（`Ctrl+A`） | 选中当前层级的全部条目 |

### 右键一个文件

在文件上右键，得到的是完整菜单：

![文件右键菜单](/shots/guide/filetree-context-menu.png)

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| **打开** | — | 在编辑器里打开 |
| **打开方式** | — | 按扩展名指定用哪个编辑器打开（装了插件、同一后缀有多个编辑器时才出现；里面可「恢复默认打开方式」） |
| **在文件管理器中打开** | — | 调起系统的资源管理器 / 访达 / 文件管理器，并选中这个文件 |
| **重命名** | — | 就地改名 |
| **添加到对话** | — | 把这个文件的内容塞进 AI 对话的上下文 |
| **剪切** | `Ctrl+X` | |
| **复制** | `Ctrl+C` | |
| **复制路径** | `Ctrl+Shift+C` | 复制完整绝对路径 |
| **另存为…** | `Ctrl+S` | 存一份副本到别处 |
| **删除** | `Del` | |

::: tip 菜单最下面可能有插件加的项
如果装了插件，菜单底部会多出它贡献的项（插件可以往文件右键菜单里加自己的入口）。

这是插件在正常工作，不是出了奇怪的东西。
:::

### 拖拽

- **拖文件到另一个文件夹** → 移动
- **拖文件到编辑器正文**：**图片**会被插入，并把文件拷进 `<工作区>/.notrat/images/`；**其它类型**（pdf / txt / zip…）不插入，会打开成一个新标签页
- **拖文件到对话输入框** → 作为附件加进上下文

### 多选与框选

- 按住 `Ctrl` 点条目逐个加选，按住 `Shift` 点选一段范围
- 也可以在**行尾留白**或**左侧缩进条**按下并拖动，拉出一个框选范围（这两处以前按下去是选中 / 拖文件，1.3.6 起都能起手拉框）
- 快速按一下再拖、或拖一下马上松手，不会被误当成单击把文件打开
- 把文件拖到它本来就在的文件夹上，现在静默忽略，不会弹「已移动」

### 文件类型图标

不同类型的文件在树里有不同的图标（Markdown、代码、图片、PDF、压缩包…），方便一眼扫出来。

## 在编辑器里看当前文件

编辑器顶部的标签栏会显示已打开的文件，可以同时开好几个：

![编辑器标签栏](/shots/guide/editor-tabs.png)

底部状态栏一直显示当前文件的路径（窄窗口下缩短的是目录，文件名永远留着）。点一下它不是复制，而是在文件树里定位到这个文件，在哪一层、旁边还有谁，一眼看到。

## 搜索

Notrat 提供两级搜索：

| 想找什么 | 用哪个 |
| --- | --- |
| 文件名 / 目录名 | 文件树顶部的搜索框（默认是一条窄输入框，点一下撑开） |
| 文件**内容**里的某句话 | 左栏的**搜索**页签（`Ctrl+Shift+4`），或 `Ctrl+Shift+F` 直接落进搜索框 |
| 当前文件里的某个词 | 编辑器内查找替换（`Ctrl+F`） |

## 工作区里的 `.notrat` 目录

打开工作区后，文件树里可能出现一个 `.notrat` 文件夹（默认隐藏，取决于你的设置）。里面是 Notrat 的工作区级数据：

```
<你的工作区>/
└── .notrat/
    ├── images/     ← 你粘贴/拖入编辑器的图片存这里
    ├── ...         ← 索引、状态等
```

::: warning 别删 `.notrat/images`
编辑器里插入的本地图片按**相对路径**引用这个目录。删掉它，那些图片在文档里就变成裂图了。

文档本身没坏，把图片放回去即恢复。
:::

## 换台电脑接着写

工作区就是一个普通文件夹，所以：

1. 把整个文件夹拷到 U 盘 / 上传网盘 / 用 Git 推上去
2. 在另一台电脑的 Notrat 里「打开工作区」指向它

笔记、图片、目录结构全部照旧。账号里云端的一部分只有**账号与订阅信息**，不含你的笔记内容。详见 [账号、版本与数据](/guide/account)。
