# 工作区与文件管理

「工作区」是 Notrat 里最重要的一个概念：**它就是你的一个文件夹**。Notrat 不建自己的库、不用专有格式，打开一个文件夹就是打开一个工作区。

## 打开、新建、关闭

工作区的所有操作都在**顶部标题栏的工作区菜单**里：

![工作区菜单](/shots/guide/workspace-menu.png)

| 菜单项 | 作用 |
| --- | --- |
| **新建工作区…** | 输入一个名字，Notrat 建好文件夹并打开 |
| **打开工作区…** | 挑一个已有的文件夹 |
| **打开文件** | 不切换工作区，单独打开一个文件（比如桌面上的 `待办.md`） |
| **关闭工作区** | 回到欢迎屏，文件树清空 |
| **最近** | 最近打开过的工作区列表，点一下直接切 |

::: tip 「最近」在菜单里是全量列表；欢迎屏上的是分页的
欢迎屏的「最近工作区」首屏显示 10 条，往下滚会自动补一页，最多记 50 条。

标题栏菜单里的「最近」不设折叠，一次铺开——它本来就短。
:::

### 同时开多个工作区

每个工作区在**自己的窗口**里。想同时开两个项目：菜单里选另一个工作区，Notrat 会新开一个窗口，原来那个原样留着。

::: tip 关掉应用再打开，全部窗口会原样回来
打开过的工作区、窗口顺序、窗口个数、每个窗口的大小和位置都会被记住，下次启动一起恢复。

如果某个工作区的文件夹被删掉或移走了，Notrat 不会假装打开成功——它会明确提示这个路径已经不存在，并让你选新的位置。
:::

## 文件树

左边那一列就是当前工作区的文件树。

![文件树](/shots/guide/filetree.png)

### 新建

把鼠标移到**任意文件夹**上，右侧会出现 **`＋`** 按钮：

![文件树的加号](/shots/guide/filetree-new.png)

点开有三项：

| 项 | 说明 |
| --- | --- |
| **新建文件** | 建一个空文件，名字自己写全（含扩展名） |
| **新建 Markdown** | 建 `.md`，名字不用带扩展名 |
| **新建文件夹** | 建目录 |

在文件树的**空白处**右键，是同一个菜单，外加两项：

| 项 | 说明 |
| --- | --- |
| **粘贴**（`Ctrl+V`） | 把剪切/复制的文件粘贴到当前位置 |
| **全选**（`Ctrl+A`） | 选中当前层级的全部条目 |

### 右键一个文件

在文件上右键，得到的是完整菜单：

![文件右键菜单](/shots/guide/filetree-context-menu.png)

| 菜单项 | 快捷键 | 说明 |
| --- | --- | --- |
| **打开** | — | 在编辑器里打开 |
| **在文件管理器中打开** | — | 调起系统的资源管理器 / 访达 / 文件管理器，并选中这个文件 |
| **重命名** | — | 就地改名 |
| **添加到对话** | — | 把这个文件的内容塞进 AI 对话的上下文 |
| **剪切** | `Ctrl+X` | |
| **复制** | `Ctrl+C` | |
| **复制路径** | `Ctrl+Shift+C` | 复制完整绝对路径 |
| **另存为…** | `Ctrl+S` | 存一份副本到别处 |
| **删除** | `Del` | |

::: tip 菜单最下面可能有插件加的项
如果你装了插件，菜单底部会多出几项——比如示例插件会在文件菜单末尾加「📦 示例插件：打开这个文件」和「浏览文件夹」。

**这是插件在正常工作**，不是出了奇怪的东西。每项左边的小图标就是那个插件的标记。
:::

### 拖拽

- **拖文件到另一个文件夹** → 移动
- **拖文件到编辑器** → 插入图片 / 插入文件引用（见 [编辑器进阶](/guide/editor-advanced)）
- **拖文件到对话输入框** → 作为附件加进上下文

### 文件类型图标

不同类型的文件在树里有不同的图标（Markdown、代码、图片、PDF、压缩包…），方便一眼扫出来。

## 在编辑器里看当前文件

编辑器顶部的标签栏会显示已打开的文件，可以同时开好几个：

![编辑器标签栏](/shots/guide/editor-tabs.png)

底部状态栏一直显示当前文件的完整路径，点一下可以复制。

## 搜索

Notrat 提供两级搜索：

| 想找什么 | 用哪个 |
| --- | --- |
| 文件名 / 目录名 | 文件树顶部的搜索框 |
| 文件**内容**里的某句话 | 全局搜索面板（活动栏「帮助」下方的搜索入口，或 `Ctrl+Shift+F`） |
| 当前文件里的某个词 | 编辑器内查找替换（`Ctrl+F`） |

## 工作区里的 `.notrat` 目录

打开工作区后，文件树里可能出现一个 `.notrat` 文件夹（默认隐藏，取决于你的设置）。里面是 Notrat 的工作区级数据：

```
<你的工作区>/
└── .notrat/
    ├── images/     ← 你粘贴/拖入编辑器的图片存这里
    ├── ...         ← 索引、状态等
```

::: warning 别删 `.notrat/images`
编辑器里插入的本地图片按**相对路径**引用这个目录。删掉它，那些图片在文档里就变成裂图了。

文档本身没坏——把图片放回去即恢复。
:::

## 换台电脑接着写

工作区就是一个普通文件夹，所以：

1. 把整个文件夹拷到 U 盘 / 上传网盘 / 用 Git 推上去
2. 在另一台电脑的 Notrat 里「打开工作区」指向它

笔记、图片、目录结构全部照旧。Notrat 账号里同步的是**设置与订阅信息**，不是你的笔记内容——详见 [账号、版本与数据](/guide/account)。
