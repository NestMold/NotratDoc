# 技能

**技能**是给 AI 的一套固定做事方法。

和「专家」的区别：专家是**一个角色**（谁来做），技能是**一套方法**（怎么做）。一个专家可以带多个技能，一个技能也能给不同专家用。

设置 → 扩展管理 → **技能**。

![技能管理](/shots/guide/settings-skills.png)

## 技能长什么样

一个技能就是一个目录，里面一个 `SKILL.md`：

```
技能名/
└── SKILL.md
```

`SKILL.md` 开头是元信息，后面是正文：

```markdown
---
name: 周报整理
description: 把一周的零散记录整理成结构化周报。适用于从流水账、会议记录中提炼要点并成文。
---

# 周报整理

## 什么时候用

用户手上有零散记录、要产出正式周报时。

## 怎么做

1. 先通读所有输入，不要边读边写
2. 按「做成了什么 / 遇到什么阻碍 / 下周要做什么」三段归类
3. ...
```

::: tip `description` 写得越具体，触发越准
`description` 是 AI 判断「这个技能该不该用」的**唯一依据**。

写「整理周报」它可能想不起来；写「把一周的零散记录整理成结构化周报，适用于从流水账、会议记录中提炼要点」，它就知道什么时候该调用。
:::

## 三种来源

技能列表按来源分组：

| 来源 | 位置 | 说明 |
| --- | --- | --- |
| **内置** | 应用自带 | Notrat 自带的技能（[插件开发](/plugin-dev/) 用得到的那批也在这里），不能删，可以停用 |
| **工作区** | `<工作区>/.notrat/skills/` | 只在当前工作区生效 |
| **全局** | 应用数据目录下的 `skills/` | 所有工作区都能用 |
| **插件带的** | 插件自己的目录 | 装插件时一起装进来 |

顺序就是列表里从上到下的顺序：**内置 → 你自己装的（工作区 / 全局 / 插件）**。

::: tip 工作区 vs 全局怎么选
- 只服务这一个项目的（比如这个 repo 的提交规范）→ **工作区**
- 走到哪都想用的（比如「把这段话改得更利落」）→ **全局**
:::

## 三种用法

| 方式 | 范围 | 怎么做 |
| --- | --- | --- |
| **`/` 命令** | 当前消息 | 输入 `/` 找技能名，选中后以 chip 插入 |
| **`@` 面板** | 当前消息 | 输入 `@` → **技能**页签 → 勾选（可多选） |
| **专家自带** | 用那个专家时 | 在专家的配置里勾选技能 |

::: tip `@` 勾的技能是「本条消息」级的
用完即弃，下一条消息不受影响。要连续几条都用，用 `/` 命令插 chip 更顺手。
:::

技能被调用时，`SKILL.md` 的正文会进上下文——AI 就按里面写的步骤干。

## 建一个自己的技能

### 方法一：让 AI 帮你写

Notrat 内置了一个 **skill-creator** 技能——它就是用来写技能的。

在对话里说「我想做一个 xxx 的技能」，它会带你走一遍：明确做什么 → 写一版 → 用两三个真实例子试 → 一起看结果 → 改。

::: tip 这是最省事的办法
写技能的难点不在格式，在**把你自己脑子里的隐性步骤说清楚**。让 AI 追问你几轮，比你自己憋着写快得多。
:::

### 方法二：手写

1. 在 `<工作区>/.notrat/skills/` 或全局 `skills/` 下建一个目录
2. 目录名就是技能名（会在 `/` 菜单里显示）
3. 里面写 `SKILL.md`，开头按上面的格式写 frontmatter
4. 回到设置 → 扩展管理 → 技能，应该就能看到它

### 方法三：从市场装

活动栏「扩展」→ **技能**货架 → 装。

## 启用、停用与更新

技能页里每项可以：

| 操作 | 效果 |
| --- | --- |
| **启用 / 停用** | 关掉它不再出现在 `/` 和 `@` 里，文件保留 |
| **更新** | 从市场装的技能，对比版本后可以更新（按 slug 匹配） |
| **删除** | 删掉技能目录 |

页头有**全部更新**，卡片上也有单独的更新入口。

## 排查：技能列表是空的

如果你确定技能目录里有东西，但技能页里什么都没有：

**先把设置关掉再打开一次。**

::: warning 这是一个已知的历史问题
1.3.5 修掉了一个与此相关的 bug：技能页的数据加载逻辑里还留着对**旧分类名**的判断，导致某些路径下这一页**恒空**。

如果你在更早的版本上遇到这个现象，升级即可。
:::
