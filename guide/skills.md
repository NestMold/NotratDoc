# 技能

**技能**是给 AI 的一套固定做事方法。

和「专家」的区别：专家是一个角色（谁来做），技能是一套方法（怎么做）。一个专家可以带多个技能，一个技能也能给不同专家用。

设置 → 扩展管理 → **技能**。

![技能管理](/shots/guide/settings-skills.png)

## 技能长什么样

一个技能就是一个目录，里面一个 `SKILL.md`：

```
技能名/
└── SKILL.md
```

`SKILL.md` 开头是元信息，后面是正文：

```markdown
---
name: 周报整理
description: 把一周的零散记录整理成结构化周报。适用于从流水账、会议记录中提炼要点并成文。
---

# 周报整理

## 什么时候用

用户手上有零散记录、要产出正式周报时。

## 怎么做

1. 先通读所有输入，不要边读边写
2. 按「做成了什么 / 遇到什么阻碍 / 下周要做什么」三段归类
3. ...
```

::: tip `description` 写得越具体，触发越准
`description` 是 AI 判断「这个技能该不该用」的**唯一依据**。

写「整理周报」它可能想不起来；写「把一周的零散记录整理成结构化周报，适用于从流水账、会议记录中提炼要点」，它就知道什么时候该调用。
:::

## 来源

技能页顶部有一排**来源页签**（带数量），点一个就只看那一类：

| 页签 | 位置 | 说明 |
| --- | --- | --- |
| **内置** | 应用自带 | 目前**只有一个：插件开发**（写插件用的那套方法，[开发文档在这里](/plugin-dev/)），不能删，可以停用 |
| **项目** | `<工作区>/.notrat/skills/` | 只在当前工作区生效（「工作区」在界面上的标签就是「项目」） |
| **个人** | 应用数据目录下的 `.skills/` | 所有工作区都能用（界面上叫「个人」） |
| **插件** | 插件自己的目录 | 装插件时一起装进来 |
| **ZCode 插件** | 插件自己的目录 | 来自 ZCode 格式插件的技能 |
| **Claude Code / CodeX / OpenClaw** | 各自工具的目录 | 从别的 AI 工具同步过来的 |

默认是「全部」，把各类合在一起看。

::: tip 项目 vs 个人怎么选
- 只服务这一个项目的（比如这个 repo 的提交规范）→ **项目**（放进工作区）
- 走到哪都想用的（比如「把这段话改得更利落」）→ **个人**（放进应用数据目录）
:::

## 三种用法

| 方式 | 范围 | 怎么做 |
| --- | --- | --- |
| **`@` 面板** | 当前消息 | 输入 `@` → **技能**页签 → 勾选（可多选），选中后以 chip 插到光标处 |
| **专家自带** | 用那个专家时 | 在专家的配置里勾选技能 |
| **`/skill` 命令** | 当前会话 | 输入 `/` 打开命令菜单，里面有 `/skill list`、`/skill use` 等管理命令 |

::: tip 为什么技能不在 `/` 菜单里
`/` 菜单列的是**内置命令与插件命令**（按通用 / 文件 / 编辑 / 连接器（MCP）/ 终端 / AI / 搜索 / 分享 / 导出 / 工作区分类），不铺具体技能。

想让这条消息带上某个技能，走 `@` → **技能**页签。勾选是「本条消息」级的，用完即弃；下一条还要用就再勾一次。
:::

技能被调用时，`SKILL.md` 的正文会进上下文，AI 就按里面写的步骤干。

## 建一个自己的技能

### 方法一：让 AI 帮你写

Notrat 内置了一个叫**「技能创建」**的技能（内部名 `skill-creator`），它就是用来写技能的。

在对话里说「我想做一个 xxx 的技能」，它会带你走一遍：明确做什么 → 写一版 → 用两三个真实例子试 → 一起看结果 → 改。

::: tip 这是最省事的办法
写技能的难点是把你自己脑子里的隐性步骤说清楚，格式本身不难。让 AI 追问你几轮，比你自己憋着写快得多。
:::

### 方法二：手写

1. 在 `<工作区>/.notrat/skills/` 或应用数据目录的 `.skills/` 下建一个目录
2. 目录名就是技能名（会出现在 `@` 面板的技能页签里）
3. 里面写 `SKILL.md`，开头按上面的格式写 frontmatter
4. 回到设置 → 扩展管理 → 技能，应该就能看到它

### 方法三：从市场装

活动栏「扩展」→ **技能**货架 → 装。

## 启用、停用与更新

技能页里每项可以：

| 操作 | 效果 |
| --- | --- |
| **启用 / 停用** | 关掉后不再出现在 `@` 面板的技能页签里，文件保留 |
| **更新** | 从市场装的技能，对比版本后可以更新（按 slug 匹配） |
| **删除** | 删掉技能目录 |

页头有两个按钮，别混：

- **检测更新**：去 SkillHub / ClawHub 对照市场来源技能的新版本（要联网）
- **刷新**：只重新扫一遍本地技能目录，不碰网络

你刚手写了一个技能、页面里没看到它，点**刷新**。

## 排查：技能列表是空的

如果你确定技能目录里有东西，但技能页里什么都没有：

先把设置关掉再打开一次。

::: warning 这是一个已知的历史问题
1.3.5 修掉了一个与此相关的 bug：技能页的数据加载逻辑里还留着对**旧分类名**的判断，导致某些路径下这一页**恒空**。

如果你在更早的版本上遇到这个现象，升级即可。
:::
