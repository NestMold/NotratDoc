# 编辑器

Notrat 的编辑器默认是**所见即所得**：你打出来的是排版好的样子，不是 `**加粗**` 这样的符号。但 Markdown 语法它全认——内行可以当 Markdown 编辑器用，外行可以当 Word 用。

![编辑器](/shots/guide/editor.png)

## 两种模式

编辑器右上角有一个 **编辑 / 源码** 开关：

| 模式 | 看到什么 | 什么时候用 |
| --- | --- | --- |
| **编辑**（所见即所得，默认） | 排版后的样子 | 正常写作 |
| **源码** | 原始 Markdown 文本 | 精确控制标记、检查格式、批量替换 |

**源码模式**的快捷开关是 `Ctrl+/`。也可以在文件树的右键菜单里选「用源码模式打开」，打开时就进源码模式。

::: tip 大文档会自动切源码
超过 **10 万字符**的单个文件，Notrat 会跳过富文本渲染直接进源码模式。

这不是限制，是让你别等——富文本模式渲染这种体量的文档要几十秒。源码模式几乎瞬间就开。
:::

## 工具栏

编辑器上方是一条工具栏。从左到右：

![编辑器工具栏](/shots/guide/editor-toolbar.png)

| 按钮 | 悬停名 | 快捷键 |
| --- | --- | --- |
| `A ▾` | 字号 / 字体 | — |
| `B` | 加粗 | `Ctrl+B` |
| `I` | 斜体 | `Ctrl+I` |
| `HL` | 高亮 | — |
| `FN` | 脚注 | — |
| `H ▾` | 标题（H1–H6 下拉） | `Ctrl+1`…`Ctrl+6` |
| `≡` | 列表 | `Ctrl+Shift+[` / `Ctrl+Shift+]` |
| `🔗` | 链接 | `Ctrl+K` |
| `📎` | 文件引用 / 文件图片 / 文件嵌入 | — |
| `🖼` | 图片 | `Ctrl+Shift+I` |
| `↶ ↷` | 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| `?` | 帮助 | — |
| `⊞` | **百宝箱** | — |

`Ctrl+D` 删除线、`Ctrl+U` 下划线也在快捷键里，只是没占工具栏的位置。

## 百宝箱

工具栏最右边的 `⊞` 是**百宝箱**——一个可收起的浮动面板，装的是「跟当前文档有关但不常按」的开关。

![百宝箱](/shots/guide/editor-toolbox.png)

里面至少有三样：

| 项 | 作用 |
| --- | --- |
| **编写模式** | 在「所见即所得」和「斜杠命令」之间切 |
| **AI 补全** | 开关写作时的 AI 自动续写 |
| **大纲** | 显示 / 隐藏当前文档的目录 |

点 `⊞` 展开，点别处自动收起。

## 斜杠命令

在编辑器里输入 **`/`**，会弹出一个命令菜单：

![斜杠命令菜单](/shots/guide/slash-menu.png)

菜单里是所有能插入的东西——标题、列表、表格、代码块、图表、图片、引用卡片……打字可以筛选，上下键选，回车插入。

::: tip 这是最不用记的入口
忘了某个东西怎么插？输入 `/` 搜它的名字。比记快捷键快。

（如果 `/` 没有反应，检查 设置 → 编辑器 里的「斜杠命令」开关是否开着。）
:::

## 大纲

一篇长文写到后面，最需要的是「我在哪」。

打开大纲（百宝箱里，或编辑器右栏），会列出当前文档的所有标题，点一下跳过去。

![编辑器大纲](/shots/guide/editor-outline.png)

大纲跟着光标位置高亮当前所在的小节——滚到哪，它指到哪。

## 查找与替换

`Ctrl+F` 呼出查找栏，再按一次（或点展开箭头）切到替换。

![查找替换](/shots/guide/editor-find.png)

在源码模式下，查找替换作用于原始 Markdown 文本；在所见即所得模式下，作用于你看到的文字。

## 状态栏

编辑器最下面一行从左边到右边依次是：

![状态栏](/shots/guide/statusbar.png)

| 位置 | 内容 |
| --- | --- |
| 左 | **字数 · 词数 · 行数**（实时更新） |
| 中 | 当前文件完整路径 |
| 中右 | **插件箱**入口 |
| 右 | **Ln, Col**（光标行列） |
| 右 | **UTF-8**（文件编码） |
| 最右 | 版本号与当前档位 |

::: tip 窄窗口时状态栏会自己收
窗口拉窄时，固定标签（编码、行列）不缩不折，只有中间那条**文件路径**会缩短——但文件名永远保留。

所以你永远能看到自己在编辑哪个文件，哪怕窗口只有半个屏宽。
:::

## 自动保存

编辑时自动保存，不用按 `Ctrl+S`。

**默认打开**。想关：设置 → 通用 → 自动保存。关掉之后 `Ctrl+S` 才真正必要。

::: tip 自动保存 ≠ 没有撤销
自动保存的是「文件内容」，撤销历史是独立的。写了不想要的，`Ctrl+Z` 照样能退回去。
:::

## 打开多个文件

编辑器顶部是标签栏，同时开多个文件，点标签切换，中键或标签上的 `×` 关闭。

![编辑器标签栏](/shots/guide/editor-tabs.png)

同一时刻只有一个文件是「当前文件」——它决定：
- AI 对话的默认上下文
- 状态栏显示谁
- 大纲显示谁

## 让 AI 帮你写

编辑器里最常用的三个 AI 入口：

| 入口 | 怎么做 |
| --- | --- |
| **选中一段，让 AI 改** | 选中文字 → 右键菜单 → 选一个 AI 动作 |
| **按当前文件提问** | 右侧对话边栏，输入框会自动带上当前文件 |
| **边写边续** | 百宝箱里开「AI 补全」，写作时它给你灰色的续写建议，`Tab` 接受 |

三个入口的细节见 [AI 对话](/guide/chat) 与 [编辑器进阶](/guide/editor-advanced)。
