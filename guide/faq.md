# 常见问题 FAQ

按**症状**找，不用先知道术语。

---

## 装 / 启动

**Q：Windows 上双击安装包提示「Windows 已保护你的电脑」？**
点「更多信息」→「仍要运行」。新发布的安装包信誉还没攒够，与文件安全性无关。

**Q：macOS 提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」？**
在「访达」里**右键** Notrat → 「打开」→ 再点一次「打开」。**直接双击不行**，必须是右键菜单里那个「打开」。

**Q：macOS 每次弹「notrat 想要使用钥匙串中的机密信息」？**
Notrat 用它加密保存 API Key。未签名的版本系统每次都会问。选「始终允许」可只输一次；拒绝了 Key 会退回明文保存，功能不受影响。

**Q：macOS 退出时弹「意外退出」？**
这是已知问题的表现之一，与退出时的收尾流程有关。升级到修复版本即可。

**Q：Linux 双击图标打不开，只有命令行能启动？**
常见于 Fedora 42+、Ubuntu 24.04+ 等较新发行版（它们在收紧非特权用户命名空间）。先在**终端跑一次**看报错：

- `SUID sandbox helper ... user namespaces` → 沙箱被禁，用 `--no-sandbox` 兜底，或开启 userns
- `libnss3.so` / `libgbm.so` 找不到 → 缺运行时库
- `libfuse.so.2` 找不到 → AppImage 缺 FUSE2，改用 `--appimage-extract-and-run`，或改装 `.rpm`

**Q：Fedora 缺库？**

```bash
sudo dnf install -y nss nspr gtk3 atk at-spi2-atk at-spi2-core \
  libX11 libxcb libXext libXcomposite libXdamage libXfixes libXrandr \
  libXScrnSaver libXtst mesa-libgbm mesa-libGL libdrm libxkbcommon \
  pango cairo expat alsa-lib cups-libs dbus-libs libnotify
```

**Q：临时先跑起来？**

```bash
./notrat --no-sandbox
# 或
ELECTRON_DISABLE_SANDBOX=1 ./notrat
```

关沙箱会略降安全性，仅作临时兜底。

## 登录 / 档位

**Q：重启应用后要重新登录？**
正常不会，令牌会自动续期。若每次都要重登，检查系统密钥库服务是否被安全软件拦了。

**Q：突然跳回登录页？**
会话真失效了（令牌过期 / 账号在别处登录把你顶下线 / 设备超限被移除）。重新登录即可。

**Q：状态栏显示「纯净版」，但我是付费用户？**
登录态丢了。重新登录，档位会自动恢复。

**Q：能不能手动解锁会员功能？**
不能。档位是主进程签名下发的，改浏览器里的变量无效。

## 写东西

**Q：`Ctrl+/` 切源码模式偶尔没反应？**
先点一下编辑区获取焦点再按。

**Q：列表里 `Tab` 不缩进？**
确认光标在列表项内。代码块里的 `Tab` 是缩进代码，不切列表层级。

**Q：复制表格粘到别处格式乱了？**
用源码模式（`Ctrl+/`）复制原始 Markdown。

**Q：打开很大的 Markdown 很慢？**
超过 **10 万字符**的文件，编辑器会跳过富文本直接进源码模式——如果你打开一个巨大的文件发现是源码视图，那是正常行为，不是出错。

**Q：粘贴的图片存哪了？**
`<工作区>/.notrat/images/`。**别单独移动或重命名这个目录里的文件**，正文按相对路径找它们。

## 文件 / 工作区

**Q：双击 `.md` 没用 Notrat 打开？**
安装时没勾选文件关联，或被别的软件抢了。重装时勾上，或在系统「打开方式」里选 Notrat。

**Q：文件树里看不到某个文件？**
检查是否被搜索框过滤；隐藏文件与 `.notrat` 这类目录可能默认不显示。

**Q：换台电脑怎么把笔记带过去？**
工作区就是一个普通文件夹——整个拷贝过去，在新机器上「打开工作区」指向它。图片、目录结构全在。

**Q：某个工作区的文件夹被我删了，应用一直报错？**
Notrat 会明确告诉你路径不存在并让你重选，不会假装打开成功。选新位置或关掉这个工作区即可。

## AI

**Q：对话输入框写着「升级到基础版 / 专业版后即可开聊」？**
两个可能：① 没登录 / 是纯净版；② 登录了但没配 AI 服务商。→ [接入 AI 服务商](/guide/ai-setup)

**Q：AI 回复中断 / 出现空回复？**
已输出的部分会保留。点停止后重新发送，或换模型、调小最大长度后重试。

**Q：提示「超出上下文窗口」？**
开新会话，或让它先压缩历史；删掉不需要的附件与大引用。

**Q：AI 改文件前没问我？**
默认每次写操作都要确认。检查输入框工具条上的**「完全访问」**是不是被点亮了（红盾 = 已放开；同一开关在 设置 → 扩展管理 → 连接器（MCP）里叫「自动授权连接器（MCP）工具」）。

**Q：它改错了，能撤回吗？**
用编辑器的撤销（`Ctrl+Z`）。文件在版本控制下时也可以用 Git 回退——**让 AI 改代码时建议工作区在 Git 里**。

**Q：模型列表拉不出来？**
先确认能上网、Key 有额度。第三方中转不一定完整实现官方协议——换成官方地址试一次，能区分是服务端问题还是配置问题。

## 扩展

**Q：装了插件没任何反应？**
先看**插件日志**：插件卡片上的 **⋯** → 「查看日志」，或插件箱里右键 → 「查看日志」。

**Q：带连接器（MCP）的插件装了不生效？**
需要**重启 Notrat**——MCP 服务器是独立子进程，要在启动时拉起来。

**Q：更新插件失败 / 报 EBUSY？**
Windows 上活进程会占住自己的目录导致文件删不掉。Notrat 已经处理了大部分情况，**最简解法：重启 Notrat 再更新**。

**Q：技能列表是空的，但目录里明明有技能？**
把设置关掉再打开一次。1.3.5 修过一处导致该页恒空的问题，升级即可。

**Q：卸载插件后它又「长回来」了？**
只删了一边的痕迹。用扩展管理或插件市场里的卸载入口。

**Q：连接器显示连上了，但一调工具就失败？**
在连接器卡片里**手动执行**那个工具试一次：
- 手动也失败 → 连接器本身的问题（路径、依赖、网络）
- 手动成功 → 检查对话里是不是用 `@` 限制了消息级的连接器

## IM 插件（远程助手）

**Q：显示「已连接」但收不到消息？**
「已连接」现在判定的是**真实登录状态**。先确认凭据真的有效（微信重新扫码），再看远程助手的实时日志。

**Q：IM 里的会话上下文太长了想重置？**
在该会话里发 `/new`（或 `/clear`、`/reset`）。

**Q：IM 收到的文件路径不对？**
远程助手会按优先路径解析并做校验，异常时尝试本地恢复。确认工作区已正确打开。

## 界面

**Q：窗口拉到很窄，按钮都不见了？**
活动栏装不下的导航按钮会折进「**更多**」菜单；分隔线以下的（导出 / 便签 / 公告 / 登录 / 设置）**永远不折叠**。

**Q：状态栏路径被截断了？**
窄窗口下只有中间的**文件路径**会缩短，**文件名永远保留**。

**Q：换了主题但某个地方颜色没变？**
大面积填充与控件跟随主题；**语义色**（成功绿、危险红、警告黄）只用在小的状态标记上，这是有意的——不然换主题时界面会花。

**Q：deep dark 模式下 logo 看不见？**
不会——Logo 在深色档会自动反白。如果真遇到某处 Logo 没自适应，那是个 bug，反馈一下。

## 性能

**Q：长对话变卡？**
开新会话（`/new`）试试。超长的工具输出会被自动裁剪。

**Q：开着开发版跑久了变白屏？**
开发版（`yarn dev`）长时间运行可能因为热更新堆积而白屏。**刷新一下就好**（打包版没有这条路径）。

## 还是没解决

1. 活动栏 **帮助** 面板 → 有日志与反馈入口
2. 「查看错误日志」能看到应用记录的报错
3. 官网 `notrat.cn` 提工单

报问题时**带上版本号（状态栏右下角）与当时在做什么**，能省很多来回。
