# 授权商与激活码

这一页讲三件事：**授权商**是什么、**激活码**怎么拿怎么兑、买到授权后**怎么核验**真伪。

平台上有两条各自独立的线，别混在一起：

- **授权商（Reseller）**：经官方授权的经销商。它拿到的是**授权证书码**（`NR-` 开头），用途是**向买家证明「我是官方授权渠道」**。
- **激活码**：真正激活订阅的凭证。买家拿到激活码后，在自己账号里兑换，订阅随即生效。

授权商卖给你的东西是**激活码**；你拿去验证的凭证是**授权商的证书码**。两者不是一个码，也各自有独立的有效期。

## 授权商模式

### 授权商能拿到什么

企业账号经平台审核、开启授权商资格后，在团队中心会多出一个「授权证书」页签，里面有三样东西：

| 东西 | 作用 |
| --- | --- |
| **授权商编号** | 4 位顺序编号（`0001`、`0002`…），公开、可印在授权牌上、买家能记住。同一位授权商重发证书时编号不变。 |
| **授权证书码** | 由「授权商编号 + 随机防伪段 + 校验字符」组成。发给买家，买家在官网验证页核验你的官方授权身份与有效期。 |
| **实时身份校验码** | 6 位滚动码（RFC 6238 TOTP，每 30 秒变化）。买家索要时当场报出，证明此刻确实持有后台——截图和旧码过不了这一关。 |

### 证书码长什么样

新签发的证书码是 **两段式**：

```
NR-0001-XXXXX-XXXXX
│  │    │     └── 校验字符（防手抄错输）
│  │    └──────── Crockford Base32 随机防伪段（9 位，去掉了易混的 0/O/1/I）
│  └───────────── 授权商编号（公开、可识记）
└──────────────── 固定前缀
```

- 防伪段是加密级随机、配合限流不可枚举——所以证书码没法猜、没法批量撞。
- 校验字符拦的是**手抄错输**（把码抄错一位时提示核对），不承担防伪职责。
- **旧版证书码（`NR-XXXX-XXXX-XXXX`，全随机段）继续可以验证**，格式升级不会让已签发的码失效，授权商不需要为此重新签发。
- 对外查询时证书码会打掩码显示（`NR-0001-7Q***-*****`）：编号公开、防伪段保密。完整码只有持有人在自己的后台能看到。

### 有效期、吊销与换码

- 证书签发时**默认 2 年有效**，也可以是长期（跟随合作协议）。
- 证书**可吊销**：一旦吊销立即失效，买家再验证会看到「授权已被官方终止」，同时记录吊销原因。
- 证书码疑似泄露时，持有人可在后台**一键换码**：旧码立即作废，签发一张**同编号**的新码（只换防伪段），需要把新码重新分发给客户。仅建议在疑似泄露时使用。

::: warning 授权范围是有限的
每张证书可带一条**授权范围说明**（例如「仅限专业版销售」），会原样展示给买家。核验时请连范围一起看——**超出该范围的销售行为不在官方背书之内**。

此外：

- 证书**过期或被吊销**后，官方不再为该授权商的销售行为背书。
- 授权商资格被撤销时，其名下签发的**全部客户授权码一并失效**。
:::

### 客户授权码（一客一码）

主证书码是**持码凭证**——谁拿到都能对外宣称自己是这位授权商，泄露风险的粒度太粗。于是有了向下沉一级的客户授权码：

- 格式 `ND-0001-XXXXX-XXXXX`（`ND` 前缀，独立命名空间，编号与随机段的算法跟主证书一致）。
- 授权商在团队中心**自助签发 / 吊销**，每个下游客户或渠道一码。
- **绑定授权商身份、与单张主证书解耦**：主证书换码或续期，不影响已发出的客户码；但授权商资格被撤销、或名下主证书全部失效时，客户码连带失效——防的是「离职员工带走客户码继续卖」。
- 买家验证客户码时，看到的是：授权商身份 + 「该客户渠道已获得其官方授权」+ 渠道标签；被吊销的码会显示吊销原因。

### 授权商等级与折扣

在证书化校验之上还叠了一层等级体系，参数全部由平台管理员在后台配置、改动即时生效。默认阶梯：

| 等级 | 累计充值门槛 | 购买折扣 |
| --- | --- | --- |
| 基础 | 0 元 | — |
| 铂金 | ¥1000 | 5% |
| 钻石 | ¥10000 | 10% |
| 区域 | ¥50000 | 15% |

- **自动升级**：按累计充值额匹配最高门槛等级，**只升不降**；合同制的区域授权商可由管理员手动锁定等级。
- **充值赠送**：按「等级 + 单笔金额区间」匹配赠送规则，多条命中时取赠送最多的那一条。
- **折扣怎么算**：生成激活码计价时，取「全局/定向折扣」与「等级购买折扣」中的**最大者**——不是叠乘。管理员只调一个数就能精确控制到手价。

等级/赠送的计算都在支付成功结算内完成，且是 best-effort：算失败只记日志，**不会阻断支付结算本身**。

## 激活码：怎么获得

| 渠道 | 说明 |
| --- | --- |
| **官方购买** | 在 [notrat.cn](https://notrat.cn) 登录后购买订阅或充值余额，下单即到账，无需另外兑换。 |
| **授权商 / 经销商** | 向官方授权的经销商购买。**买之前先到[验证页](https://notrat.cn/verify)核验对方的证书码是「官方认证授权商」**，见下文。 |
| **客服或活动发放** | 活动、补偿、售后等场景由官方直接发码。 |
| **团队 / 企业管理员** | 团队管理员在团队中心自助生成，发给员工或客户。分两种：**团队成员激活码**——兑换时自动加入该团队并享受团队名下的定向折扣；**普通激活码**——只激活订阅，不加入团队。 |

::: warning 只从官方或官方授权的渠道购买
请勿从身份不明的第三方购买授权码（激活码）。因从未经授权的渠道获取授权所导致的授权无效、费用损失或账号风险，由您自行承担。购买前请先核验对方的授权证书码。
:::

## 激活码：怎么兑换

1. 打开 [notrat.cn/dashboard](https://notrat.cn/dashboard) 并登录（桌面端从「用户中心 → 余额充值」也可直达）。
2. 找到首页的**「兑换激活码」**卡片，粘贴激活码，点「兑换」。
3. 兑换成功后订阅**立即生效**，套餐状态会同步刷新；桌面端可在「用户中心 → 订阅套餐」看到。

<!-- shot: platform/redeem-code | 网页端用户中心首页的「兑换激活码」卡片：输入框与兑换按钮 -->

关于兑换，有几条要知道：

- **限流**：同一账号连续 **5 次**兑换失败会锁定 **5 分钟**，期间不再受理。所以码要先核对清楚再提交，别连点。
- **时长看码**：兑换后拿到的是**限时订阅**还是**永久买断**，由这张码上落库的时长决定。限时订阅自**兑换当日起算**。
- **同档累加、低档冻结**：同类档位的时长会累加；被更高档位占位时顺延；低档位的计时在更高档生效期间**暂停**，更高档到期后自动恢复。界面上的「已冻结、到期后自动恢复」就是这个语义。
- **码本身也有期限**：激活码需要在生成后的同一时长内兑换（永久码长期有效）。过期码兑换会直接报错。

::: warning 激活后不予退款
鉴于数字授权在交付后即可立即使用且不可回收，**买断授权一经激活，原则上不予退款**。如发生支付错误、重复扣款等情形，请于付款之日起 **7 日内**凭有效凭证联系 we@nestmold.cn，我们将在核实后依法处理。详见[用户协议](/platform/user-agreement)第 3.3 条。

激活码**不得转卖、出借、出租**（含共享账号、共享授权文件、群组拼单），详见[用户协议](/platform/user-agreement)第四条。
:::

## 买家如何核验（授权验证）

官方验证页：**[notrat.cn/verify](https://notrat.cn/verify)**

授权商会把**证书码**或**带码的验证链接**（`https://notrat.cn/verify?code=NR-...`）发给你。打开链接会自动填入并核验，也可以手动输入。

结果一共有六种：

| 结果 | 颜色 | 含义 |
| --- | --- | --- |
| `valid` | 绿色 | **官方认证授权商**，可以放心交易。 |
| `expiring` | 琥珀 | 授权 ≤30 天到期，会显示剩余天数。 |
| `expired` | 灰色 | 授权已过期，官方不再背书其销售行为。 |
| `revoked` | 红色 | 授权已被官方终止（证书被吊销，或该企业被禁用/取消授权资格）。 |
| `invalid` | 琥珀 | 以 `NR` 开头但格式或校验位不通过——提示你核对输入，**不是**「未找到」。 |
| `not_found` | 红色 | 该码不在授权名单中。 |

判定顺序是：企业非正常状态或非授权商 → `revoked`；证书已吊销 → `revoked`；已过期 → `expired`；30 天内到期 → `expiring`；否则 `valid`。

<!-- shot: platform/reseller-verify | notrat.cn/verify 授权验证页：「官方认证授权商」绿色结果卡、有效期与防伪校验码 -->

### 为什么截图不算数

验证结果会附一个**防伪校验码**（签名回执），它由官方服务器**实时签发**，覆盖了验证时间和一次性随机数：

- 别人**截图**给你看没用——旧截图对不上新的验证时间，复验必然不通过。
- 钓鱼站**伪造**不出有效回执——它没有服务端密钥（密钥可轮换，轮换即让历史回执全部失效）。

页面还会显示官方域名提示条。**以验证页的实时结果为准，不要相信转发的截图。**

## 验证接口

公开接口，无需鉴权：

```
GET /api/resellers/verify?code=NR-0001-XXXXX-XXXXX&nonce=<可选，一次性随机数>
```

- 响应包含状态、授权商名称、等级、类型、有效期、验证时间，以及上述**签名回执 `receipt`**。
- 响应中的证书码按掩码返回（编号公开、防伪段保密）。
- **限流**：按 IP 限流（当前为 30 次 / 分钟）。
- **审计**：每次验证都会落一条日志（码、结果、IP、UA、时间），用于识别撞码探测。

管理端接口（需管理员权限）：

| 接口 | 用途 |
| --- | --- |
| `GET/POST /api/admin/resellers/:id/certificates` | 查证书列表 / 签发证书（选有效期、授权范围） |
| `PUT /api/admin/resellers/:id/certificates/:certId/revoke` | 吊销证书（必填原因，原因入审计） |
| `PUT /api/admin/resellers/:id` | 开启或关闭授权商资格 |
| `/api/admin/reseller-tiers`、`/api/admin/reseller-bonus-rules` | 等级阶梯与充值赠送规则 |

授权商自助接口（登录后）：

| 接口 | 用途 |
| --- | --- |
| `GET /api/enterprise/reseller/certificates` | 我的证书 |
| `POST /api/enterprise/reseller/certificates/:id/rotate` | 换码（旧码立即失效） |
| `GET/POST /api/enterprise/reseller/derived` | 客户授权码列表 / 签发 |
| `PUT /api/enterprise/reseller/derived/:id/revoke` | 吊销客户授权码 |
| `GET /api/enterprise/reseller/totp` | 实时身份校验码 |

::: warning 部署注意
生产环境必须设置环境变量 `RESELLER_VERIFY_HMAC_KEY`（32+ 随机字节），否则会退用开发密钥——那意味着任何人都能伪造出「有效」回执。建议定期巡检验证日志中同 IP 的高频失败记录（撞码探测特征）。
:::

## 常见问题

**Q：激活码能退吗？**
数字授权一经激活即可使用且不可回收，**原则上不予退款**。支付错误、重复扣款请在付款之日起 7 日内凭有效凭证联系 we@nestmold.cn。

**Q：一个激活码能用几次？**
以码上设定的**可用次数**为准，达到上限即提示「激活码已被使用」。签发时即已固定，兑换前无法自行查看。

**Q：兑换提示「激活码已失效」「已过期」怎么办？**
分别对应码的状态被置为失效、码本身已过兑换期限。联系发码方（客服、活动方或授权商）核对。

**Q：兑换后界面没立刻变？**
套餐状态可手动刷新：桌面端「用户中心 → 订阅套餐」右上角的刷新按钮。若仍不对，检查兑换的码对应的档位与版本是否与预期一致。

**Q：同一个激活码能在几台设备上用？**
设备数限制按**授权等级**走，超出时最早登录的设备会被自动登出（FIFO）。已授权设备可在「用户中心 → 我的设备」查看和移除。

**Q：授权商的证书过期了，我手里的客户码还有效吗？**
会连带失效。授权商资格被撤销、或名下主证书全部失效时，其签发的全部客户授权码一并失效——这正是为了防止「离职员工带走客户码继续卖」。

**Q：验证页显示 `invalid` 和 `not_found` 有什么区别？**
`invalid` 说明这串码以 `NR` 开头、但格式或校验位没通过，多半是抄错了，仔细核对即可；`not_found` 说明格式没问题但这个码不在授权名单里——两者都请暂缓交易。

**Q：怎么成为授权商？**
联系 we@nestmold.cn。平台审核后会开启你的授权商资格、分配授权商编号并签发授权证书。
