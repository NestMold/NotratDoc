# 平台文档

这一栏放的是 Notrat 平台侧的正式文档：三份法律文本，加上授权商与激活码的说明。它们同时也是 notrat.cn 官网上长期公开的页面。

## 本栏内容

| 文档 | 内容 | 线上地址 |
| --- | --- | --- |
| [用户协议](/platform/user-agreement) | 账号注册、设备授权、授权等级与付费、退款政策、用户内容归属、争议解决 | [notrat.cn/agreement/terms](https://notrat.cn/agreement/terms) |
| [隐私政策](/platform/privacy-policy) | 本地优先原则、收集哪些信息、如何使用与共享、您的权利、Cookie 与本地存储 | [notrat.cn/agreement/privacy](https://notrat.cn/agreement/privacy) |
| [服务条款](/platform/service-terms) | 服务性质、可接受使用政策（AUP）、AI 生成内容条款、IM 网关规范、技能与连接器（MCP）规则、内容审核 | [notrat.cn/agreement/terms-of-service](https://notrat.cn/agreement/terms-of-service) |
| [授权商与激活码](/platform/reseller) | 授权商模式、激活码的获得与兑换、授权验证流程、常见问题 | [notrat.cn/verify](https://notrat.cn/verify)（验证页） |

相关页面：

- [notrat.cn/dashboard](https://notrat.cn/dashboard) —— 用户中心，兑换激活码、查看订阅套餐与设备、充值余额都在这里。
- [notrat.cn/plugins/#/agreement/user](https://notrat.cn/plugins/#/agreement/user) —— 扩展市场自己的三份协议（用户协议 / 服务协议 / 隐私协议），单独成一套，不并入本栏。

::: warning 以线上版本为准
本栏的三份法律文本是整理归档版本，**线上原文才是唯一生效版本**。线上文本可能随时修订，应用内展示的与官网展示的始终是该最新版本；如本栏文字与线上版本不一致，以线上版本为准。
:::

## 三份协议的关系

三份文本同时适用，分工不同——同一件事上，看对应那一份：

| 事项 | 以哪份为准 |
| --- | --- |
| 账号注册、付费、退款、授权等级 | [用户协议](/platform/user-agreement) |
| 个人信息处理 | [隐私政策](/platform/privacy-policy) |
| 服务功能的具体使用规则 | [服务条款](/platform/service-terms) |

三份文本之间互相引用，页内已把引用处接成链接。授权商与激活码相关的操作规则，见[授权商与激活码](/platform/reseller)。

## 关于术语

三份文本里的名词是制定时的写法，为保持法律文本的准确性，本栏**原文照录、不做事后改名**。产品在 2026-10-10 起统一了一批叫法，因此阅读时可能遇到旧称：

| 文本中的旧称 | 现在的名字 |
| --- | --- |
| 插件市场 | 扩展市场（活动栏「扩展」）／设置中的「扩展管理」 |
| 专家（Expert） | 专家（智能体） |
| 远程助手 / IM 网关（Gateway） | IM 插件（远程助手） |
| 免费版（Free） | 纯净版 |

每份文本的开头都有一段同样的对照说明，标注该文里出现过哪些旧称。产品内现行术语的完整说法见[术语表](/guide/glossary)。
