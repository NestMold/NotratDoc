# 1.3.0

发布日期：2026-09-06　·　[← 上一版](/changelog/v1.2.9)　·　[下一版 →](/changelog/v1.3.1)

**一句话总结：应用内市场一口气上了「插件」「专家」两个新货架，网页详情页点「一键安装」就能唤起 Notrat 装好；插件面板的报错不再糊脸、圆钮收进状态栏；长对话压缩把删掉的内容留档、再也不丢；主页输入框可以直接粘贴图片了。**

---

## 🏪 市场四货架：技能、MCP、插件、专家一次逛全

- **新增「插件」「专家」两个货架**：与已有的技能市场、MCP 市场并列，读 Notrat 官方注册表；安装即校验、装完即启用（和手动放进插件文件夹效果完全一致），「已安装 / 可更新」徽标直接可见。
- **专家 = 一整套技能组合包**：一个调好的专属助手（人设 + 技能清单 + 关键词）+ 一批技能，一键装进 Notrat，装完就出现在工具栏的助手选择器里。技能可以内嵌（离线开箱即用），也可以引用（缺哪个当场从市场拉）。
- **插件 zip 多文件包**：带本地服务脚本、多面板真文件源码的插件不再是「一个大 JSON」，直接以 zip 分发，装的时候自动解包到插件目录，卸载递归删干净。
- **网页一键安装**：在 notrat.cn/plugins 详情页点「一键安装」，直接唤起本机 Notrat 完成安装（插件 / 技能 / MCP / 专家四类都能装），成败以提示框反馈。
- **技能货架可按分类逛**：按「办公效率 / AI Agent / 开发编程…」等官方分类浏览，点分类就能看到该类的完整清单。
- **「一键安装」更可靠**：便携版、改过安装目录、旧版本残留等情况下网页按钮可能唤不起，现在启动时自动修复，不再点着没反应。

## 🧩 插件面板：报错不再糊脸、入口更清爽

- **修复「纯界面插件装不上还毫无提示」**：只有界面面板、没有命令/服务的插件，之前会被误判为「空包」静默拒收；现在能正常装上，装失败时也会给出原因，不再无声吞掉。
- **报错从「糊一脸」到「一行说清」**：插件出错不再把一大段晦涩的错误 JSON 原样铺在面板里，而是摘出关键一句、其余折叠进「详情」，并提供「重试」。
- **面板标题不再重复出现两遍**。
- **左下角 🧩 圆钮退休，收进状态栏**：入口变成底部状态栏一个低调菜单项，功能不变、界面更干净。
- **任何面板都能「全页打开」**：状态栏菜单里每个面板悬停都有 ⛶ 按钮，一键放大成全幅标签页查看，看完关掉即可。
- **「打开方式」每个面板自己定**：右键面板可选「弹窗还是完整页面」，选定后所有入口（活动栏 / 工具栏 / 状态栏）统一按你的偏好打开。
- **修了几个小毛病**：插件拿不到当前工作区、迁移后磁盘上的新版本被回滚、设置页里点「全页打开」没反应——都已修复。

## 🎯 技能调度详情：更清爽

- **完成态收成一行**：加载完只显示「✓ 已加载 N 个技能」一行，不再把几十个技能名重复列两遍。
- **加载中不再重复**：进行中只显示进度两排，纯选择阶段才显示「已选」。
- **内部路由助手不再出现在 Agent 列表**：过程只在「技能」徽章的调度详情里完整呈现，不再多出一张绿色卡片。

## 💬 聊天稳定性

- **新会话第一条消息发不出**：已修复。
- **登录跳转有提示**：登录后回到应用会弹提示，不再无声返回。
- **关闭「思考」时彻底不输出思考链**：即使服务端默认开思考，也强制关闭。

## 🧾 追问步骤：能自填、更抗错

- **追问选项支持自由输入**：预设选项之外可以自己填（比如预算「300 元以内」），预设与自填可混用。
- **中文弯引号不再解析出错**：AI 偶发用弯引号（“ ”）写参数时，之前会解析错，现在能正确读出。

## 🗜️ 长对话压缩：删掉的内容留档，再也不丢

- **压缩不再丢原文**：压缩移除的对话会先完整存到工作区的归档文件里，并把这个位置告诉 AI——之后缺细节时 AI 能自己去翻，而不是永远找不回。
- **轻压缩也留档**。
- **多段摘要合并不再「二次截断」**：合并时宁可多花点篇幅，也把具体事实（项目名、路径、命令、数字、结论、待办）一条不丢。

## 📋 编辑器：表格里划词，复制不再变整张表

- 之前在一张表格里选中一段文字复制，会莫名其妙复制出整张表。现在只复制你选中的内容，粗体 / 代码 / 链接等行内格式保留。

## 🖼️ 主页输入框：直接粘贴图片

- **欢迎页输入框支持粘贴图片/文件**：截图、剪贴板里的图片、复制的文件，Ctrl+V 直接贴进发送框，和拖文件进来一样。
- **引用更直观**：图片显示缩略图，其它文件显示对应图标。

## 🛠️ 给插件开发者

- **装前就能自查**：命令行工具 plugin-panel-check，无需开界面试错。
- **「运行状态」监视器**：插件页可开启，查看各进程 CPU / 内存占用（界面面板共用同一渲染进程，显示的是应用级而非单插件级，口径透明）。
- **插件身份走安全通道**：插件要用户绑定（昵称 / 头像 / 按插件计费）时走专用安全通道，你的登录凭证绝不会泄露给插件代码。
