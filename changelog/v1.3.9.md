# 1.3.9

发布日期：2026-11-18（已上线）　·　[← 上一版](/changelog/v1.3.8)

**这一版**：内置浏览器做成两套真正能用的引擎（极简 / 极速），能带登录态和扩展、能全屏、能右键引用、能 Ctrl+滚轮缩放，AI 也能直接操作；PPT 缩略图可以拖动排序；文件树拖进侧栏不会再变成文字引用；AI 读大文件会按窗口分段。

## 🆕 新功能速览

- **AI 直接登录**：在 设置 → AI 或「添加服务商」里直接用官方账号登录 DeepSeek / Kimi Code / xAI / GitHub Copilot / GPT（Codex），也可以读取本机 Claude Code 的登录。**登录一次就多一条服务商**，同平台登录两个账号就有两条，不用在账号列表里换来换去。点「添加」会先问是「直接登录 AI 平台」还是「使用 API Key」。
- **剩余额度**：服务商列表每条右侧多了一个仪表按钮，点一下查余额 / 剩余额度；API Key 方式的 DeepSeek、Kimi / Moonshot、OpenRouter、SiliconFlow 也能查。NewAPI / OneAPI 补上了网页登录令牌（Access Token）的用户头识别；小米 MiMo、MiniMax 暂不支持额度查询，条目上不会显示余额查询入口。
- **登录只在「添加」里出现**：「添加服务商」第一步只出两张方式卡，选了「直接登录」才展开平台列表；设置页本身不再常驻一块登录区，平台图标都换成了真实品牌 logo。
- **GPT 合并 Codex**：品牌网格不再单列「OpenAI Codex」；GPT 卡上同时有「API Key」和「设备码登录」，两种接入方式并排。
- **专家分范围**：同一个专家可以只在全局、某个工作空间、或某个工作区里出现；设置页可按范围筛选，编辑页直接切换。
- **插件启动封面**：插件可以带一张自己的开机画面，在 设置 → 外观 → 启动封面 里选用，**下次启动生效**。
- **插件主题**：插件可以往「全部主题」里追加一套配色，选中即套用，随时切回内置主题。
- **插件箱更干净**：只显示真正有界面可打开的插件；主题、技能集合这类插件不再占一格。
- **扩展市场列数自适应**：插件 / 技能 / 连接器市场的卡片会跟着面板宽度自动增减列数，不再卡在「这一档只能四列」的断点上。
- **连接器（MCP）可选保存范围**：新建或编辑连接器时，表单顶部直接选「全局 / 工作空间 / 工作区」；编辑时改范围会把这条连接器搬过去，不会在旧范围留一份。JSON 批量导入也按所选范围保存。
- **插件也支持三档范围**：市场安装时会问装到全局 / 工作空间 / 工作区；扩展管理 → 插件卡片底行显示当前范围，⋯ 菜单可迁移；目录型（zip）插件包现在也能迁移，不再只有单文件插件可迁。
- **导入 dsh（DeepSeek Harness）插件**：插件箱 ⋯ 菜单可直接填 GitHub 地址或本地目录。插件元数据和 `skills/*.md` 会导入，技能导入后立即可用；dsh 的 Cordis 工具代码不在 Notrat 里运行，需要工具时走连接器（MCP）桥接。这是**部分适配**，不是完整兼容。
- **连接器按需启动**：启用的 MCP 不再在应用启动时全部拉起，只读工具清单快照；真正调用某个工具时才启动对应子进程。设置里关闭连接器会立即停止它，不再出现「已禁用却还连着」。
- **API Key 服务商卡片**：换成真实品牌图标，卡片从上下结构改成左右结构（左图标、右名称+说明），列数也随宽度自适应。
- **窄窗口不横向溢出**：通用、外观、编辑器、面板、AI 模型、远程助手、扩展管理、知识库、提示词、模型用量统计、开发者这些设置页里的多列网格改成「最小宽度不超过容器」的自适应轨道；开发者/MCP 的 11/12 列表单行改成可换行布局；内容区不再被左侧导航挤到窗口外，右上角关闭 × 和右侧开关/下拉不会再被裁掉，右侧也补了固定留白，不再贴死窗口边缘。
- **设置页更好读**：专家页和设置里的小字整体放大一档，说明文字改短、改清楚。
- **内置浏览器两套引擎**：极简模式轻量、可划词引用；极速模式是内置真浏览器，能带登录态和扩展、不受网站「禁止嵌入」限制。按站点记住选择，随时在地址栏右侧切换；外置 Chrome 仍保留。
- **浏览器里能右键、能引用、能缩放**：网页里右键有复制 / 打开链接 / 复制图片 / 引用到聊天 / 引用元素到聊天；Ctrl（⌘）+ 滚轮按 10% 档位缩放，工具栏会显示当前百分比。极速模式里的全屏按钮也能正常进全屏。
- **AI 可以直接操作内置浏览器**：读页面、点按钮、填表单、截图都能在极简 / 极速两种模式里执行，优先走极速模式；「启用完整 CDP 访问权限」面板里可以一键把浏览器连接器装进扩展管理。
- **PPT 缩略图拖动排序**：左栏「幻灯片」里的页面缩略图可以直接拖到任意位置，有蓝色插入线；拖到上下边缘会自动滚动，动画和页序一起重排，右键的上移 / 下移还在。
- **电脑控制可见光标**：AI 操作电脑时，鼠标位置会出现独立光标，并显示「Notrat 正在控制电脑」的提示，不再只能看日志猜它在点什么。
- **AI 运行时（Harness）**：AI 能直接读写工作区文件、执行命令、调用连接器和插件工具；任务可以拆给子 agent 并行，结果回到主对话；高风险动作先询问。编辑消息、重新生成或停止时只作用于当前会话，不会打断另一个并行对话。
- **AI 读大文件分段**：`read_file` 默认只读 2000 行 / 约 20 万字符，超出会明确告诉你从哪个 offset 继续；流式读取读到窗口末尾就停，不再把整份大文件读一遍。
- **文件树与 IDE 对齐**：打包版 Ctrl+W 可以关标签；选中文字可以直接拖到 Sidebar 变成引用；文件删除失败会提示「被占用 / 没有权限」；视频文件有 VID 图标；工作区根可以拖进对话或右键「添加到对话」。
- **@ 面板跨工作区**：@ 文件面板会列出整个工作空间里所有工作区的文件，不再只看当前工作区；打开时第一帧就定位在输入框上方，不会先闪到左上角。
- **登录页 / 欢迎屏自适应窗口高度**：小窗口下不再整页出现滚动条，表单和按钮按可用高度收紧，底部入口始终能看到。
- **英文界面全链路英文**：界面切到 English 后，提醒 AI 用英文回答，不再出现「界面英文、回复中文」；余额 / 额度查询结果、技能选择卡、工具卡名称、思考过程标题和进度文案也都跟着界面语言走。

## 🌐 内置浏览器：极简 / 极速两套引擎

**现在**：编辑器里的网页标签可以在地址栏右侧切换两种模式，并按站点记住：

- **极简模式**：最轻，打开即用，支持划词引用和元素引用；受网站「禁止嵌入」限制，打不开时会引导切到极速模式。
- **极速模式**：内置真浏览器，支持登录态、Cookie 延续和扩展，不受嵌入限制；代价是内存占用更高。登录态会在切换模式时尽量同步过去。
- **外置 Chrome**：仍然保留，适合需要独立浏览器环境的场景；AI 可以通过 CDP 接管。
- **右键菜单**：网页里右键可以复制链接 / 图片、打开链接、复制 / 粘贴 / 全选，以及「引用到聊天」「引用元素到聊天」。
- **缩放**：Ctrl（⌘）+ 滚轮按 10% 缩放，范围 25%–300%，工具栏显示当前百分比。
- **全屏**：视频或页面里的 HTML5 全屏按钮可以正常进入 / 退出。
- **AI 操作**：读页面、点击、输入、截图都能在两种内置模式里执行；需要完整 CDP 调试时，可在「启用完整 CDP 访问权限」里一键安装浏览器连接器。

## 🎞 PPT：缩略图拖动排序

- 右键菜单里的「上移 / 下移」仍然保留。

## 📄 AI 读取大文件：默认窗口 + 续读提示

**现在**：AI 的 `read_file` 默认只读 2000 行、约 20 万字符；超过时会明确返回类似 `Use offset=2000 limit=2000 to continue` 的提示，AI 会从那里继续读，而不是一次把整份大文件塞进上下文。10MB 以上的文件改成流式读取，读到窗口末尾就停，不再把整个文件读完。

- @ 文件面板会扫描整个工作空间里的所有工作区，打开时就定位在输入框上方。

## 🤖 用官方账号登录 AI

**现在**：设置 → AI 顶部、以及「添加服务商」的第一步，都可以直接登录 AI 平台，不必再去厂商后台申请 API Key：

- **添加服务商时先选接入方式**：点「添加」先只出「直接登录 AI 平台」和「使用 API Key」两张卡；选了「直接登录」之后才展开平台列表，不再一上来铺一屏按钮。添加流程底部统一成左边「返回」、右边「取消」：API Key 流程不用再翻页找取消，直接登录页右边也能随时退出。
- **登录入口只放在「添加」里**：设置 → AI 页面不再常驻登录列表；点「开始配置」→「直接登录 AI 平台」后才出现。
- **一次登录 = 一条服务商**：登录成功后直接多出一条服务商并设为当前；同一个平台登录两个账号，就是两条服务商（名称自动带序号），在模型下拉里按名字区分即可。没有单独的账号列表，也没有「切换账号」。
- **可登录的平台**：DeepSeek（浏览器授权）、Kimi Code、xAI、GitHub Copilot、GPT / Codex（默认浏览器登录，也可以选设备码）；Claude Code 则直接读取你本机已有的登录（终端里先运行 `claude` 完成登录）。列表图标都是各家真实品牌标识。
- **GPT 与 Codex 合并**：品牌网格的 GPT 卡上同时有「API Key」和「设备码登录」两个动作；原来单独的「OpenAI Codex」卡已移除。
- **自动打开浏览器**：默认会打开授权页；想自己管理多个浏览器环境时可以关掉，改成复制链接手动打开。
- **剩余额度**：服务商列表每条右侧有一个余额胶囊——没查时写「查余额」，查询中转圈，查到显示绿色余额，查不到显示琥珀色原因，点一下可重查。OAuth 方式覆盖 DeepSeek、Kimi Code、GPT、Claude Code、GitHub Copilot；API Key 方式覆盖 DeepSeek、Kimi / Moonshot、OpenRouter、SiliconFlow、智谱 GLM、OpenCode Go、Sub2API / SubAPI、OneAPI / NewAPI，其他兼容服务商也会自动尝试常见余额接口。填 API Key 的表单里是一张「账户余额」卡片，不用先保存就能查；本地模型不显示余额。
- **余额布局自适应**：多窗口结果（5h / 周 / 月）会自动换行，不再显示省略号；接口地址和模型名也跟着面板宽度伸缩。
- **API Key 表单更干净**：名称、密钥、余额、模型区下面几行解释性小字已去掉，只留字段本身和必要状态。
- **设置页小字收口**：短说明照常显示；过长的一律单行省略，鼠标悬停时用 tooltip 显示全文；状态和错误提示不截断。
- 令牌只留在本机服务商配置里，不上传；删除这条服务商即可清除。

Antigravity 的官方登录需要接入它私有的 Cloud Code 传输，当前版本还没有开放，避免出现「登录成功却没法对话」。

## 👥 专家可以按全局 / 工作空间 / 工作区使用

**现在**：专家不再只有「所有人都能用」一种。每个专家可以选：

- **全局**：所有工作区都能看到、能 @、能被自动调度；
- **工作空间**：只在这个工作空间（命名工作区组合）里出现；
- **工作区**：只在创建 / 安装它的那个工作区根里出现。

设置 → 扩展管理 → 专家（智能体）→「我的专家」顶部可以按范围筛选；点开某个专家，在「可用范围」里一键切换。安装官方专家时，弹窗里选的范围现在同时作用于专家本人和它带来的技能；更新会保留原来的范围。

**注意**：升级前就有的专家默认仍按「全局」处理，不会被藏起来；想让某个旧专家只在特定工作区出现，进编辑页点一下「工作区」即可。

## 🖼 插件可以带自己的启动封面

插件作者写法见 `docs/PLUGIN_DEVELOPMENT.md` 的「启动封面贡献」一节，仓库里也有一份示例包。

## 🐛 Sidebar：切分支后回复不再丢

**症状**：回复生成到一半，你切到另一个消息分支继续看；这条回复本该落在**发起它的那个分支**，但收尾时可能报错，或者内容没写进去。

**原因**：收尾逻辑在切分支时访问了一个还没声明的变量，触发了 JavaScript 的「初始化前访问」错误；后面的落盘就整段中断了。

**现在**：收尾会先把正文、思考、工具段完整拼好，再判断视图是否已经切走；切走时把完整快照写到发起分支，当前视图不受影响。不会再报错，也不会丢最后一段正文。

## 🐛 其它 Sidebar 修复

- **首条消息没有工具**：等待连接器工具加载的循环之前用错了判断（对 Map 取 `.length`），实际一次都没等；现在会正常等最多 2 秒。
- **直接对话专家显示失败**：正常答完时把一段统计信息当成错误文案传给了收尾函数，整轮被标成「失败」；现在正常显示完成，统计改放进运行详情。
- **权限弹窗点不动**：待处理的统一权限之前初始化成了数组，恢复出来的权限消息点「允许 / 拒绝」会报错；现在从一开始就是 Map。
- **`/skill install openclaw`**：历史别名 `openclaude` 被原样传给主进程，而主进程只认 `openclaw`；现在两种写法都会落到 `openclaw`。
- **大工具结果外置**：渲染层那套外置逻辑调用了不存在的接口，永远失败回退；已删除，统一由主进程在保存会话时把大结果压进 blob 仓，展开详情时再按需取回。
- **分支路径**：内部建分支的路径计算之前会把「先探过但不在路径上」的消息也写进去；现在只保留真正通往目标的那条链。
- **技能预检超时**：之前超时后没有任何界面反馈；现在技能按钮上会亮一个琥珀色小点，表示本轮降级为「不带技能继续」。

## 🐛 OpenCode Go：GPT-6 Luna / Gemini 4 Argon 多轮工具调用不再报协议错误

**症状**：在 OpenCode Go 套餐里选 GPT-6 Luna 或 Gemini 4 Argon，让 AI 读文件、跑命令、查资料——只要它调用了工具，下一轮请求就可能整段失败，报：

```text
OpenAI API error: {"type":"error","error":{"type":"invalid_request_error",
"message":"messages[11].toolCallId: cannot preserve this message field across
protocols; stateful assistant history requires matching provider_metadata"}}
```

同一套餐里的 DeepSeek 不会出现。

**原因**：这两款模型的「母语」不是 Chat Completions——GPT-6 Luna 走 OpenAI Responses，Gemini 4 Argon 走 Google generateContent，OpenCode Go 需要把请求翻译过去。Notrat 在多轮工具续跑时，给上游的工具结果消息里同时带了标准 `tool_call_id` 和一个内部用的驼峰 `toolCallId`；翻译层对字段是硬校验，遇到这个无法映射的字段就整条请求拒掉。DeepSeek 原生就说 Chat Completions，直接透传，多余字段被忽略，所以不报。

**现在**：发给上游的工具结果只带标准 `tool_call_id`，内部消息和渲染层仍照旧使用驼峰字段。GPT-6 Luna、Gemini 4 Argon 的多轮工具调用可以正常继续；DeepSeek 及其它 OpenAI 兼容服务商的行为不变。
