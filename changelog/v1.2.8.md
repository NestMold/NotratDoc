# 1.2.8

发布日期：2026-09-02　·　[下一版 →](/changelog/v1.2.9)

**一句话总结：打开就能聊、不用先配环境；AI 干活的过程看得见；跑再久的任务也不会被莫名掐断；设置界面终于说人话了。**

---

## 🏠 打开就能聊，不用先开工作区

- **欢迎页直接开聊**：还没打开任何项目也能在欢迎页输入框提问，回车自动开始新对话；需要读写文件时再关联工作区即可，两步随时切换。
- **输入框该有的都有**：模型、推理模式、MCP 工具、技能、文件引用、@Agent、GOAL 模式一应俱全，和侧栏完全同步——欢迎页不再是"只能看不能问"。
- **AI 会主动问你要用哪个工作区**：没开工作区时，遇到需要改代码/跑命令的任务，AI 会先问「用哪个工作区」，不再瞎猜路径或闷头干不需要的活；纯问答聊天完全不受打扰。
- **文件引用不再依赖工作区**：随时从电脑任意位置选文件（支持多选）丢给 AI，没开工作区也能引用；AI 本轮改过的文件会以卡片列在回复底部，先看正文再看"这轮改了什么"，动线更顺。
- **老用户欢迎屏更清爽**：最近使用列表在上、输入框在下，常用大按钮常驻，列表多了也不翻页；文案统一成「打开工作区」，不再一会儿"文件夹"一会儿"工作区"。

## 🤖 AI 用了哪些帮手，这次一眼看穿

- **不再偷偷调 Agent**：AI 调用任何助手前都会在回复里说明——调了谁、去干什么、结果一句话总结；内置 researcher / planner / summarizer 也只在你显式 @ 时才触发，不再被关键词巧合静默拉起。
- **Agent 活动面板自动浮现**：只要有 Agent 在跑（或刚跑完 2 分钟内），对话底部自动浮出面板，实时显示每个 Agent 在干什么、可展开看过程、可随时取消，任务结束自动收起——不用再手动展开消息去找。
- **每张 Agent 卡都写清"它是干嘛的"**：planner=任务规划、researcher=信息调研、summarizer=内容总结……不再只有光秃秃一个名字。
- **AI 能自建并长期保留专属助手**：代码审查员、翻译助手、SQL 优化师这类专职角色，AI 可以创建并保存（设置 → Agent 也能管理），以后每次对话都能直接调用——助手从"只能用内置的"变成"按需自建、持续可用"。

## ⚙️ 设置终于说人话了

- **AI 配置三步走**：① 选服务商 → ② 填密钥（或一键登录，密钥只存在你自己电脑上；Ollama 等本地服务免密钥）→ ③ 挑模型。第一次配置时还有引导卡片带路。
- **黑话全面大白话**：「Base URL」→「接口地址（一般自动填好）」、「图片视觉」→「识图能力」（发图报错就改这里）、「模型参数」→「回答风格」、「对话压缩」→「长对话处理」……一眼就懂，不用查文档。
- **开关更清楚**：36+ 处设置开关的开启/关闭状态一眼可辨，不再"开了没开傻傻分不清"。
- **模型列表更新到最新阵容**：GPT-5.6、DeepSeek V4、GLM-5.3、Kimi K3、通义 Qwen3.8、Claude 5 系……旧型号标注「旧版」，不再显示一堆早停服的模型。

## 🧭 沉浸式 AI：先选地方，再开聊

- **无工作区时左栏只列工作区**：每个工作区显示名称 + 会话数 + 最近活跃时间，点哪个进哪个；底部「打开其它工作区…」走系统选择框。想换地方？左上角「← 退出工作区」一键返回列表。
- **没选工作区就发不了消息**：输入框会提示先选工作区，回车/点发送自动弹出选择浮层，不再出现"发出去不知道聊到哪个文件夹里"的混乱。
- **正文排版升级**：全屏沉浸式下回复正文字号、行距、行宽全面加码，观感对齐侧栏水准，告别"小而稀"。

## 📂 拖文件、开文件更听话

- **从微信 / IM 直接拖文件进来**：文档、视频、任意类型都行，不再受 10MB 与格式限制（此前只能拖文本/图片/PDF/zip，微信拖文件经常静默失败）。
- **拖到哪个文件夹就进哪个**：光标正上方是哪个目录就落进哪个，不再"想拖进子文件夹结果退回父目录"，也不会进错最深层。
- **快速切换文件不再串内容**：连续点开多个文件，正文不会串到别的文件里。
- **下拉面板不再被窗口裁掉**：MCP / 技能 / @Agent / 推理模式面板会自动朝空间大的一侧弹出，靠窗顶时也能看全。

## ⏳ 稳定性：那些"莫名其妙"的毛病这次根治

- **长任务不再被误断**：装依赖、批量生图这类跑很久的任务，只要还在正常吐字/推进就不会被 15 分钟总闸掐断——判断标准从"跑了多久"改成"多久没进展"；真卡死的流仍会在 5 分钟内被兜底处理，静默防护不打折。
- **工具跑得久结果也能等到**：长工具执行不再"回调被拆、结果超时"。
- **二次启动能打开工作区了**：命令行带工作区路径再次启动（含 macOS Dock 最近工作区菜单），不再只是聚焦窗口、工作区纹丝不动。
- **滚动跟随更聪明**：只要你没主动往上滚，流式回复就会一直跟着滚到底——布局变化造成的抖动不再误判成"用户上滚"而停用跟随。
- **欢迎页发送后不再"秒断"**：从欢迎页发起对话后，回复能稳定流式输出到底。

## 🧬 进化实验室（专业版）

- **一键迁移全部档案到 V2**：不用再一个个手动迁移，已迁过的自动跳过、可反复点。
- **"总变体一直是 1"修复**：手动"进化到下一代"不再被样本数门槛卡死，随时能进化出新变体；每代至少产出一个新变体，点"进化"不再纹丝不动。
