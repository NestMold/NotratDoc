# 1.2.2

发布日期：2026-08-19　·　[← 上一版](/changelog/v1.2.1)　·　[下一版 →](/changelog/v1.2.3)

**一句话总结：插件面板能开成一整页、也能自己改样子；多个窗口各跟各的工作区、各用各的模型；模型规格表按真实数据重写，Max Tokens 默认值更合理。**

---

## 🧩 插件面板：能开成一整页，也能自己改样子

- **完整页面**：插件可以贡献主区标签页，用来放 git 图谱、看板、仪表盘这类大视图，从插件菜单打开，和文件标签混排切换。
- **右侧停靠栏改成标签式**：多个面板不再纵向堆叠，改成标签切换；宽度可以拖（240 - 560px）并记住，悬浮窗也能自由拖位。
- **插件菜单列全了所有面板**：以前只列触发型的位置，现在任何面板都能在同一处呼出。
- **右键「移动到…」多了「完整页面」**：小面板可以一键升级成全幅页面；位置会记住，也能恢复默认。
- **面板外观可以自己改**：面板外壳带上了能按插件区分的样式标识，AI 能照着它帮你改面板外观，也可以自己写样式，插件作者不用做额外适配。
- **插件能读到运行环境**：当前工作区、所在窗口、本窗口的模型、应用版本与语言主题都能直接拿到，切工作区或开新窗口会自动更新，插件不用再自己缓存这些会变的信息。
- **修好「打开某些插件面板就崩」**：部分面板（比如 Git 面板）一打开就报错，另一些则是面板内容显示得不对，两个问题一起修了。

## 🪟 多窗口：各跟各的工作区，各用各的模型

- **不再读到别人的工作区**：插件有时会读到 `C:/Users/...` 这样的默认路径；现在工作区就绪或切换后会自动刷新，用上正确的路径。
- **切工作区后不再「MCP server not connected」**：以前切完工作区，插件的工具会永久失联，只能重启应用；现在会自动重连。
- **工作区插件不再莫名消失**：插件列表短暂读空时，工作区里的插件曾被误判成「已删除」而卸载；现在不会了。
- **迁移到全局不再把插件删掉**：从工作区迁到全局时曾出现插件真被删掉、磁盘文件也没了的情况；现在迁移后插件还在。
- **每个窗口可以各用一个模型**：「当前服务商 + 当前模型」按窗口的工作区分别记忆，一个窗口切模型不再把其它窗口一起改掉；服务商列表、API Key、模型列表、温度 / Max Tokens 仍是全局一份，不用重复填。

## ⚡ 插件装得多，也不再拖住整个应用

- **导入 dsh 插件期间应用不再冻结**：以前从 GitHub 拉取时整个应用会卡住最长两分钟，窗口、托盘全都点不动；现在导入期间照常使用。
- **插件目录读取挪到后台**：以前插件越多、启动越慢；现在扫描与读取都不再阻塞启动。

## 🧠 模型规格表按真实数据校准

- **上下文与输出上限全部重写**：GPT-5.2+（400K / 128K）、GLM-5.x（200K - 1M / 131K）、Kimi-K2.5（256K）、Grok-4（2M）、DeepSeek-V4（1M）、Qwen3.5（262K）、MiniMax-M2.5 等一并到位；新增 GPT-5.5 / 5.6、gemini-3、kimi-k2.5、minimax、grok 系列条目。
- **默认 Max Tokens 改为模型输出上限的 60%**（按 1024 取整、最低 4096）：留出上下文余量，避免「输入 + 输出超出窗口被拒」，长输出的空间也够用；上限在设置里可见，也可以手动顶格。
- **旧值一次性清理**：以前被偏小的规格表自动带出来的 Max Tokens 会清掉，切模型时按新表重新带出；你手动改过的值绝不会被覆盖。

## 🔐 网络与登录态：两个环境级问题

- **开了应用内代理后 AI 全挂的问题修好**：以前代理会把发往本地的请求也一起代理走（报 Failed to connect to SSE server），代理够不到你自己的机器。现在本地地址永远直连，规则填不填都不会漏。
- **localhost 解析异常的机器也能连上本地服务**：部分机器把 localhost 解析到别处导致连接被拒，技能预检也会超时，现在一并修复。
- **没登录不会再显示已登录**：以前退出登录只清当前窗口，其它窗口、以及 24 小时内的每次启动都还显示登录态；现在登出会同步到所有窗口。
- **图谱解析加了等级门**：未登录会先跳到登录页，免费版会弹升级引导，权限对不上时不再直接放行。
