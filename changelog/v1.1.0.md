# 1.1.0

发布日期：2026-08-01　·　[← 上一版](/changelog/v1.0.9)　·　[下一版 →](/changelog/v1.1.1)

**一句话总结：AI 写的 Linux 命令终于能在 Windows 上直接跑起来，窗口最小化也能第一时间知道回复好了。**

---

## 🖥 终端：AI 写的 Linux 命令在 Windows 上也能跑

- **症状**：AI 常写 `ls`、`grep`、`find`、`sed` 这类 Linux 命令，在 Windows 上执行却报错（例如 `FIND: Parameter format not correct`），任务直接卡住。
- **现在**：内置终端新增 Shell 选择层，按命令自动挑合适的执行环境。Linux 命令走 Git Bash，PowerShell 命令（Get- / Set- / Remove- 开头）走 PowerShell，npm / git / python 这类通用命令走默认 Shell。
- **四种模式**（设置 → 通用 → 内置终端 Shell）：
  - **auto（默认）**：按命令特征自动路由，就是上面那套规则；
  - **git-bash**：全部用 Git Bash 执行，Linux 命令、管道、重定向原生可用；
  - **powershell**：保持原来的 PowerShell 行为；
  - **wsl**：用 WSL 执行，享受完整 Linux 环境。
- **自动检测**：自动探测 Git Bash 与 WSL 的安装位置并记住结果，检测不到时回退 PowerShell，不用手动配置。
- **路径写法自动转换**：Git Bash 的 `/e/foo`、WSL 的 `/mnt/e/foo` 会对应回 `E:\foo`，工作目录跟踪不会串台。
- **命令识别**：`$env:`、`~/`、`$()` 这类写法会被识别出来交给对应 Shell，判断偏保守，避免误判。
- **AI 的写命令习惯跟着变**：bash 环境下 AI 会更放心地用 `&&`、管道和标准 Linux 命令，PowerShell 环境保持原来的限制。
- 一次性执行、会话式终端、后台命令三条路径都接入了这套选择。

## 🔔 完成提醒：不盯着屏幕也不会错过回复

- **完成提示音**（设置 → 通用 → 播放完成提示音）：一段清脆的上行琶音，只在 AI 成功完成回复时响，出错或中断不响。
- **桌面通知**（设置 → 通用 → 完成桌面通知，默认开）：系统通知加任务栏图标闪烁，窗口最小化时也会在桌面右下角提醒；点通知直接回到主窗口。
- 就算 Windows 的勿扰模式挡掉了通知，任务栏闪烁仍然看得见。

## 📁 文件管理

- **外部改动有提示**：文件被别的编辑器改过时，编辑器顶部出现黄色提示栏「文件已被外部修改，是否重新加载？」，可选**重新加载**或**忽略**，你未保存的编辑不会被默默覆盖。
- **AI 动过哪些文件一眼可见**：AI 写完文件后，对应标签页显示黄点标记。
- **同一个文件不再开出一堆标签页**：路径写法（大小写、正反斜杠）统一后再判断，同一个文件只开一个标签页。

## 🐛 稳定性修复

- **修复「正在整理最终回答」不消失**：发送按钮不复位、界面一直转圈、回复像被掐断，这几个毛病以前会一起出现，现在都修好了。
- **修复连接残留**：每次回复结束后会彻底断开与模型的连接，不再有残留连接拖慢后续发送。
- **修复技能读取异常**：发送前读取技能偶发重复执行、把 CPU 占满的问题已修，表现是技能选择器不正常。
- **回复不再抢焦点**：AI 回复结束时不再强行把光标抢回聊天输入框，正在编辑器里打字不会被打断。
