# 1.3.10

发布日期：2026-11-20（已上线）　·　[← 上一版](/changelog/v1.3.9)

**这一版**：0 项新功能 · 14 处修复 · 6 项改动详情 —— 这是 1.3.9 之后的**修正版**，只修问题，不加功能。

如果你在 1.3.9 上遇到过下面这些，这一版就是为你发的：

- 删文件 / 删空文件夹老提示「被占用」，删的时候界面还要卡一下；
- 窗口偶尔莫名其妙一直置顶，切走又切回来才好；
- 新建工作区后，弹窗里找不到「附加到当前窗口」；
- 让 AI 改工作区外的文件，同一段内容被追加两遍写进磁盘；
- 两条已经生成好的回复同时点「重新生成」，两条分支一起跑、互相抢输出；
- 在主页聊过的对话，建完工作区就从列表里消失了。

## 🩹 修好了这些

### 删除不再「被占用」，也不再卡一下

文件树里删一个**空目录**，明明没有任何程序在用它，却一直提示被占用 —— 那是 Notrat 自己的文件监听在 Windows 上握着目录句柄，目录空了也一样。

**现在**：删除遇到占用时，会先临时释放自己持有的那一份监听，删完自动恢复。删除过程中的卡顿一并消除；删除失败也会明确告诉你是「被其他程序占用」还是「没有权限」，不再静默。

### 窗口不再莫名其妙一直置顶

应用没有「主窗置顶」这个功能，置顶来自 Windows 在**退出全屏后残留的置顶状态**。

**现在**：PPT 放映、HTML 预览、内置浏览器全屏退出时都会清掉这个残留；关闭放映标签、切走文件也会还原进入前的窗口状态。

### 新建工作区后，能找到「附加到当前窗口」

新目录建在**当前工作区里面**时，这个选项原先会被整条隐藏 —— 因为父目录本来就在文件树里，附加它会导致重复。

**现在**：子目录也能附加，弹窗里会说明「文件树里会重复一段，可以右键移除多余的那个」，你自己决定。

### AI 不会再写重文件

改工作区外的文件时，写入会挂起等你选「原文件上改 / 新建工作区 / 附加到当前窗口」。这段挂起期间如果上层把这次工具调用当成超时重放了一次，这段内容就会被**追加第二遍**写进磁盘。

**现在**：写入是幂等的 —— 文件末尾已经是这次要写的内容时直接跳过，重复执行不会产生第二次副作用。同时记住了你对某个目录的选择，不会再为同一个目录反复弹窗。

### 「重新生成」连点不会打架

两条已经生成好的回复，同时点「重新生成」，会各建一条分支同时跑，两条流一起往界面上写、互相抢输出。

**现在**：上一次的生成没跑完时，新的「重新生成」直接忽略（60 秒兜底，异常收尾也不会把按钮锁死）。

### 主页聊过的对话不会凭空消失

在**主页**（还没打开工作区）建的对话，归属为空；一旦创建工作区，会话列表只读工作区自己的那一桶，这条对话就从列表里看不到了。

**现在**：建完工作区后，这条对话会跟着新工作区走，并自动选中 —— 你刚才聊到哪、回来还在哪。

### 内置浏览器不再盖住侧栏

极速模式用的是系统原生图层，**永远画在界面之上**，网页会盖住侧栏的下拉、列表和弹窗。

**现在**：只要界面上出现浮层并与编辑区重叠，浏览器就让位；浮层关掉再挂回去。层级表现和编辑器一致。

### 等待提示不再一直停在「正在整理最终回答」

切走再切回一个会话时，等待行会一直停在最后一档「正在整理最终回答」，看起来像卡死在收尾。

**现在**：只有在真的有一条流在跑时才计时，残留的状态不会再冒充「正在生成」。

### 活动栏与标题栏

- **隐藏一个活动栏按钮后，所有按钮的名称文字会一起冒出来** —— 那是写配置时把「不显示名称」这个开关丢了。现在隐藏 / 拖动按钮都不会再影响它。
- **标题栏最大化 / 还原两个状态的图标一模一样** —— 现在最大化时是双矩形，一眼能看出这一下是还原。

### 技能加载更快

按 Claude Code 的做法重做了技能加载：发消息后不再先转一圈才出结果；本地能直接命中的技能，不再白跑一次 AI 判断。

### 界面文案跟随语言

英文界面的余额 / 额度查询结果、技能卡、工具卡名称、思考过程标题仍是中文 —— 现在全部跟随界面语言。

## 🧩 插件：装得明白，用得清楚

- **打开方式修好了**：插件位置选「完整页面」现在真的开成主区标签页，不再变成弹窗。
- **装完就能打开**：详情页「关闭」和「已安装」之间多了「打开插件面板」，按插件实际声明的贡献面列出可打开的面板。
- **来源一眼可辨**：市场卡片直接标「官方」或「社区」，悬停显示作者名。
- **第三方插件免责声明**：社区插件市场的首屏和详情页都会明确提示 —— 与巢墨科技无隶属关系，Notrat 只校验代码结构规范、不审查业务逻辑与安全性；插件可能读写工作区文件、执行命令或访问网络，请确认来源可信后再安装。
- **付费功能提前告知**：插件用到基础版 / 专业版能力时，使用手册顶部会说明「有功能需要 XX 版，当前套餐下用不了」，每条贡献面也标了所需的 Notrat 版本与套餐。被套餐拦下时，提示从一串英文错误改成「这个插件用到了需要订阅套餐的能力（基础版 / 专业版）」。
- 插件页不再残留大纲 / 反向链接。

## 🎛 活动栏与市场

- **活动栏精简**：自进化实验室、图谱、定时任务、远程助手、常用功能帮助、导出默认收进「更多」，想要哪一项右键点亮即可。
- **默认不显示文字标签**：只留图标；需要文字的到 设置 → 面板 里打开。
- **去掉重复的「AI 全屏」**：它和「AI 搭档」功能重复，已移除。
- **市场筛选收起来**：来源和套餐两排小按钮合并成一个「筛选」弹层，工具条只剩 搜索 · 筛选 · 刷新。

## 📝 其他改动

- **AI 改工作区外的文件时，只在你看得见的时候问**：**开着「完全访问 / 自动授权」就不问**（你已经把授权交给 AI 了）；没开的时候，只有那份文件**正开在编辑器里**才在**对话里**给一张三选一面板 —— 就在原文件上改（临时）/ 把它的目录作为新工作区 / 附加到当前窗口。**没打开的文件不再打扰**，插件改自己的配置、缓存也不问。面板跟在对话里，不再是一个盖住屏幕的弹窗。
- **非强制更新也会提示**：以前只有强制更新才弹，现在普通更新也会在右下角弹一张可关闭的卡片。
- **打开外部文件弹窗文案去重**：改成「临时打开 · 当前窗口」「作为工作区打开 · 替换当前工作区」等，一眼看出文件归属。
- 专家可以按「全局 / 工作空间 / 工作区」安排；连接器支持全局 / 工作空间 / 工作区三档范围，并按需启动。
- 设置页文字整体更清楚，窄窗口不再横向溢出。

## 关于版本号

用 `1.3.10` 而不是 `1.3.9.1`：自动更新按语义化版本（semver）判断高低，而 `1.3.9.1` **不是合法版本号**，1.3.9 的用户会收不到这次更新。`1.3.10` 严格大于 `1.3.9`，所有人都能正常升级。

> 这一版的功能面与 1.3.9 相同（内置浏览器两套引擎、AI 直接登录、PPT 缩略图拖动、AI 读大文件分段等都在），变化集中在修复。
