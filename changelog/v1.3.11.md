# 1.3.11

发布日期：2026-11-20（已上线）　·　[← 上一版](/changelog/v1.3.10)

**这一版**：0 项新功能 · 4 处修复 —— 1.3.10 之后的又一个**修正版**。

如果你在 1.3.10 上遇到过下面这些，这一版就是为你发的：

- 开两个窗口时，A 窗口的网页浮在 B 窗口的编辑器上，而且 B 里没有标签能关掉它；
- 两个窗口各开各的工作区，B 的会话列表里却出现 A 的全部对话；
- 设置里「接口格式」那段说明把面板撑破、开关被挤没；
- 某些模型的上下文 / 输出上限显示得偏小。

## 🩹 修好了这些

### 内置浏览器的网页会浮到别的窗口上

在内置浏览器（极速模式）打开一个网页后，切到另一个窗口，那块网页会盖在编辑器上面 —— 而那个窗口里没有任何标签可以关掉它，刷新渲染层也没用。

**原因**：网页用的是系统原生图层，不归渲染层管；而它「记住自己在哪个窗口」的逻辑只认**第一个开过网页的窗口**，之后所有窗口的网页都挂到那个窗口上。

**现在**：每张网页视图记住自己的宿主窗口；别的窗口的视图不会被误摘、也不会被误挂；**窗口关闭时连同它的所有网页视图一起销毁**。另外，工作区外文件的三选一询问也改成投给**当前聚焦的窗口**，不再固定发给主窗口。

### 两个窗口的会话列表会串

窗口 A 用工作区 X，窗口 B 用工作区 Y，B 的会话列表里却出现了 A 的全部对话。

**原因**：主进程保存会话后会通知**其他所有窗口**「这个工作区变了」，而每个窗口收到就把这个工作区登记进**自己**的列表枚举 —— 于是别人的工作区被读进了自己的列表。

**现在**：只有「本窗口本来就认识的工作区」（自己写过、或启动时快照里有）才会登记；缓存失效照旧做（那与工作区归属无关，是同桶并发写的另一半防护）。

### 设置里「接口格式」的说明撑出面板

设置 → AI 服务商 → 更多设置里，「接口格式：Responses / Chat Completions」下面有两段长说明，会把整块卡片撑出面板，右侧开关被挤到看不见。

**原因**：这一行是弹性布局，文字那一列没有「允许被压缩」，长文本就顶着宽度往外撑。

**现在**：文字列可压缩（`min-w-0`）、开关固定宽度不受文字影响，纵向对齐改成顶部对齐 —— 说明换行后开关不会跑到中间。

### 部分模型的上下文 / 输出上限识别不出来

比如中转返回的模型名是 `deepseek-v4.1-flash-1017`（**小数点**版本），内置规格表里只登记过连字符版本 `deepseek-v4-flash`，匹配不上就只能退回一个更保守的默认值 —— 于是上下文窗口和最大输出都显示得偏小，按它钳制的 `max_tokens` 也可能与真实能力不符。

**现在**：补上了 `deepseek-v4.1-flash` / `deepseek-v4.1-pro` / `deepseek-v4.1` 三条规格（1M 上下文 / 384K 输出），口径与 v4 系列一致。

## 关于版本号

1.3.10 已经发布，这四笔修复必须换号 —— 自动更新按语义化版本比对，`1.3.11 > 1.3.10` 才会提示升级；同号重发用户收不到。

> 这一版的功能面与 1.3.10 完全相同，变化集中在上面四处修复。1.3.9 及更早的用户升级时，会一并带上 1.3.10 里的那批修复。
