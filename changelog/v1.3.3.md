# 1.3.3

发布日期：2026-09-23　·　[← 上一版](/changelog/v1.3.2)　·　[下一版 →](/changelog/v1.3.4)

---

## 🧠 AI 正在回复时重载应用，聊天记录不再丢

- **症状**：让 AI 重载应用（或 AI 自己触发重载）后，**还没写完的那段回复消失了**——聊天里直接断掉，没有任何提示。
- **现在**：重载前应用会**先停下来等你这边的聊天记录保存完**（最多等 2 秒，不会卡住），确认「已保存」后才真正重启。进行中的回复会以「已中断」的形式完整留在对话里，重开能看到。

## 🖱 文件树右键菜单不再被聊天「顶掉」

- **症状**：AI 正在输出内容时，你在左边文件树上点开右键菜单——**菜单闪一下就消失**，怎么都点不了。
- **现在**：只有**菜单所在区域自己**滚动时才收起；聊天那边滚翻天也不影响你操作文件树。

## 📝 便签：自动保存 + 不再丢内容 + 顺手修了个大 bug

- **自动保存**：写完停 1.5 秒自动存盘，标题栏实时显示「● 未保存 / 已保存 14:32」，不用再惦记 Ctrl+S。
- **关窗不再丢内容**：不管用 ✕、Esc 还是 Alt+F4 关闭，有未保存内容都会先问一句「保存并关闭？」，不会再无声丢失。
- **便签管理齐了**：列表改成浮层（不再压缩正文），每条便签可以**重命名**、**删除**，按最近修改排序，暗色模式也正常了。
- **窗口记得住**：便签窗口的大小、位置、是否置顶，重开全部还原。
- **修了个老 bug**：便签里 **Ctrl+A 一直没法全选**——它被误设成了「置顶」快捷键。现在置顶是 Ctrl+Shift+A，Ctrl+A 恢复全选。
- 顺手：新建便签自动聚焦输入；关掉弹出菜单时的 Esc 不会顺手把窗口关了。

## 🕸 图谱：能搜索了，操作控件也齐了

- **搜索**：顶栏新增搜索框，输入文件名/路径——命中的节点高亮 + 光环 + 显示名字，其余淡出，一眼找到目标文件。
- **布局收纳**：七种布局（力导向/环形/网格/径向/层次/树状/拓扑）从平铺一行收进下拉菜单，顶部不再拥挤。
- **右下角控制簇**：放大 / 缩小 / **一键回到全图**（以前缩放丢了只能切布局找回）/ **隐藏无链接的孤立节点**（大工作区清屏利器）。
- **左下角图例**：说明各颜色含义和操作方式（悬停聚焦、拖拽平移、滚轮缩放）；悬停节点会显示连接数和完整路径。

## ⏱ 长任务不再被误判为「断开」

- **症状**：跑长任务时（大量工具调用、长思考、大上下文），聊到一半**自动停住**——没有报错、没有提示，就像被掐断。
- **现在**：静默容忍度从 5 分钟放宽到 **3 小时**，同时把原先 1 小时的绝对上限抬到 6 小时。真卡死的任务随时可以手动停止。

## 💾 长对话「越存越短」—— 修好了，而且是根治

- **症状**：聊到内容变长之后，**越用越不对劲**——重启应用或切换会话再回来，长回复的尾巴不见了；再聊再存，内容又短一截。像「存一次剪一刀」。
- **现在**（三层根治）：
  1. 正常长度的内容不再被剪；
  2. **磁盘上保存的永远是最长的版本**：即使显示时需要省略，任何保存都不会再覆盖掉更长的版本；
  3. **超长内容改为按需加载**：打开对话先快速显示（不卡），超过上限的长段落会在后台**自动取回完整版**补上——您从此看到的和存下的都是完整的。

## 🐛 「思考超出 Max Tokens」频繁误报 —— 已修（deepseek-flash 等别名模型）

- **症状**：用 `deepseek-flash`（含其它不带 `v4` 的 DeepSeek 别名）时，**频繁**提示「思考过程超出了 Max Tokens 上限」，而且**把 Max Tokens 调到多大都没用**。
- **现在**：**设置页显示多少，实际就发多少**；并为 `deepseek-flash` / `deepseek-pro` 等别名补上正确规格（1M 上下文 / 384K 输出）。这些模型不再频繁误报，Max Tokens 设置也真正生效了。

## 🤖 「AI 完成了思考但未给出最终回答」——终于说人话了

- **症状**：用思考型模型（DeepSeek-Reasoner / GLM 等）时偶尔弹这句「瞬时问题，请重新发送」，但**重发多少次都一样**。
- **现在**：这种情况会明确提示「思考超出了 Max Tokens 上限（重发无效），请调大 Max Tokens 或关闭深度思考」，并且不再白白自动重试三次。遇到时去 设置 → AI 服务 把 Max Tokens 调到 8192 以上即可。
- （真正的偶发「只思考不回答」仍会自动重试三次，照旧兜底。）

## 🧩 插件开发者：三个新位置 + 编辑器双视图 + 划词能力

- **插件面板可以放到三个新位置**（右键「移动到…」里也全部可选）：
  - **大纲面板**（左侧大纲 tab，标题列表下方）——文档导航/结构类工具的专属位；
  - **标签栏按钮**（文件标签右侧）——只在编辑器页出现，适合「这个文件的双视图切换」类入口；
  - **顶部控制带**（「编辑|源码」/ 新手任务 / 窗口控制那一排）——所有页面常驻，适合全局快捷入口。
- **编辑器双视图：声明一个字段就有一等座**——插件编辑器在 manifest 里写 `"dualView": ["可视化", "源码"]`，打开该格式的文件时，标题栏自动出现与内置「编辑|源码」同款的切换按钮（只在对应编辑器激活时显示），组件通过 `props.mode` / `props.onModeSwitch` 与之联动，与内置编辑器完全同权。
- **编辑器插件对接大纲（新增）**：插件编辑器声明 `"outlineTool"`，当前文件被它接管时，左侧大纲面板自动改由该工具产出条目（`level/text/anchor`），点击条目即可跳回编辑器对应位置——画布、PCB、私有格式都能有自己的大纲导航。大纲位置的插件面板还支持 `extensions` 按文件后缀过滤显示。
- **编辑器实时状态同步到状态栏（新增）**：插件编辑器可把实时状态（光标行列、缩放比例、节点数…）推到状态栏右侧（内置 Ln/Col 旁），随编辑器状态即时刷新，切走编辑器面自动隐藏、关闭文件自动清空。
- **插件面板菜单更好管**：状态栏「插件面板」入口按位置分组（输入框上方 / 右侧停靠栏 / 大纲 / 弹窗…带计数）；点常驻位的面板会直接跳回它所在的位置显示（不再弹一个居中副本）。
- **划词能力开放**（两条官方通道，详见插件文档 §5.9）：
  - **读**：任意位置的面板组件可从 `props.ctx.selection` 实时拿到当前选中文本（来源文件、行号），翻译/解释/格式化类工具可以自己做「划词即响应」；
  - **写**：插件编辑器派发 `notrat-quote-to-chat` 事件，即可把选中内容钉进聊天输入框生成引用卡——与宿主原生「引用到聊天」完全同级。
- 文档同步更新：面板新位置表、`ctx` 字段与划词双通道见[面板与界面扩展](/plugin-dev/panels)，开发排错 CLI 参考见[调试与日志](/plugin-dev/debug)。

## 📂 外部打开文件：选项更干脆

- 双击外部文件唤起 Notrat 时的选择框，去掉了「在新窗口打开」——单个临时文件开一整窗没有必要（「单文件打开」本来就不动你当前的工作区）。现在只剩两个选项：**单文件打开** / **用工作区打开**。多窗口需求走工作区打开或编辑器右键。
