# 1.0.4

发布日期：2026-07-20　·　[← 上一版](/changelog/v1.0.3)　·　[下一版 →](/changelog/v1.0.5)

**一句话总结：新用户第一次打开不再「看得到编辑器却不知道怎么登录」：欢迎引导先登录再往下走，登录页也重新排了版。**

---

## 🎉 欢迎引导

- **首屏不再透出编辑器**：修复首次进入引导页、第一页渐显时能透过遮罩看到编辑器的问题；主题在第一帧之前就已应用，欢迎层用不透明底，应用启动画面也会先盖住底层界面。
- **去掉「跳过」**：欢迎轮播不再提供「跳过 / Esc 关闭」，新用户需要走完介绍页。
- **先登录，再详细引导**：最后一页的按钮改为「去登录」；登录成功（或选择游客继续）之后，才会启动工作区、文件树、编辑器等详细引导。
- **入场动画**：功能亮点标签、标题下划线等会随翻页重播，并带轻微错落入场。

## 🔑 登录页

- **左右分栏**：左侧是品牌与卖点说明，右侧是紧凑的登录表单（密码 / 验证码 / 第三方登录 / 游客继续），整体更扁、更容易扫读。
- **细节补齐**：密码显示与隐藏、输入框聚焦反馈、加载中的转圈；中英文文案同步。
