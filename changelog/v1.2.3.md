# 1.2.3

发布日期：2026-08-19　·　[← 上一版](/changelog/v1.2.2)　·　[下一版 →](/changelog/v1.2.4)

**一句话总结：连接器（MCP）和技能都分成「全局」和「工作区」两份，不同工作区各用各的，还能一键搬来搬去。**

---

## 🗂 连接器（MCP）与技能：全局一份，工作区一份

- **MCP 配置两级化**：每个 server 都可以存成「全局」或「某个工作区」，优先读工作区那份，没有再回退全局；不同工作区可以用完全不同的 server，互不干扰。
- **技能配置两级化**：技能同样分全局与工作区两份，切换工作区会自动加载对应的配置。

## 🔄 一键在全局与工作区之间搬移

- **MCP 管理面板**：每个非内置 server 多了「迁移」按钮，一键在全局和工作区之间搬移，启用状态与配置都保留。
- **技能管理面板**：全局 / 工作区技能也多了「迁移」按钮，一键搬移技能目录。

## 🛒 市场安装状态跟着当前工作区走

- 修好「在 A 工作区装的技能，切到 B 工作区后市场还显示已安装」：市场现在按当前工作区的配置判断，切换工作区即时刷新，不再误读全局配置。

## 🏷 应用名统一为 Notrat

- 此前应用名被误设成 Notrat2，这次全部改回 **Notrat**：安装包名、快捷方式、菜单、协议都已更正。
