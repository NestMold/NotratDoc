# 1.3.4

发布日期：2026-10-05　·　[← 上一版](/changelog/v1.3.3)　·　[下一版 →](/changelog/v1.3.5)

**一句话总结：插件系统全面翻新，编辑器里的图表与代码预览大幅升级，多窗口协作、远程助手更好用——外带一大批老问题集中修好。**

**这一版**：8 项亮点 · 12 处修复 · 45 项改动详情（详情按模块收起，点标题展开）

## ⚡ 更新亮点

- **🧩 插件箱整个重做**：按插件列出的九宫格抽屉取代旧清单——格子可拖动排序、自动分页；点击即打开主面板、右键即插件操作；每个插件有自己的图标与设置窗，入口还能挪到活动栏 / 侧边栏 / 编辑区标题栏。
- **🧲 插件侧栏焕新**：从「浮层遮内容」改成真正占位的一列，宽度可拖、顺序可调；开合开关就在状态栏，和「AI」排成一组。
- **📊 编辑器写完就出效果**：mermaid / PlantUML 图表、HTML 页面、SVG 图——写完立刻渲染预览；敲 ``` 还会弹出语言候选列表。
- **💬 对话体验升级**：等待回复时思考过程直接显示，不再一片空白；搭档模式新增「运行详情」右栏——AI 动过哪些文件，一眼就能回看。
- **🪟 多窗口不再打架**：一个窗口登录，其它窗口即时同步；同一工作区的对话记录不再互相覆盖。
- **📱 远程助手整页重做**：按「第一次用」的顺序重排——三步引导 + 点平台卡片直接连，术语全部换成大白话；定时任务搬到活动栏、有了独立入口。
- **🛒 扩展与专家更顺手**：「市场」改名「扩展」；专家可以整包卸载；设置 → 专家分成三段；输入框 @ 面板分四个页签，技能 / 连接器可以「只对这一条消息」生效。
- **🛡️ 安全与隐私更透明**：「完全访问」换成盾牌开关、开启前需确认；错误日志独立开关、本机随时可查。

### 插件箱全新交互：按插件列出的九宫格抽屉

- 状态栏的「插件箱」从「按位置分组的面板清单」改成**按插件列出**的九宫格抽屉——一个插件一枚格子，不用再先想「它挂在哪」。
- **点击格子 = 直接打开该插件的主面板**（整页型插件开成主区标签页、常驻型回到它该在的位置）；**右键格子 = 插件级操作**：⚙ 设置 / 打开主面板 / 禁用 / 卸载 / 进插件管理页。
- 插件多了自动**分页**（每页 9 个，底部 ‹ › 翻页，也支持 ← → 键）；**拖动格子可调整顺序**，顺序会记住。
- 已停用的插件不再出现在抽屉里（避免误点），到 设置 → 插件 里启用后回来。

### ⚙️ 每个插件有自己的设置入口

- 以前所有插件的设置挤在「设置 → 插件」同一页里混排；现在**每个插件独立设置对话框**——在插件管理列表点该行的「⚙ 设置」，或在抽屉里右键该插件选「设置…」，只弹出它自己的设置项。
- 改完即时保存，约 1 秒后自动重启该插件的后台服务使设置生效。

### 🖼️ 插件图标可自定义

- 插件现在可以带自己的图标：**emoji 或图片 URL**。
- 抽屉格子、插件管理页、插件设置对话框、社区货架统一显示该图标；没声明则依次回落到插件第一个面板的图标、🧩。

### 📌 插件箱入口可以换位置了

- 「插件箱」入口不再固定死在状态栏：**右键入口按钮 → 「移动到…」**，可改挂到 **左侧活动栏 / 侧边栏工具栏 / 编辑区标题栏**（状态栏为默认）；挂到活动栏后还能在 设置 → 外观 → 活动栏按钮 里和别的按钮一起排序、显隐。
- 想清静可以「隐藏入口」；隐藏时会提示找回路径——**设置 → 插件 → 「↺ 显示插件箱入口」**（只恢复入口本身，不影响其它面板）。

### ↩️ 单插件恢复：不用再「全部恢复」了

- 误关了某个插件的面板？**右键该插件的格子 →「恢复已关闭的面板」**——只把这一个插件被关掉的面板放回来，其它插件不受影响（有多个时显示数量）。
- 面板位置被挪乱了：右键 → **「重置面板位置」**，只重置这个插件各面板的位置与打开方式，回到默认布局。

### 🧲 插件侧栏（原右侧停靠栏）：真占位，不再遮内容

- 原来这条栏是浮在界面上的覆盖层（展开会盖住聊天栏）；现在改成**真正占位的一列**——展开时占最右、与聊天栏相邻、编辑区自动让位，不再遮挡任何内容；收起后空间完全回收，宽度可拖（240–560px，记忆保留）。
- **展示方式可切换（装了 2 个以上插件面板时）**：默认**树状**——面板纵向堆叠、每块标题点一下就能折叠，**左侧把手拖着就能调整上下顺序**；标题栏那个小按钮一点，换成**标签**——顶部横排标签、一次看一个面板，省纵向空间。顺序、折叠状态、切过的选择都按窗口记住，重开还是原样。
- **细处整了一圈**：栏头换成与状态栏开关同款的小图标；面板块的折叠箭头、收起箭头换成干净的线条箭头；**关闭面板的 ✕ 从悬浮在内容右上角挪进标题行右端**（悬停标题行才浮出）——面板折起来时也能直接关；右键整块（含折起的标题行）都能弹出「移动到…」菜单（以前折起后这个入口就没了）；标签模式的标签换成分段样式，关闭键收到标签条右端，不再压着面板自己的头部。
- **开合入口就在状态栏，和「AI」并成一组**：状态栏右下角现在是一组开关——左边「**插件侧栏**」开合这条停靠栏、右边「**AI**」开合聊天侧栏，中间一条细分割线，两个都带文字标签和悬停说明。没装带停靠栏面板的插件时，「插件侧栏」不出现，这一组自动缩回只剩「AI」，不留空位。
- **入口不再会「消失」**：只要还有插件声明了侧栏面板，开关就一直在——哪怕面板全被 ✕ 关过，它也不会跟着不见（点它会先把面板恢复回来再展开），不再有「唯一入口没了、只能去插件右键里翻恢复」的死角。

### 🖱️ 插件右键菜单统一为全局样式

- 插件格子与插件面板的右键菜单，统一为和文件树 / 编辑器右键**同款**的样式与操作：↑↓ 键选择、Enter 执行、Esc 关闭；面板的「打开方式」改为悬停展开的子菜单。

### 🔄 插件更新提醒：自动检测 + 用时询问

- **自动检测**：启动后自动对照官方市场与社区货架核对已装插件的新版本（版本号比对，6 小时内只自动查一次）。
- **使用插件时询问**：打开某个插件发现它有新版本时，弹窗询问——**立即更新 / 暂不 / 不再提示**（「暂不」本次启动内不再打扰；「不再提示」永久静音该插件，市场与插件页仍可手动更新）。
- **一键更新**：点「立即更新」复用市场安装通道，替换文件后插件自动重载。
- **手动检查**：也可以随时到 **设置 → 插件** 点「**⟳ 检测更新**」——发现新版本时，对应插件行会直接出现「**⬆ 更新 vX**」按钮，一键升级（比原来只查官方市场多了社区货架，且结果直接落到每个插件的行内）。

### 🧩 插件开发者：只加模式声明，热重载也能生效

- **症状**：开发插件时，只往插件的描述信息里加几项编辑器相关的声明（多模式按钮、大纲入口之类），热重载后**不生效**——按钮和入口都不出现，必须重启应用才管用。
- **现在**：这类声明现在也会被算作「有变化」——改完就重新生效，调试循环不用再重启应用。

::: details 📱 远程助手（在手机上用 AI） · 2 项

### 整页重做，按「第一次用」的顺序讲

- **没连上时，页面就是一张三步说明书**：① 选一个聊天软件 → ② 按提示连上（扫码，或填几个值）→ ③ 在手机上发条消息。下面是一排**可以点的平台卡片**（微信 / 飞书 / 企业微信 / QQ 机器人 / Telegram / WhatsApp / Discord / Slack），每张卡直接标着「扫码即可」或「填 2 个值」。**点哪家，就带着这家打开填连接信息的表单**，不用再自己在下拉框里找一遍。
- **点平台卡片进的连接表单，只会弹这一次**：从远程助手点「微信」→ 设置里直接把这家填连接信息的表单开好；关掉它，之后在设置里来回换分区、换回「连接聊天软件」，都不会再自己弹出来——表单只在你点卡片的那一下开。
- **删掉两张「说明卡」**：原来正文有两张卡专门讲「在左侧查看各平台的会话」「AI 会自动回复外部消息」——那是在给用户讲界面本身。现在这些话收成一句，界面该自己说清楚。
- **连上之后，页面只回答三件事**：正在为你服务的是哪几个（带名字，不再是一排灰图标靠悬停猜）、去哪看消息、还没消息时该做什么（去手机上发一条）。
- **术语换成人话**：IM 通道 → 连接聊天软件；机器人 → 账号；实例名称 → 备注名；测试连接 → 检查连接；扫码登录 → 扫码连接；Agent 绑定 → 回复规则。
- **连接卡片按「先看怎么拿，再动手填」排**：平台侧的申请说明挪到输入框**前面**；填完点「检查连接」；失败时写人话（「没能连上」「检查没通过」），不再甩英文的 Startup Failed。
- **空态不留死路**：设置里的空态直接给平台网格，点一个就开填；「回复规则」页明说「一般不用配，AI 会照常自动回复所有消息」，不必担心漏配。
- **账号名不再自己叠自己**：原来自动建的账号叫「微信 (个人号) 1」，列表里又在后面接一次平台名，成了「微信 (个人号) 1 (微信 (个人号))」——同一个名字出现两遍。现在默认就叫「**微信**」（再建一个叫「微信 2」），自己起过名字的显示成「**工作微信（微信）**」。
- **「回复规则」表单说人话，也不再点了没反应**：机器人实例 → **用哪个账号回复**；聊天 → **哪个会话**；聊天名称 → **备注名（可选）**；智能体 → **由谁回复**；两个开关下面各写了一句这开关到底管什么。**没选全时保存按钮变灰，旁边直接写「还差：哪几项」**（原来有几项没填时，点保存是静默无效的，像坏了）。列表里「由谁回复」显示助手名字，不再是一串内部 ID；没收到过消息的账号也说明了「让对方先发一条，这里就会变成可选的列表」。
- **设置页签只剩「连聊天软件」这件事**：「连接聊天软件」「回复规则」两个大的在上面，「平台插件」在下面一行小字的「进阶」——平台插件管的就是聊天平台，留在这里名正言顺。原来同在这一行的定时任务 / 自进化 / A2A 服务都搬去了各自更合适的位置（见下节）。
- **「收到的消息」列表**：没起过名字的会话显示平台名（「微信」），不再是「点击命名」这种像空表单的占位字；删除会话前会先确认。
- **窗口标题栏那条「设置 / 编辑器 / 沉浸式」去掉了**：远程助手页自己的顶栏已经有「连接设置」「返回编辑器」和面板 / 沉浸切换，左边活动栏也各有一个入口——同一件事在标题栏再摆一遍，只是把导航重复三次，还让这页看着像开发者面板。

### 🧭 定时任务 / 自进化 / A2A 服务：从「进阶」里搬出来，各归其位

- **原来的问题**：这三样挤在「设置 → 远程助手 → 进阶」一行小字里，可它们没一个和「连聊天软件」有关——想开个定时任务是「打开设置 → 找到远程助手 → 点进阶 → 点定时任务」四步，第一次用的人根本猜不到它藏在哪。
- **定时任务 → 活动栏自己的按钮 + 一整页**：左侧活动栏多一个「定时」（时钟带回环的图标），点一下直接进定时任务页——任务列表、新建 / 编辑 / 删除、启停、手动跑一次、执行日志，原样搬过来，只是不用再先钻进设置里。功能与门槛都没变（和远程助手同一档）。
- **自进化 → 只留「自进化实验室」**：远程助手那个「自进化」页签其实只有一张跳转卡，真正的配置本来就长在「自进化实验室」里——现在页签去掉了，看行为、调开关、看记录都在实验室，不用再绕一道。
- **A2A 服务 → 设置左栏自己的分类**：A2A 管的是「让外部 agent 调进来」——开哪个端口、要不要验证来路，这是一台服务器该怎么配置的事，和「连微信 / 飞书」不是一回事。现在它是设置左栏的一个独立分类（A2A 服务），开关、端点、接入信息和调用示例都在里面。
- **平台插件留在原地**：它管的本来就是聊天平台，留在远程助手的「进阶」里。远程助手设置从此只剩三件事：连接聊天软件 / 回复规则 / 平台插件。

::: details 📊 编辑器与预览 · 6 项

### 📊 编辑器里的图表：写完就出图（mermaid / PlantUML）

- **症状**：在笔记里写 mermaid 代码块（AI 写给你的也一样），代码块下面**什么都不出现**——只有一片空白，也没有任何报错提示，让人以为是语法写错了。
- **现在**：代码块写完（或改动后）**立刻出图**，不用来回滚动、也不用改一个字试探；图表跟随界面明暗主题。
- **尺寸按图本身走**：小图保持自己的大小居中显示，不会被硬拉到满宽（此前小图会被放得很大）；宽图等比缩进可用宽度，不溢出、不裁切。
- **源码块与预览分得开**：源码块是灰底实心，预览是页面底色 + 描边的一块「画布」，一眼能分清哪块是代码、哪块是图；点预览展开源码，点别处收起。

### 🖼️ 代码块即预览：HTML / SVG 写完就出画面

- **```html 直接当页面跑**：在笔记里写一段 HTML，块下面立刻给出页面效果——样式照常生效、表单能填、脚本能跑；改完源码预览即时跟着变，不用另存文件切浏览器。
- **```svg 直接出矢量图**：图标、示意图这类 SVG 标记同样写完就出图，缩放不糊；没写颜色的线条**默认跟界面文字色走**，深色模式下也看得清。
- **预览框尺寸自动贴合**：高度随内容走（内容多高框就多高，不白留一大片空）；内容比可用宽度宽时**整体等比缩小到放得下**——像浏览器缩小显示，线条依旧清晰，而不是在框里塞一条横向滚动条；内容窄就保持满宽。缩到约四分之一就不再缩了，更宽的图才会横向滚动。
- **聊天里也认 ```svg**：AI 回你的 SVG——包在 ``` 里的、还是直接铺在正文里的——都直接出图，不再是满屏看不懂的标签；出图之后右上角的**复制按钮给的仍是原始标记**，方便拿去别处复用。
- **边输出边成形**：AI 还在写的时候，图就已经开始画了——先写好的部分先显示，后面的元素跟着输出一个个补上去，不用等整段写完才「啪」地换成一张完整的图；编辑器里写 / 改代码块时，预览同样实时跟着变。
- **画出来的图默认只给人看，不往硬盘写**：聊天里渲染出的图**不会**自动存成文件（每画一张就写一份磁盘是没人要的副作用，而且哪张值得留只有你知道）；想留成文件，鼠标移到图右上角点「**存为 SVG**」，挑个位置保存即可——存下来的就是你或模型写的那份原始标记。要让 AI 直接写进工作区，让它用文件工具写，那条路有文件树、看得见。
- **文档里的图，搬进聊天也认得**：从笔记里带出来的图片引用（`.notrat/images/…` 这类相对路径，或 `file://` 地址）在聊天里会按当前工作区找到文件并显示，不再是一块碎图；笔记里插入的图仍旧一律存成工作区里的文件、按图片显示，两种形态各走各的路。
- **该配图的地方，AI 会主动画**：现在明确告诉 AI——流程、结构、关系、对比、时间线这类「说出来绕、画出来一眼就懂」的内容（必要性 / 可行性分析、方案取舍、决策树…），不用等你说「画个图」，它就直接配图；简单问答也不会硬塞装饰。图的去处同时定了：给人看的就画在回复里（画出来的图右上角一键存盘），只有你确实要一份文件（「存成 .svg」「放进项目里」、后面还要用），它才用文件工具写进工作区并在回复里引用出来。这条说明与你的提示词设置无关，人人都生效。
- **简单的图用 mermaid，复杂的图改用 SVG**：短流程图、状态图、ER / 甘特图这类几步画完的继续用 mermaid（节点少时它的自动布局更清爽）；**参与者多、交互细的时序图，分层 / 分组的架构图**改用 SVG——位置、对齐、连线精确可控，不会再被自动布局挤成一团。和上一条一样，不用你指定，AI 自己按复杂度选格式。
- **安全边界**：预览的 HTML / SVG 是 AI 生成的，所以一律跑在**与应用隔离的沙箱**里——它碰不到你的笔记、登录状态和本地文件；直接铺在聊天里的 SVG 标记会先洗掉脚本与外链再画，而按图片文件显示的 SVG（浏览器层面禁脚本）天然更严。

### ⌨️ 敲 ``` 直接挑代码块语言

- 输入三个反引号，光标下方就会弹出**语言候选列表**：继续打字即筛选（敲 `mer` 就只剩 Mermaid），↑↓ 选、**↵ 或 Tab 落定**、Esc 关掉。
- 列表里没有想要的语言？**↵ 直接拿你打的字当语言用**——想写什么都可以；也可以完全不理列表，继续手打「```语言 + 空格」，老写法原样有效。
- 落定后就是带语言的代码块，源码块右上角会显示语言名（mermaid / plantuml / html / svg 则同时出图）。

### 📋 粘贴进代码块，内容不再掉到块外

- **症状**：光标停在代码块里粘贴一段内容（尤其是带 ``` 的代码），内容**跑到代码块下面的正文里**去了，得切到纯文本模式再粘一遍。
- **现在**：光标在代码块里时，粘贴**一律按纯文本落在光标处**，粘多长都留在块内。

### 🎨 聊天与侧边栏里的图表：跟着主题走

- **症状**：切到暗色模式后，聊天记录和侧边栏里的 mermaid 图表还是白底的浅色样式，跟界面格格不入；同一段图在编辑器里和聊天里长得也不完全一样。
- **现在**：图表**跟随界面主题即时重渲染**，三处（编辑器 / 聊天 / 侧边栏）长相一致；顺带收紧了渲染的安全等级——AI 生成的图源不再被当成 HTML 原样注入。

### 📄 代码块底色：深灰太沉 —— 换成素笺纸白

- 编辑器、预览、聊天、侧边栏、更新日志里的代码块，底色从偏深的灰**统一换成素笺纸白**：浅色模式下是一张**近白的纸面**——几乎贴着页面白纸、靠细边框划出区域，眼睛不再被一整块深灰拽住；暗色模式下是**提亮一档的中性深灰**，不再闷住，深浅两版同一张纸的明暗两面。
- 代码块顶上的**语言条**（语言名 + 复制）和正文保持一档明暗差（浅色更深、深色更亮），层次感保留；十套主题都会自动适配。
- 语法高亮的配色没动，只换底。

::: details 💬 对话与工作区 · 8 项

### 🪟 多窗口登录：一个窗口登录，其它窗口即刻同步

- **症状**：同时开两个窗口时，在一个里登录成功，另一个还停在「未登录」——再在第二个里登一遍，还可能把先登录的那个「顶下线」。
- **现在**：任一窗口登录或登出，**所有窗口即时同步**——这边登录、那边立刻变成已登录，登出也是一起登出，不用再重复登录。
- **同机多版本并存也自愈了**：「开发版 + 安装版」同时开着的时候，后登录的那个会被自动认作有效会话——不再误踢下线。

### 💬 不同窗口 / 来回切工作区：对话回显不再错乱、不再互相覆盖

- **症状**：同一个工作区，换个入口进去——新开一个窗口、点最近工作区列表、或从文件对话框打开——聊天记录对不上：显示的是旧会话列表，保存时还可能把另一处新聊的内容整个盖掉；同一个窗口来回切工作区也会撞上。
- **现在**：同一个工作区不管从哪个窗口、哪个入口进来，都认作同一个工作区——读到的就是同一份对话记录，不会再显示成旧会话，也不会互相覆盖。

### 💭 等待回复时的思考：对话区不再一片空白

- **症状**：消息发出去之后、AI 开始写正文之前，有一段准备时间（备好技能、起好工具服务、查过知识库……）——这段时间对话区**一片空白**，思考只显示在底部那条悬浮的运行状态里，盯着对话区的人会以为卡住了。
- **现在**：这段等待里，**思考过程直接在对话区里显示**；正文开始输出后自然接上——同一处显示，不重复、不闪跳。搭档模式和面板模式的对话区都会生效。

### 📎 搭档模式的「运行详情」：常驻右栏，「时间线 / 改动」双页签

- **AI 干活的过程有了固定落脚处**：搭档模式右侧常驻一列「运行详情」，默认跟着**当前这一轮**走、边跑边更新；不用时收成窄条（只是收起，不是关掉），宽度也能拖。
- **「时间线」**把这一轮的工具调用、思考按发生顺序排开，运行中实时更新；**「改动」**把 AI 写过的文件逐条列出——新建、追加还是整篇改写，展开就能对照（默认只展开最新一条，点过之后按你的来）；子代理改过的文件同样计入。
- **终端命令动过的文件只记路径**：这类改动在列表里只有路径、没有内容——命令改了什么以终端输出为准，免得两份记录对不上。
- **动作名说人话**：事件标题不再是一串内部工具名，而是「读取文件」「执行命令」这样的中文动作。
- **每一轮都能回看**：正文底下、有工具调用或文件改动的轮次会带一个「运行详情」入口——点它就聚焦到那一轮（角标标着第几轮），对话视图也跟着定位过去；看完点「回到最新」回来。

### 💬 输入框 @ 面板：四个页签，技能 / 连接器可以「只对这一条消息」生效

- **以前**：@ 面板是一个混排长列表——文件、专家、技能、连接器挤在一起，越装越多越难翻；「这条消息想用某个技能 / 某个连接器」也没有顺手的入口。
- **现在**：面板顶部是四个页签——**文件 / 专家（智能体）/ 技能 / 连接器（MCP）**，按 **← →** 可以直接左右切换，也可以点选。某一类没有内容时页签不出现，不会摆一排空的分类。
- 文件、专家两页照旧：选中就把引用插进输入框，作为这条消息的引用 / 指派对象。
- **技能页**：按来源分组（内置 / 工作区 / 全局 / 插件 / Claude Code / Codex / OpenClaw），可搜索、可多选。选中的技能**只对这一条消息生效**——发送后自动恢复，不会改你的全局配置。
- **连接器页**：同理——选中某个连接器（MCP）**只给这一条消息**挂上它，不用为了偶尔用一次而长期开着。
- **发出去之后看得见**：消息气泡上会以标签回显这条消息用了哪些技能 / 专家 / 连接器；技能与连接器的标签标着来源（自定义 / 内置），专家的标签带 🎓 标记——过几天回看，也知道当时带了什么。
- 气泡上的这些能力标签**不再带 @ 字形**，和正文里真正的 @ 引用一眼分得开。
- **修掉一个插入位置的老问题**：以前在面板里选技能，内容可能被塞到整句话的末尾——哪怕 @ 是在句子中间敲的。现在一律插在 **@ 所在的位置**、光标停在它后面，连着选第二个也不会再跑到末尾；文件、专家是同一个毛病，一并修好。

### 🧭 选择工作区：不用在两个几乎一样的列表里选两次

- **以前**：沉浸式界面里还没选工作区时，左栏是一份工作区列表，输入框顶上又挂着第二份几乎一样的选择器——同一个动作两个入口、两套长相，条数还可能一处新一处旧；「打开其它工作区…」也重复出现了两次。
- **现在**：输入框上那份列表撤掉了，**左栏就是唯一的工作区列表**。输入框只剩一行说明「尚未选择工作区 · 去左栏选择 ›」，点它——或者直接按回车、点发送——焦点会**直接跳到左栏列表**上，不用再对着两个列表做同一道选择题。
- 左栏列表也顺手补齐了：每个工作区是一枚**键盘可达的按钮**（Tab 走到、回车打开，带焦点底色），悬停底色、图标底与字号跟沉浸式其它面板统一；一个工作区都还没有时，这一步会直接落到「打开其它工作区…」上，不会点了个没反应。

### 📂 外部文件对话框：补回「用工作区在新窗口打开」

- **症状**：1.3.3 之后，双击外部文件唤起 Notrat 的选择框里找不到「用工作区在新窗口打开」了。
- **现在**：「用工作区在新窗口打开」回来了，对话框恢复三个选项：单文件打开 / 用工作区打开 / 用工作区在新窗口打开。单个文件的新窗口打开依然没有——维持 1.3.3 的取舍。

### 💰 对话压缩：基础版即可用（口径修正）

- 长对话自动总结（防止超出模型记忆上限）此前资料误标为「专业版」功能，实际上从**基础版**起就一直是开放的。本次统一口径：**基础版即含对话压缩**，与线上实际行为一致。

::: details 🎨 界面与导航 · 6 项

### 🧭 活动栏：当前在哪、什么开着，现在一眼能分出来

- **症状**：左侧活动栏上常常有**好几个按钮同时看着像「你正在这里」**——开着终端、或开过插件面板之后，指示条能亮三条。鼠标悬停在「当前项」上**没有任何反馈**，像按钮坏了；用键盘 Tab 走一圈，也看不出焦点落在哪。

### 📌 活动栏默认排布：导出 / 便签归底部，插件按钮归顶部

### 🏷️ 活动栏每个按钮都有名字了

- **栏宽没变**。名字是塞进原来那个 40×40 的按钮格里的，不是把格子撑大：52px 的栏宽、按钮尺寸、外边距、圆角全部保持原样，只把字号压到 9px。这也意味着名字必须短——所以有四个按钮换了更短的叫法：自进化实验室 →「自进化」、常用功能帮助 →「帮助」、插件箱入口 →「插件箱」、悬浮便签 →「便签」。完整的名字仍然在鼠标悬停提示里。
- 名字太长（插件自己起的名字，长短不可控）会**省略号收尾**，不会撑破格子；完整名字在悬停提示里。

### 🛒 「市场」改名「扩展」

- 名字改在四处，一次改齐：活动栏按钮与悬停提示、页签顶栏标题、**设置左侧的分类名**、以及新手引导任务。新手任务原来写「探索插件市场」——按钮上却写着别的名字，用户会去找一个不存在的入口。
- 「技能市场」「MCP 市场」这些**货架**的叫法没动，指的是扩展页签里的四个 tab。

### 🛒 MCP 管理 / 技能管理：搬进扩展，二级进入

- 活动栏上原来有「MCP 管理」「技能管理」两个独立入口，现在都并进**扩展**（当时叫市场）——货架栏右端多了一组「**发现 | 管理**」切换：**发现**是逛货架、装东西；**管理**是已经在机器上的那些（来源、执行模式、安全策略、服务器增删改）。技能、MCP、插件三个货架各有自己的管理页，不用再横跨两处找。

::: details 🎓 专家（智能体） · 3 项

### 🧩 专家：可以整包卸载了

- **症状**：从市场装了一个「专家」，事后不想要了——只能自己去设置里找到那个自定义专家删掉，它带进来的技能还得一个个手动翻、手动删，又怕删错。
- **现在**：安装时留一份**清单**，记下这个专家带来了哪条专家配置、哪些技能，以及**装机前你就已经有的那些**。卸载按这份清单走：装机时现建的技能删掉，你原本就有的**跳过**，专家配置一并移除；技能早已被你手删的，算「已经是想要的状态」，不报错。
- **两个入口**：**市场 → 专家货架**，已安装的卡片上直接有「卸载」；**设置 → 专家（智能体）→ 我的专家**，从专家货架装的会显示「专家」徽标，展开有详情卡（专家名 / 版本 / 安装时间 / 内嵌技能 / 市场技能 / 未装上 / 原有保留）和「卸载专家」。两个入口的确认框都会**逐条列出删什么、留什么**——点这个按钮时你想的是「不要这个专家了」，不是「删掉三个技能」。
- 卸载**没有加套餐门槛**：掉档到免费也能卸。给「删东西」加门槛只会把人困住。

### ⚙️ 设置 → 专家（智能体）：从「一摞卡片」变成三段

- 这一页原来只有一句「多 Agent 配置」管全部，全局开关和某个专家的设置混在一起，看不出改的是谁、作用到哪。现在分成三段：**默认对话行为** / **专家（智能体）** / **运行时调度**；「AI 设计步骤能力」原本只在「我的专家」视图里出现（它其实是全局开关，专业版功能），已挪进运行时调度区，专业版下两个视图都能看到。
- **Skills 范围重做**：以前技能全平铺进一个只装得下 5 行的矮盒子，**没搜索、没分组、也不知道自己勾了几个**。现在有：搜索框（名字和来源都能搜）、已选置顶 + 计数（「已选 3 / 71」）、按来源分组折叠（内置 / 各市场分别成组，带数量）、盒子加高一倍多；「主 Agent 提示词编排（进阶）」默认收起，进页面不再先撞上一段排序表。
- **自定义专家卡**去掉了蓝 / 绿渐变的分组卡和「系统组」「自定义组」标签——分组身份改由分区标题承担，不再靠颜色说话。
- **补上「启用」开关**：此前自定义专家建出来就是永远开着的，**只能删不能停**。现在卡片头部有开关，标签行也加了状态点（实心 = 启用、空心环 = 停用、名字同步压暗）；关掉的专家不会再被主 Agent 调度，也不出现在输入框的 @ 列表里。
- **改掉一句假话**：原来写着「自定义 Agent 当前仅做配置管理与持久化，可用于后续流程编排扩展」——它们其实早就能被主 Agent 按需调度、也能在输入框用 @ 直接提到。把已经做完的事说成「将来再说」，用户读完就不去用了。
- **删掉三个假开关**：「自动任务拆分 / 拆分前预览 / 自动总结结果」——它们此前并不真的生效，文案却承诺「AI 会自动拆分为多个 Agent 并行执行」。等能力真正可用再加回来：开关先于能力上线就是骗用户。目前该区唯一真开关是「Agent 运行时调度」。

### 🎓 专家：叫法和新建入口收口，内置专家有中文名

- **叫法统一为「专家」**：界面上原来「专家包」「专家」混着用，说的是同一件事，读起来像两个概念。现在所有面向用户的地方统一叫**专家**（市场货架、设置页、@ 面板与消息气泡上的标记都算）；安装、卸载的流程不变——见上文「专家：可以整包卸载了」。
- **新建入口合一**：以前点新建会先弹一张「从零建 / 去货架挑」的二选一卡片。现在点 ⊕ 就是**直接新建专家**；想去货架，「市场 → 专家货架」一直都在，不再中间拦一道。
- **内置专家中文名**：内置的三位显示为**规划者 / 研究者 / 总结者**。只改显示的名字，已有的配置和引用都不受影响。
- **分组顺序**：专家列表调整为 **专家 → 自定义 → 内置**，自己装的放最前。
- **标记统一**：专家在 @ 面板、消息气泡等处统一带 🎓 标记，和技能 / 连接器的标签一眼分得开；显示即时刷新，不用重开应用。

::: details 🛡️ 安全与隐私 · 2 项

### 🛡️ 「完全访问」开关：一眼看清开没开，开启前先过确认

- **开关换了个显眼的样子**：侧栏和欢迎页那个小锁，从「锁」换成**盾形图标**——关着的时候是灰色盾形对勾 +「**默认权限**」，开着是**红色警示盾** +「**允许完全访问**」。红色不是装饰，是在提醒你：此刻起，操作不再逐个征求同意；悬停提示也把两种状态各自会发生什么写清楚了。
- **从「默认」切到「完全访问」先弹确认窗**，把开启后放开的三类能力逐条摆清楚：**文件操作**（读取 / 修改 / 新建 / 上传 / 删除这台电脑上任意位置的文件）、**终端命令**（运行命令、安装软件、修改系统设置）、**访问互联网**（访问网站、收发数据，并使用已启用的连接器）。
- **必须勾选才能继续**：确认键在勾选「我理解以上操作将直接执行，并接受相应风险」之前是灰的；**窗口每次打开都从「未勾选」开始**——上一次的确认不替这一次背书。取消、Esc、点窗口外都算放弃，开关保持原样。
- **关掉不用确认**：收回完全访问是往安全的方向走，点了直接生效。
- 侧栏小锁、欢迎页小锁、设置里的开关，三个入口行为一致。

### 📝 错误日志：上报单独一个开关，本机也能自己看

- **开关拆开**：原来「匿名使用统计」一个总开关管着所有上报。现在它旁边多了一项**「错误日志上报」**（默认开启）；此前把「匿名使用统计」关掉过的人，这一项继续保持关——拆开关不会把它悄悄打开。
- **本机可查看**：开关下面新增**「查看错误日志」**——程序出错时记录了什么、堆栈长什么样，本机直接看（只读，随时可看），不用等报障来回问。
- **上报什么、不报什么**：只涉及 Notrat 自身功能的崩溃与运行错误；路径、密钥等敏感信息已脱敏，不含任何文件内容或对话内容。**第三方插件、你自己配置的连接器出错只留在本地，从不外发。**

::: details 🩹 问题修复 · 9 项

### 🩹 窗口不够宽时，插件侧栏被切掉一截 —— 修好了

- **症状**：把聊天栏拖宽过之后（或者窗口本身不宽、左边还开着文件树），最右边的**插件侧栏被窗口边缘切掉一截**——栏头的按钮、面板里的内容、底部那行插件信息都贴着边缘断掉，看不全也够不着；窗口一拉大又恢复正常，像是随窗口宽度时好时坏。
- **现在**：
  - **空间不够时聊天栏先让位**：临时收窄（最多收到 280px）把插件侧栏完整留在窗口里。
  - **你设的宽度不会被改掉**：让位只发生在显示上——窗口变宽、或把插件侧栏收起来，聊天栏就回到你拖到的那个宽度。
  - 反过来拖宽插件侧栏，也会在聊天栏收到 280px 时停住，不会再把它挤没。

### 🩹 代码块「复制」出来是一串 [object Object] —— 修好了

- **症状**：聊天、侧边栏里**带语法高亮**的代码块，点「复制」粘出来不是代码，是一串 `[object Object], ,[object Object],(,...`；而没被高亮的块（比如 mermaid）复制又是好的——时好时坏，看不出规律。更迷惑的是按钮照样弹「已复制 ✓」，让人以为只是粘错了地方。
- **现在**：
  - 点复制**一律还原成原始源码**——配色只影响显示、不再影响复制内容，那串 `[object Object]` 彻底消失（插件说明页里的代码块是同一个毛病，一并修了）。
  - 复制按钮改成**三态**：**复制** → **已复制 ✓** → **复制失败**（红字，1.5 秒后回到原样）——写失败不再谎报，还会自动换一条兜底通道再试一次。
  - **每条 AI 回复旁那个复制小图标**同步修好：图标 → **对勾** → 失败时**叉、染红**，悬停说明也跟着显示「已复制 / 复制失败」；顺带修掉了在剪贴板不可用的环境下点它会直接报错的问题。

### 🩹 图表偶尔渲染失败，报一串英文 —— 修好了

- **症状**：一篇笔记里放了两张以上图表时，其中一张会变成红字——「图表渲染失败: Cannot read properties of null (reading 'getAttribute')」，另外几张却好好的；刷新或随手改一个字，有时又好了。聊天里 AI 边输出边画图时，编辑器里的图也可能跟着遭殃。
- **现在**：一张图在画的时候，不会再被另一张图牵连——一篇笔记里放几张图、聊天里一边输出一边画，都互不打扰。

### 🩹 报错之后，新一轮的思考「浮」进了上一条空回复 —— 修好了

- **症状**：某轮回复出错后（比如网络出错、请求被拒），错误提示的上方留下一条**空空的回复**；你接着发下一条，AI 开始思考——思考内容却显示在了那条旧回复里，像从上面「浮」进来的一样，正文倒是正常出现在新位置。
- **现在**：出错时留下的那条空回复会被清掉——思考只会显示在它该在的位置；已经写了内容的回复不受影响，照旧保留。

### 🩹 派子 Agent 干活时，对话里塞满挂错名字的卡片 —— 修好了

- **症状**：让主 Agent 派子 Agent 干活（比如派它去查资料），它的回复被切成一段一段，每段顶上都被套一张「@researcher」的卡片——可框里那些话是**主 Agent 自己说的**（「我来帮你做…」「资料齐了，现在生成文件…」），看着像子 Agent 的旁白把整个对话铺满了；偶尔还会冒出几张挂着并不存在的 Agent 名字的卡片。
- **现在**：
  - **主 Agent 派发出去的子 Agent 不再出这类卡片**——主 Agent 的旁白按原样显示，不再被一段段挂到别人名下。
  - **手动 @ 某个 Agent 时卡片保留**——那种情况本来就是它在回答你，卡片（名字、状态、可展开的完整内容）照旧。
  - **它干活的过程一个没少**：下面的子 Agent 调用列表里，「代理 researcher」那一行照旧带着状态（运行中／完成）与耗时，展开就是执行记录、完整输出，以及「进入子 Agent 会话」的入口；「运行详情」右栏照常记录。
  - **假的 Agent 名一并堵掉**——内部工具名不再被当成 Agent 名，那种并不存在的 Agent 卡片不会再有。

### 🩹 插件管理页「⚙ 设置」按钮不出现 —— 修好了

- 插件明明有设置项，管理列表行上却没有按钮，无处可点。**现在**有设置的插件都会出现「⚙ 设置」按钮。

### 📦 文件树「解压」：报错说人话，也不再给解不开的格式递「解压」

- **症状**：右键压缩包点「解压」，失败时弹出的可能是英文技术报错——「Can't find end of central directory : is this a zip file ?」（还附一条文档链接），或 `EACCES: permission denied, open 'G:\...'`；而且这种报错两秒就消失，连截图都来不及。7z / rar 文件同样会出现「解压」菜单项，点下去才被告知解不了。
- **现在**：
  - 失败都翻成**人话**：下载不完整 / 后缀名与真实格式不符（7z、rar 改成了 .zip）、压缩包带密码、分卷压缩包、用了不支持的压缩方式、没有写入权限或被占用、磁盘空间不足、路径过长……每句都带下一步怎么办；错误提示**停留 6 秒**，看得完。
  - **解不开的格式不再假装能解**：非 zip 的压缩包（7z / rar / tar.gz 等），右键里的「解压」直接**置灰**并标明「仅支持 zip」——不再点完才发现。
  - **解压到一半失败不装死**：会告诉你已经解出几个文件、半成品留在哪个目录（可整个删掉重试），不会让你以为目录里是完整的一份。
  - **解压成功后文件树立即刷新**，新出现的「xxx_extracted」文件夹当场就能看到。

### 🩹 某些对话一发消息就被网关打回（400）—— 修好了

- **症状**：某些对话（工具调用比较多的、或历史在多窗口 / 多入口之间合并过的）某天打开继续聊，**一发消息就被拒绝（400 报错）**，AI 完全不回；报错大意是「工具的结果必须紧跟着它对应的那次调用」。有的对话完全正常，有的每次必挂。
- **现在**：发出去的请求无论对话历史怎么拼接都保持合法，这类 400 不再出现；工具的结果也严格对上它对应的那次调用，配不上的不会发出去。

### 🩹 安装包版里所有连接器（MCP）连不上 —— 修好了

- **症状**：安装包（正式版）里，**所有基于连接器（MCP）的能力全面连不上**——带后台服务的插件（比如 LaTeX 助手）面板里约 30 秒后报「连接超时」，自己配的连接器也一样；开发模式里一切正常。
- **现在**：打包时，连接器相关的部分换用了更稳妥的保护档位（其余文件的保护强度不变）；发布流程里加了自动闸——打包完成后必须让连接器实际连一次，**0.9 秒内连上、工具清单完整才算过关**，此类问题发不到你手上。
