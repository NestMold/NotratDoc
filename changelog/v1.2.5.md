# 1.2.5

发布日期：2026-08-29　·　[← 上一版](/changelog/v1.2.4)　·　[下一版 →](/changelog/v1.2.6)

**一句话总结：AI 服务商新增阿里云百炼 Coding 与一批开箱即选的模型；知识图谱细到段落，左面板补上全工作区搜索替换；子 Agent 能开自己的会话页，还能接着聊。**

---

## 🤖 AI 服务商：新增阿里云百炼 Coding

- **两个品牌入口**：供应商品牌网格里新增「百炼 Coding」，OpenAI 兼容协议与 Claude（Anthropic 兼容）协议各一个，按习惯自选。
- **内置全模型清单**：Qwen3.6 Plus / Qwen3.5 Plus（视觉）、Kimi K3（旗舰 · 1M）、Kimi K2.7 Code、Kimi K2.5（视觉）、Qwen3 Max、Qwen3 Coder Next / Plus、GLM-5 / GLM-4.7、MiniMax M2.5 开箱即选，视觉模型的能力表自动生效。
- **鉴权守卫**：DashScope 入口必须使用 DashScope API Key，误用 Qwen OAuth 登录时会给出明确指引，不会只甩一串看不懂的 401。
- **MCP 一键收录**：MCP 目录新增百炼官方联网搜索，填入 DASHSCOPE_API_KEY 即可用。
- **输出上限按当前模型钳制**：**Max Tokens** 改为三级优先（单个模型的设置 > 内置规格 > 全局默认）。像百炼这类一个入口挂多个模型、各自上限不同的服务商，此前会被统一套上全局上限，超过当前模型上限时直接返回空回复，现在不再踩坑。
- **模型规格自动识别**：上下文窗口与最大输出按模型自动识别，结果缓存在本地；国内访问不到时短超时后静默回落到内置的默认值，不影响使用，设置里还能配镜像地址自助更新。

## 🕸 图谱细到段落，搜索覆盖整个工作区

- **块级反链**：反链面板支持段落粒度，定位引用来源不再只到文件。
- **按文件分色的块群**：块级图谱里每个来源文件的块用专属颜色（8 色调色板轮转），中心文件保留天蓝色；引用线保持灰色系，悬停时按距离由近及远分四档递进，块与引用各走一套色系，层次一眼可辨。
- **中心主角不熄灯**：悬停聚焦远处时，中心块与中心连线保持亮度，主角不会被调暗看丢。
- **右下角图例**：每个颜色对应哪个文件、灰线代表引用、橙色代表焦点，随构图实时更新。
- **缩放托底**：块级展开后的自适应缩放不低于 0.8，不再缩成看不清的一小团。
- **新增「搜索」tab（Ctrl+Shift+F）**：左面板加了 VS Code 风格的全工作区文本搜索，输入停下 400 毫秒自动开始；大小写、全字、正则三个开关，正则有错实时提示。
- **结果树按文件分组**：按匹配数排序、可折叠，匹配处黄色高亮，点一行直接打开文件。
- **替换三档**：单行 / 单文件 / 全部替换，Ctrl+Shift+H 与 Ctrl+Shift+R 在查找与替换之间来回切换，支持 `$1` 等捕获组引用，并保留原文件的换行风格。
- **遍历规则**：与图谱索引一致，跳过 node_modules、隐藏目录与二进制文件；超大工作区有文件数上限，超出时提示「已截断」。

## 🤝 子 Agent 会话页：能进去看，也能接着聊

- **运行中就能进会话**：底部「子 Agent」列表条里，每张任务卡新增 💬 按钮，点开即切换到该子 agent 的会话视图，实时看对话流与流式输出；顶部标签条同步高亮该 agent，点「主对话」一键切回，主会话不丢。整卡点击仍是「查看详情」弹窗。
- **跑完还能接着聊**：任务卡片运行中只显示状态点与进度；完成后卡片上出现「进入子 agent 会话 →」，进去是完整交互页，可以继续对话，上下文连续，顶部一键回到主 agent。
- **外部 Agent 同样能进**：对话里 @ 点名外部 Agent（如 claude-code）时，其内容块头部也有「进入会话 →」按钮，直接进入该外部 agent 的会话。
- 这些外部 Agent 会出现在名册中，但只有你显式 @ 点名时才会被调用。
- **思考分段展示**：思考与正文交替输出时，思考会按段落独立渲染，不再全部挤成一坨；侧栏、沉浸视图、行内三处口径一致。

## 🔔 应用内公告，以及几处顺手小改

- **左侧活动栏底部新增公告入口**：位置在设置区上方，有未读公告时显示红点；点开在右侧弹出列表，点击条目以弹窗展示详情（支持 Markdown）并标记已读，已读状态记录在本地。
- **「重要」公告自动弹出**：启动时或新公告到达时自动弹出详情，每条只自动弹一次。
- **按套餐定向**：未登录能看到全员公告；登录后自动按当前套餐档位展示定向公告，面向纯净版 / 基础版 / 专业版的公告按「该档及以上」下发。
- **置顶与重要标记**：官方置顶的公告排在最前，「重要」级别带红色标记。
- 公告由官方发布，应用静默拉取，拉取失败不影响使用。
- **历史工作区「查看更多」**：首页「最近使用」与左上角工作区菜单不再只显示 5 个，底部「查看更多 (N)」一键展开全部历史工作区。
- **上下文快捷设置**：点击头部或沉浸工具栏的上下文占用条，就地弹出自动压缩开关与触发阈值（百分比 / Token 两种模式）、上下文预算（单个模型的设置优先）、立即压缩，不用再进设置页翻找。
- **完成提示音**默认开启，在 设置 → 通用 里可以关掉。

## ⌨️ 输入框与快捷键体验修缮

- **输入框不再被超长内容撑破**：粘贴或拖入超长文本、长文件名时，输入框整体越出右边界的问题修复；@ 出的长文件名标签以省略号截断，不再撑破一行。
- **软换行自适应**：不按回车、纯靠自动换行的长文本现在正确进入多行形态，发送按钮落位正确，内容太高还能滚动查看（此前会被裁掉且滚不动）。
- **中文输入法选词修复**：候选窗里按 ↑ / ↓ 选词不再被误判成「翻历史消息」，不会把整段草稿换成历史消息、光标乱跳；@ 选文件等操作之后 Ctrl+Z 的撤销位置也不再错乱。
- **提示语中文化**：中文环境下输入框占位文案显示中文（此前是固定英文）。
- **@ 文件面板**：底部操作提示行完整显示（此前被面板高度裁掉一截），提示文案同样中文化。
- **快捷键清单补齐**：新增全局搜索 / 替换三键、左面板开关（Ctrl+Shift+1/2/3/4）、标签切换（Ctrl+Tab / Ctrl+Shift+Tab）、输入框历史消息（↑ / ↓）等 11 条此前已实现却没展示的条目。
- **快捷键页可搜索**：支持按功能名称或按键过滤，快速定位。
- **没实现的默认不显示**：还没做的快捷键默认隐藏（免得照着按没反应），可以一键展开；macOS 下才显示 ⌘ ⇧ ⌥ 对照表。
- **左面板 tab 快捷键补全**：Ctrl+Shift+4 切换搜索面板，与 1 文件 / 2 大纲 / 3 反链一样，再按一次隐藏。
