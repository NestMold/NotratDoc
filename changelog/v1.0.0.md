# 1.0.0

发布日期：2026-07-12　·　[下一版 →](/changelog/v1.0.1)

**一句话总结：Notrat 的第一个正式版，一款本地优先的 Markdown 编辑器：写笔记的同时让 AI 帮你查资料、跑脚本、改文档，还能把 AI 助手接进微信和飞书。**

---

## 📝 写笔记这件事

- **所见即所得**：写 Markdown 就像用 Word，打字的时候排版已经做好了，不用分两栏来回切换。
- **源码模式**：想直接写 Markdown 源码，按 `Ctrl + /` 一键切换，支持 40+ 种编程语言的语法高亮。
- **多文件标签页**：像浏览器一样同时开好几个文档，拖拽就能排序。
- **工作区**：把一个文件夹设为工作区，里面的文件以树形展示，支持新建、重命名、删除、搜索。
- **格式快捷键**：`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+K` 插链接，常用的排版操作都有快捷键。
- **公式与图表**：行内公式和整段公式都支持；内置 Mermaid 和 PlantUML，流程图、架构图直接在 Markdown 里写。
- **各种文件都能看**：除了 `.md`，PDF、Word、PPT、Excel、图片和代码文件都能直接预览。
- **导出与双击打开**：笔记可以导出成 PDF 或 HTML 文件；把 `.md` 文件关联到 Notrat，以后双击就能直接打开编辑。

## 🤖 AI 能力（基础版及以上）

- **接入市面主流模型**：Claude、GPT（支持 Codex 登录）、DeepSeek、智谱 GLM、月之暗面 Kimi、百川智能、MiniMax、Grok、Perplexity，以及在你自己电脑上跑的 Ollama / LM Studio；也可以绑定自己的 API Key。
- **边写边聊**：左侧编辑笔记，右侧跟 AI 对话，随时提问、随时改稿。
- **AI 续写**：写到一半卡壳了，按 `Tab` 让 AI 根据上下文自动接下去。
- **沉浸式 AI 工作台**：全屏打开 AI 面板，让它自己规划任务、调用工具，帮你写完一整篇文档。
- **智能体自动化**：批量处理文件、联网搜索信息、运行脚本这类重复性的工作交给 AI 智能体，它会自动拆解任务并一步步完成。
- **四种思考模式**：计划模式（先列一个计划给你看，确认后再执行）、推理模式（把思考过程实时展示给你）、思维链（一步步推理）、思维树（同时尝试多个方案，选最好的）。
- **四种预设**：创意写作 / 日常平衡 / 精确生成代码 / 快速回复。
- **交互式回复**：AI 回复里可以嵌入按钮、卡片、选项等可交互组件，不只是干巴巴的文字。

## 🧩 工具市场与技能系统

- **内置工具免安装**：终端、文件系统、联网搜索、网页阅读、应用控制，开箱即用。
- **工具市场**：浏览社区工具市场，找到需要的工具一键安装；覆盖国内外 5 大工具源，分数据库、文件、AI、效率工具、媒体、通信、开发工具等 11 大分类；还能安装社区开发的插件来扩展功能。
- **技能可以理解为 AI 的工作流模板**：把一套复杂操作封装成一个技能，随时调用。
- **斜杠命令**：在编辑器里输入 `/` 就能快速触发技能或插入模板。
- **技能市场与自定义技能**：浏览官方技能库，一键安装需要的技能；也可以自己写技能，支持变量、参数、环境变量等高级配置。

## 📡 专业版：IM 网关、定时任务、自进化实验室

- **IM 即时通讯网关**：把 Notrat 的 AI 助手接入企业微信、飞书、个人微信、QQ 机器人，在手机上也能指挥 AI 干活。
- **多账号，各聊各的**：可以同时连接多个平台的多个账号；不同的聊天能绑定不同的智能体，各有各的人格和工具权限。
- **上下文记忆与任务通知**：跨消息保持对话上下文，不会聊一句忘一句；定时任务完成或失败时，通过聊天工具通知你。
- **定时任务**：像闹钟一样，设定好时间和任务，到点自动执行；三种任务类型（让 AI 做一件事 / 调用某个工具 / 运行一段脚本），支持手动触发与启用、禁用。
- **自进化实验室**：提示词自动优化（按你的使用习惯改进提示词）、方案对比（同时跑多个 AI 配置，看哪个效果更好）、行为分析（分析你平时怎么用，推荐更好的工具和操作方式），让 AI 自己变得越来越聪明。

## 🎨 版本、隐私与开箱体验

- **三种版本**：纯净版（只想安静写笔记，编辑器全部功能，没有 AI 和高级模块）、基础版（再加 AI 对话、智能体、工具市场、技能系统）、专业版（再加 IM 网关、定时任务、自进化实验室、HTTP Bridge）；随时切换，控制界面显示哪些功能。
- **账户**：支持第三方授权登录，不用记密码；在个人中心管理已登录的设备。
- **笔记存本地**：你的笔记以 `.md` 文件存在自己电脑上，不依赖云端，任何编辑器都能打开。
- **密钥与网络**：API Key 等敏感信息安全保存；AI 调用经过加密通道，不经手第三方；自动检测系统代理，代理不通时智能切换直连。
- **新手引导**：首次打开有 5 张插画带你了解核心功能，然后自动打开一个示例工作区；内置 4 篇笔记模板（项目说明、语法演示、快捷键速查、空白模板）。
- **场景化提示**：登录后、升级后、第一次进设置页，都会给出针对性的功能介绍；编辑器底部有个 `?` 按钮，随时查看所有快捷键。
- **外观与个性化**：亮色 / 暗色双模式，10+ 种预设配色，可自定义强调色；字体大小、行高、字体系列、内容宽度全部可调；中文 / English 自由切换；可最小化到系统托盘，后台常驻不占任务栏。
- **支持平台**：Windows（64 位 / 32 位 / ARM64，`.exe`）、macOS（Intel / Apple Silicon / 通用，`.dmg`）、Linux（x64 / ARM64 / ARM32，`.AppImage` / `.deb` / `.rpm` / `.tar.gz`）。
