# 1.2.0

发布日期：2026-08-15　·　[← 上一版](/changelog/v1.1.9)　·　[下一版 →](/changelog/v1.2.1)

**一句话总结：插件能铺到界面的 9 个位置，桌面上多了一颗随手可呼出的悬浮球，别的 AI 工具的插件和技能也能直接搬进 Notrat。**

---

## 🧩 插件：想放哪儿就放哪儿

- **9 个位置可选**：输入框上方、消息区顶部、右侧停靠栏、弹窗、悬浮窗、侧栏工具栏、活动栏、状态栏、悬浮器，插件面板都能落在其中。
- **关了能找回来**：每个面板和悬浮窗都有 ✕，关掉后位置会被记住；插件面板菜单里一键「恢复已关闭面板」，不用重装。
- **全局还是某个工作区**：插件可以只装给某个工作区，也可以全局通用，两边互不干扰；想换地方一键迁移，启用状态跟着走。
- **多个插件改同一个位置也不打架**：各自独立开关，不会互相牵连，也不会连累别的插件。
- **插件统一收进磁盘目录**：自动发现，安装、卸载立即生效；老版本装在浏览器存储里的插件会自动搬过去，不用重装。

## 🪐 桌面悬浮球：随时把 Notrat 叫出来

- 独立的透明置顶小窗，白色 logo 小球，点一下弹出竖排毛玻璃菜单（Notrat 常用操作 + 插件面板）。
- 可以自由拖到任意位置（自动夹在屏幕内），拖到屏幕边缘会自动半隐藏，不挡视线。
- **全局快捷键 Ctrl+Alt+F** 随时呼出或隐藏；托盘里也有「悬浮器」入口。
- 插件的悬浮器位置会出现在这个菜单里；主窗聊天完成、AI 触发时，小球会脉冲高亮提醒你。

## 🤖 兼容 dsh 插件格式，也读得懂别的 AI 工具的技能

- **导入 dsh 插件包**：插件面板里的「导入 dsh」支持选文件夹或填 GitHub 地址，包里的技能直接进 Notrat 可用，元数据会生成一个插件条目。
- **工具调用前后可以挂钩子**：插件能声明在工具调用前插手（可拦截）或调用后观察结果。
- **技能目录直接读**：Claude Code / Codex / OpenClaw 的技能目录会自动识别，开箱即用。
