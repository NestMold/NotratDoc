# 1.2.4

发布日期：2026-08-24　·　[← 上一版](/changelog/v1.2.3)　·　[下一版 →](/changelog/v1.2.5)

**一句话总结：编辑消息与切换分支这条链路整条修通；推理过程和文件卡片换了新样子；拖拽丝滑了；笔记知识库上线，AI 能直接查你的笔记。**

---

## 🌿 编辑消息、切换分支：这条链路终于通了

编辑消息后让 AI 重新回复，是这版修得最重的一条链路，五处相互纠缠的问题一起治了：

- **编辑后刷新，分支不再消失**：以前新分支会被编辑前的旧内容覆盖掉。
- **编辑会正经建分支**：以前内容被直接追加进主分支，看不到「编辑前」的那一版。
- **切换分支不再新老内容同屏**：切过去之后旧消息会被合并回新分支，两版内容混在一起。
- **不再重复消息、时间戳乱序**：编辑产生的新消息曾被当成全新消息再写一遍。
- **编辑保存不再没反应**：以前有概率点了保存却没生效。
- 恢复排序只在时间戳确实乱序时执行，不会打乱消息原有的追加顺序。

## 🖱 拖拽丝滑了，顺手修掉几处卡顿与崩溃

- **拖起来不卡了**：拖侧栏宽度、拖文件树与编辑器之间的分隔条，以前每动一下都要整页重算、明显掉帧；现在跟手。
- **修掉三处拖拽故障**：浏览网页（内置浏览器）时拖拽会冻结；拖完偶尔整个界面点不动；拖到窗口边缘会误中断。
- **手柄看得见**：拖拽手柄平时隐形，鼠标移上去显示一条灰色细线，拖拽中变成主题色。
- **文件树不再高频抖动**：AI 写文件或构建输出时，文件树被变更刷得一直闪；现在同类变更会合并后再刷新。
- **鼠标甩出窗口不再让文件树崩溃**：以前把鼠标移到窗口外有概率报错。
- **技能标签改成中文**：技能 / 智能体 / 工具标签中文化，匹配理由也从一段判定 JSON 变成人话；没有匹配的技能时整组隐藏，发一句「你好」不再挂一排空标签。
- **权限确认弹窗的一处崩溃修好**。

## 🎨 聊天气泡里的新样子：思考块、附件卡、文件图标

- **推理过程换成 DeepSeek 风格灰色块**：不再用卡片、时间轴层层堆砌，灰色背景块直接内嵌在消息里，没有多余标题行；点整块就能折叠或展开，折叠时显示字数，展开时内部滚动，不会把消息流撑爆。
- **模型自带的深度思考和 ReAct 推理合并显示**：一套界面统一呈现，不再分成两个地方。
- **生成中与生成后长得一样**：流式输出时的推理过程与历史消息用同一套渲染，不会「输出时一个样、结束后变个样」。
- **文件卡片重做**：一行一卡的竖排列表（多文件自动换行），32px 图标 + 文件名 + 大小与路径 + 右侧「查看文件 →」（悬停高亮）。
- **图标和文件树完全一致**：文件树那套图标体系现在与消息卡片共用，文件夹也从 emoji 换成同款蓝色图标。
- **图片文件直接显示缩略图**：粘贴进来的图片即使原路径失效，也能看到预览。
- **点卡片会聪明地打开**：`.md` / `.markdown` 直接在 Notrat 编辑器标签页里打开（自动切到编辑器），其它文件与文件夹走系统默认程序。
- **图片附件大图预览**：统一 160px 等高缩略图整齐排列，点击全屏放大（黑色遮罩，Esc 或点击关闭）；IM 消息里的图片同样支持。
- **输入区附件胶囊极简化**：从蓝紫渐变改成中性灰底细边框，删除按钮换成图标（悬停变红），图片加载时显示脉冲骨架。

## 🧬 自进化（专业版）：断掉的环全部接上

自进化「采集 → 挖掘 → 推荐 → 反馈 → 变异 → 注入」整条链路做过一次全面审计，这次把断掉的地方全部接好：

- **工具推荐不再永远是空的**：以前挖掘环节实际产不出任何模式，推荐一直在空转。
- **自动进化开关能真正打开了**：设置页里那个开关以前点了没反应。
- **变异由 AI 真实改写**：改写通道以前没接上，退化成了字符串拼接；现在和进化实验室共用同一条通道。
- **正常聊天就能自动建档**：以前「注入需要已有档案、建档只能靠实验室手动或 AI 反馈」互为前提，普通聊天永远不产生进化档案；现在首次遇到的助手会自动建立第一份档案，从下一次请求开始进入采样与归因。
- **反馈记得更准**：以前按提示词模糊归因，还会绕过 V2 直接记到 V1；现在按实际生效的变体精确记账，并同步到 V2。
- **工作区数据对齐**：MCP 工具以前永远读写全局那一份，与聊天写进工作区的数据是两套；现在跟着当前工作区走。
- **设置页的开关能存住了，推荐计数不再恒为 0**；没启用 V2 引擎时，进化实验室会回落 V1 视图，不再停在一个用不了的界面。

## 📚 笔记知识库（基础版及以上）

- **语义 + 关键词混合检索**：AI 对话里可以直接检索当前工作区的全部 markdown 笔记；也可以用 `/notes <查询>` 把匹配到的片段直接带进对话。
- **本地优先**：默认用本地模型（bge-small-zh）算向量，模型缓存在本机，数据不出电脑；也可以切到智谱 embedding-3 云端。用本地还是云端、什么时候下载模型都由你选。
- **按笔记结构分块、增量索引**：按标题层级分块，每块带上它所属的标题路径；保存、新建、删除都会被实时跟踪，只重建变化的部分。
- **自动注入上下文（专业版）**：每轮对话自动检索最相关的 3 段笔记带进上下文，支持排除某些目录。
