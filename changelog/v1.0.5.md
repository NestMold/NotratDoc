# 1.0.5

发布日期：2026-07-21　·　[← 上一版](/changelog/v1.0.4)　·　[下一版 →](/changelog/v1.0.6)

**一句话总结：编辑器里敲一个 `/` 就能插入标题、表格、代码块等常用元素，段落块可以直接拖着换位置；侧边栏几处「吞消息、串历史」的老毛病一并修掉。**

---

## ✨ 编辑器：敲 `/` 就能插入常用元素

- **快速插入**：在编辑器里输入 `/` 唤起命令菜单，标题、列表、代码块、表格、分割线、Mermaid 图表都能直接选，不用再去工具栏点。
- **边打边筛**：菜单自带搜索框，按名称、描述、关键词即时过滤，想找什么直接打出来。
- **子菜单也能用键盘走**：标题命令会展开 H1-H6 子菜单，`↑↓` 导航、`Enter` 选择、`←` 返回、`→` 展开，选中项高亮显示；鼠标移动全程没有死区，走位流畅。
- **跟着光标走位**：菜单按光标位置自适应，下方空间不够就翻到上方，水平方向不会超出窗口，内容多时菜单内部滚动，不再被边缘裁掉。
- **子菜单完整弹出**：子菜单浮在菜单右侧完整显示，右侧空间不够时自动翻到左边，不再被面板裁掉。
- **Esc 之后接着打字**：按 Esc 或执行完命令，菜单关闭且编辑器自动重新获得焦点，可以立刻继续输入或再敲一次 `/`。
- Slash 模式底部会显示一句提示：「想插入点什么？敲个 / 就行」。

## ✍️ 段落块可以拖着换位置

- **拖拽句柄**：段落、标题、表格等块级元素左侧会出现拖拽句柄，按住就能拖动重新排序。
- **浮动插入线**：拖动时有一条跟随的插入线指示落点，带平滑滑动与淡入淡出；插入线浮在最上层，不受层级和容器裁剪影响，段落、标题、表格下都能正常显示。
- **落点判断更准**：按拖拽句柄所在行的位置判断落点，段落、标题、表格都能准确插入。

## 💬 侧边栏对话：不再吞消息、不再串历史

- **读大文件的工具结果不再挤爆上下文**：工具一次返回超大结果（比如读取 50KB 文件）时，会把 token 预算吃光、最近几轮对话被挤掉。现在每个工具结果只保留开头 6000 与末尾 500 字符，中间插入截断标记，单次结果的 token 消耗从可能数万降到 2000 左右封顶，开头的摘要/输出与末尾的结果/错误都还在，对话历史也有了余量。
- **新对话不再显示旧历史**：修复新建对话后发消息，界面里却出现上一个会话内容的问题，消息不会再归错会话。
- **工具调用参数不再格式错乱**：修复非 Ollama 模型调用工具时参数格式错误、出现嵌套引号的问题。
- **大会话不再卡顿**：会话读写加了内存缓存，发一条消息不再反复读写存储，长会话的卡顿明显缓解。

## 🔧 其他修复

- **插件技能重新出现在选择器里**：技能来源补上了缺失的本地来源，插件带的技能现在能正常被列出。
- **工作区级与插件级技能能被正确定位**：列技能时会带上当前工作区，工作区级和插件级的技能都能被找到。
- **清空历史清得更干净**：清空对话历史现在会同时清掉存储文件与内存缓存，不再留下残存内容。
- **Slash 菜单不再「按 Esc 又弹回来」**：修复按 Esc 关闭菜单后它立刻重新弹出来的问题。
