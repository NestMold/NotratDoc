# 1.3.1

发布日期：2026-09-19　·　[← 上一版](/changelog/v1.3.0)　·　[下一版 →](/changelog/v1.3.2)

**一句话总结：初学引导整个重做——可跳过的欢迎页 + 一份会自动打勾的「新手任务」清单，教你找入口而不是把你空降进功能；编辑器能敲 `[[` 直接挑笔记、AI 写文件后预览与正文自动跟进，保存前还会拦下「把磁盘新内容盖掉」的操作；AI 补全升级为多候选 + 全文预览 + 可调思考深度；登录后弹三档功能对比、免费试用一键领。**

---

## 🎓 初学引导：从一个欢迎页 + 一份「新手任务」清单开始

- **欢迎页终于能跳过了**：原来的 5 页强制轮播（不能跳过）换成单页欢迎页，一句话讲清 Notrat 是什么 + 三条价值点，点「开始使用」或右上角 × 直接进主界面，不赶时间就「稍后再说」。
- **新增「新手任务」清单**：左下角一张 Linear 式卡片，带进度条，任务做完自动打勾——登录、领免费套餐、打开工作区、写第一篇笔记、配好 AI、开启补全、跟 AI 聊一句、逛逛插件市场、调一调设置。**只会显示你现在能做的任务**：免费用户不会看到完不成的 AI 项，还没配 AI 时先教你「配置 AI 服务商」。
- **「去完成」是教你走，不是替你走**：点「去完成」不再把你凭空空降到功能里，而是高亮左侧活动栏那个图标、让你自己点进去——你就记住了入口在哪、下次怎么找。高亮左侧图标时清单自动让到右边，不挡路。
- **关掉它，藏在右上角**：点 × 不再是「关不掉」，而是收成顶部窗口控制按钮旁一个「✨ 新手任务」小徽标（带进度 n/m），并提示你到哪能重新打开；从右上角、设置页、悬浮球菜单都能随时再打开。
- **做完之后入口移交**：全部完成后，「新手任务」入口自动挪到「设置」页和悬浮球菜单里；设置页还多了个「使用指南」——点开问你是「看文档」还是「继续新手任务」。
- **少打扰**：原来那 9 套会自动连环弹出的引导光斑全部删掉，只剩版本更新、升级成功这类一条小提示。

## 💬 多会话：切走就断，但会告诉你一声

- **切换 / 新建会话打断当前回复时，会弹提示**：以前是无声打断，现在明确告诉你「已中断上一条回复（切换对话）」。
- **幽灵重复消息清干净**：多会话并行下偶发「同一条回复显示两遍」的重复气泡已根除。
- **切回会话不再一片空白**：之前切回某会话偶发内容被清空，现在切回就能立刻看到内容。
- **多窗口打开同一工作区不再互相覆盖**：不同窗口的会话历史会合并，不再后来居上把整份历史盖掉。
- **多会话并行默认关闭**：这版先默认关掉并行（设置里可手动开），回到「一个会话一条路」的稳妥体验。

## ✨ AI 补全：多个候选随便选，还能调「思考深度」

- **候选多了，也能挑**：AI 补全现在会给出多个候选，↑↓ 上下选、Tab 接受；左边紧凑列表、右边全文预览框，长内容不再被一行截断看不到。
- **补全面板不再被裁掉**：光标贴近底部或边缘时，面板会自动翻到上方、收进屏幕内，不再出现「补全框看不到 / 只有一半」。
- **可调「思考深度」**：设置里从原来的低/中/高扩成「关闭 / 极低 / 低 / 中 / 高 / 极高」六档，关闭时更省用量、按模型默认来。
- **编辑器里一键开关 AI 补全**：工具栏「百宝箱」里多了个 AI 补全开关，不用进设置就能开/关。

## 🤖 子 Agent：实时看到它在干嘛

- **@ 内部专家不再「装死」**：以前 @ 一个内部专家，要等它整段跑完才一次性吐出来，过程一片黑；现在它的正文和每一步工具调用都实时流式显示，你能看到它正在查什么、调什么。

## 📊 用量统计：数字更真实

- **缓存命中不再算进「输入」**：之前「输入 Token」会偏大；现在缓存命中按便宜计价单独另计，总 Token = 新输入 + 输出，看得更清楚。

## 🧹 其他小修

- **最近工作区不再重复**：Windows 上同一个文件夹（`G:\…` 和 `G:/…`）之前会重复出现在最近列表，现已归并为一条。

## 🔐 登录更顺：验证码不再「抽风」

- **登录页不再偶发红屏**：验证码之前一进登录页就开始加载，网络一抖就会出错、把登录页打红；现在改成用到才加载，红屏噪声没了。
- **「获取验证码」不再报「未初始化」**：点太快时验证码还没加载好会报错，现在自动等它就绪。
- **验证码出错会说人话**：验证码加载失败现在会告诉你是哪一类问题（配置失效 / 域名 / 网络），不再只甩一句「初始化失败」。
- **打包版验证码缺失修复**：之前的安装包漏带了验证码所需的文件，导致登录页验证码显示不出来，现已补上。
- **不会「没登录却显示已登录」**：之前个别情况下实际没登录也会显示成已登录，现已修复。
- **一个窗口登出，其它窗口同步登出**。
- **领取免费套餐不再被要求重新登录**：之前领免费套餐时偶发被踢回登录页，现已修复。

## 🖥️ 终端：想要 Git Bash / WSL 也能跑

- **终端 Shell 可选**：设置 → 终端里可以选 auto / Git Bash / WSL / PowerShell，AI 执行命令不再死绑 PowerShell；auto 会自动按命令特征挑合适的 shell。
- **WSL / Git Bash 路径不再错乱**：AI 在 WSL / Git Bash 里拿到的工作目录会正确转回 Windows 路径，下一次 cd 不再失败。
- **中文 Windows 不再乱码**：终端输出 GBK 乱码已修。
- **AI 能在你打开的面板里跑命令**：新增「在面板执行」能力，交互式 / 长命令你能在旁边看着跑。
- **终端「建议命令」**：设置里开启后，终端面板顶部会给出命令输入框 + 实时建议（Tab 确认）。

## 🎁 登录后：三档功能对比 + 免费试用一键领

- **登录后弹「免费试用对比」弹窗**：三档功能一目了然，一键领取免费试用。
- **免费套餐空着时，个人中心会提醒你领取免费活动**。
- **封号、删号、踢设备分清提示**：账号被封、被删、还是只是设备被踢下线，现在提示得明明白白。

## 🖼️ 编辑器：粘图片不再裂图

- 粘贴 / 拖入图片现在固定存到工作区相对路径，之前部分环境（如中文工作区目录、盘符写法差异）会存成绝对路径导致图片裂掉的问题已修复。

## 🔗 编辑器：敲 `[[` 就能挑笔记

- **输入 `[[` 直接选笔记**：光标下方会列出工作区里的笔记，接着打字就筛选，↑↓ 选、回车插入。插入的是标准 `[[笔记名]]`——点一下能跳到那篇笔记，对方笔记的「反向链接」里也会出现你这条。
- **列表里能看到「被引用次数」**（↩N）；同名的笔记会自动用路径区分，帮你选对那一篇。
- **和聊天里的 `@` 文件选择器是同一套手感**：同一套面板样式、同一套模糊匹配。

## 📋 聊天：代码块一键复制

- 回复里的代码块右上角多了「复制」，点一下变「已复制 ✓」。

## 🛡 不会再「把磁盘上的新内容盖掉」

- **保存前会先看一眼磁盘**：如果文件在你打开之后被 AI 或别的编辑器改过，保存会被拦下并提示——不会再拿编辑器里的旧内容把新内容覆盖掉。提示条给两条路：**重新加载**（看磁盘上的新版本）或**覆盖保存**（以你编辑器里的为准，只在你有未保存改动时出现）。
- **HTML 预览跟着文件自动刷新**：文件一改，预览一秒内自己更新，不用再手动点重新加载——不管改动来自 AI、别的编辑器还是构建脚本。

## 🔗 双击 .md 就用 Notrat 打开

- **装完首次启动会自动帮你设好**：安装时那个「将 Notrat 设为 .md 默认打开方式」（默认勾选）之前断在最后一步——没弹确认窗，所以看起来"装完什么都没发生"。现在会弹一次系统的「打开方式」，选 Notrat 并勾「始终使用」即可（Windows 不允许程序自己抢默认值，必须你点这一下）。
- **`.md` 文件用回专属图标**：以前系统里会出现两个都叫 Notrat 的候选、图标还各不相同；就算你选了 Notrat，文件图标也是应用的通用图标。现在统一成一个候选 + 专用的 `.md` 图标。
- **Mac 和 Linux 也能设成默认了**：Mac 会帮你在访达里定位 Notrat.app，按提示「显示简介 → 打开方式 → 全部更改」；Linux 点一下「设为默认」即时生效。
- **双击 .md 会问你「怎么打开」**：以前只有已经开着工作区时才问；没启动 Notrat 时双击 .md 是直接按单文件打开、什么选择都没有。现在一律问你：**单文件打开 / 用它的文件夹作为工作区打开 / 在新窗口打开**。
- **.md 图标不会再变成应用 logo**：旧版本留下的条目没清干净，系统会回退到它、把文件图标显示成应用图标；现已一并清掉。

## 🧩 修复：打包后没登录过的人，验证码一直是「初始化超时」

- **现在**：打包安装的版本里，验证码能正常加载，不再卡 25 秒报「初始化超时」；验证码所需的资源也随安装包一起提供，少一次对外部网络的依赖。

## 🐛 这一版修好的

- **会员不再被误判成免费版**——不再莫名弹出「AI 对话是 Basic 及以上功能」。
- **长对话不再被工具调用配错误中断**（Claude / Claude Code 渠道尤其明显）。
- **编辑器偶发崩溃**（提示「The editor view is not available」）已修。
- **模型选择重启后不再自己跳回第一个**（Claude Code / Codex 这类自动导入的服务商尤其明显）。
- **领取免费套餐后个人中心不再显示「未领取」**，也不会再频繁刷新。
- **欢迎页 → 领取弹窗 → 新手教程不再打架**：先看欢迎页，领完再进教程；跳过的教程随时能从「设置 → 使用指南」找回。
