# 1.0.1

发布日期：2026-07-16　·　[← 上一版](/changelog/v1.0.0)　·　[下一版 →](/changelog/v1.0.2)

**一句话总结：一次把聊天从头捋顺的修复版：消息不再闪没、回复不再残缺、长会话不再卡，子代理和后台命令也都听话了。**

---

## ⚡ 聊天更快、更稳

- **输入与滚动不卡了**：输入框加了防抖，不再每敲一个字就重算整棵界面；消息列表虚拟化，长会话滚动更顺；消息分组里重复的计算也去掉了。
- **长对话不再把 CPU 打满**：重叠发送时会同步取消重复的技能预检请求；历史压缩结果做了短时缓存，不再并发重复摘要。
- **标题栏不再闪**：顶栏的会话标题不再跟着流式输出的每一个字重绘。
- **消息不再「闪一下又没了」**：修复发送瞬间用户消息一闪即逝、AI 输出过程中发新消息导致内容被吞、停止后消息丢失、长列表流式结束前新内容被隐藏这一串问题。
- **不再无限重试**：部分失败场景下 AI 请求陷入无限自动重试的问题已修复。
- **文件路径点了就开**：AI 回复里的文件路径（绝对路径或相对路径）点击直接在编辑器打开，不再刷新整个应用。
- **上下文估算更准**：估算时计入工具调用结果、附件与图片；超长的工具输出会被裁剪；压缩阈值也提高以适配现代模型的上下文窗口，缓解「exceeds context window」报错。

## 💬 回复不再残缺

- **新工作区的第一条回复**：修复只显示思维链、正文不输出的问题。
- **多步任务**：修复回复正文中途消失、只剩工具调用、跑完才整套出现的问题。
- **流式中断保留内容**：中途出错或手动中断时，已经输出的部分会留在对话里，不再整段清空；ESC 与停止按钮能真正中止上游请求，停止后消息的位置也对了。
- **少一些「空回复」误报**：能识别非标准的回复内容格式了。
- **历史会话**：修复重启后聊天记录消失、旧会话消息顺序错乱、自动保存失效等问题。
- **表格不再被压成纯文本**：AI 回复里的 HTML 表格会按 Markdown 表格渲染。

## ⌨️ 输入、参数与展示

- **GOAL 模式**：`/goal 目标内容` 现在会开启 GOAL 并立刻把目标发给 AI；只输入 `/goal` 时仍是开关切换。
- **输入框**：支持右键菜单与撤销、重做快捷键。
- **推理参数**：工具栏新增推理等级选择（o 系列模型），并修复选择器按钮崩溃；Max Tokens 改为数字输入加预设按钮，支持自动降级重试，输出上限提升。
- **工具调用看得见**：运行中就显示参数；文件类工具支持查看文件与 Diff。
- **沉浸式界面**：修复沉浸式模式下头像显示异常。
- **状态栏**：显示真实的应用版本号。

## 🤖 智能体、子代理与连接器

- **子代理监控**：侧边栏新增子代理监控卡片，可看实时状态与详情；任务流与子代理监控合并为底部的标签面板。
- **AI 可以临时建角色**：新增「创建代理」能力（专业版），临时自定义的角色能正常运行，不再误报找不到；子代理创建类工具按专业版订阅权限开放。
- **后台跑的帮手会把结果交回来**：修复后台启动的子代理结果没有自动注入主对话的问题。
- **界面组件只由主代理产出**：子代理不再输出可交互的界面组件，统一由主代理负责，界面元素不再打架。
- **不再误报「未启用 / 不可用」**：提示词里明确了创建类工具在专业版下可用，工具运行中的文案也做了澄清，减少模型误读。
- **连接器（MCP）**：启动时默认选中全部已启用的服务器；移除内置的 web-search，改走其它搜索能力。
- **应用控制**：让 AI 打开工作区的工具现在能真正切换工作区。

## 🖥 终端、多窗口与其它

- **后台命令**：`go run` / `npm run dev` / `python -m http.server` 这类服务器或常驻命令改为后台执行，不再阻塞 AI 5 分钟；补充识别 uni-app 等更多开发服务器命令。
- **多窗口**：新窗口能打开正确的工作区；侧边栏的显示状态按窗口独立。
- **应用内打开网址**：支持用应用内标签打开 URL；修复了内嵌浏览视图导致的崩溃。
- **编辑器与文件树**：增强右键菜单与表格编辑操作；修复文件树折叠后重新展开异常、删除时滚动跳动等问题。
- **PDF 预览**：修复 PDF 渲染组件加载不到的问题。
- **网络**：优先走系统代理，代理不可达时自动回落直连。
- **账号安全**：登录后立即心跳，被踢下线时能及时发现；关闭了一个可以绕过订阅层级校验的漏洞。
- **用户中心与引导**：IM 网关的渠道 Logo 裁切为正方形；社区区展示真实的微信、QQ 品牌 Logo，补充加入社群卡片与头像回退；修正升级、版本导览的高亮区域与工作区导览的焦点、队列问题。
