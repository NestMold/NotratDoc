# 1.0.3

发布日期：2026-07-18　·　[← 上一版](/changelog/v1.0.2)　·　[下一版 →](/changelog/v1.0.4)

**一句话总结：这一版几乎都在编辑器里：回车就换行、链接有对话框、括号自动补全、代码块一键插入，登录掉线和档位模式也理顺了。**

---

## ✍️ 写 Markdown 更顺手

- **单个回车就是换行**：回车即渲染成可见的换行（Typora 风格），编辑器里看到的和预览一致，不再被合并成一行。
- **`Ctrl+K` 换成链接对话框**：可以填网址和显示文字，也能编辑或移除已有链接，不再是浏览器自带的那种输入框；工具栏的链接按钮和右键菜单用的是同一个对话框。
- **链接快速插入**（设置 → 编辑器，默认关闭，适合老手）：开启后 `Ctrl+K` 不再弹窗，直接插入 `[名称](链接)` 模板。有选中文字就把它包起来，光标落在 `()` 里；没有选中就插入 `[光标]()`，输完名称按 `Tab` 跳到 `()` 填网址。对话框底部也有勾选框，可以一键开启这种模式并说明怎么关掉。
- **自动转链接**：手动输入或用快速模式补全 `[名称](网址)` 后，会自动变成可点击的链接（图片语法 `![]()` 不受影响）。
- **括号自动补全**：输入 `[` 或 `(` 会自动补上 `]` 或 `)`，光标停在中间；选中文字后按括号可以直接包裹；已经有了闭合括号时会跳过而不是重复；一对空括号里退格一次删掉两个；代码块内不触发，保留字面括号。
- **代码块一键插入**：`Ctrl+Shift+K` 直接插入空代码块（Typora 风格），不再弹语言输入框。

## 🛠 工具栏与快捷键

- **图标不再撞脸**：底部工具栏的「链接 / 文件引用」不再共用同一个图标（文件引用改为回形针），「文件嵌入 / 代码块」也不再共用（文件嵌入改为文档图标）。
- **一排线性图标**：底部工具栏的「文件图片 / Mermaid / PlantUML / HTML」按钮由彩色图标换成与其余按钮一致的单色线性图标；顺带修好「文件图片」按钮上的文件夹图标跑到底部、看起来像状态栏里多出一个图标的问题。
- **源码 / 富文本切换不再卡死**：修复 `Ctrl+/` 偶发失效的问题，切换后再也不会一直卡住。
- **列表缩进不再报错**：修复列表里按 `Tab` / `Shift+Tab` 缩进时弹出的运行时报错。

## 🔐 登录与会话

- **掉线会跳登录页**：登录过期、设备被踢下线（超出设备数或被移除）这类会话真正失效的情况，会自动跳到登录页提示重新登录，不再静默退回编辑器变成游客；本机把旧设备顶下线等仍在线的场景只提示、不跳转。
- **登录状态保持得住**：访问令牌临期自动续期，刷新令牌加密保存在系统密钥库里，重启应用仍是登录状态；网络抖动也不会把你登出。

## 🧭 模式与等级联动

- **界面模式跟着等级走**：登录或等级变化时，纯净版 / 基础版 / 专业版优先采用你自己的选择；拥有该档位就用你选的，没有就回退到账号权限对应的最高档。
- **个人偏好会记住**：手动切换过的模式本次会话内保持，之后升级时也会自动恢复到你原来选的模式。

## 🎁 个人中心

- **套餐功能排版更紧凑**：已含功能从一行一个改为横向流式排列，一屏能看到更多，不再被换行挤到看不见。
- **头像上的活动角标**：有可领取的活动（免费体验 / 返现）时，活动栏头像右上角显示红点与数量，下拉菜单里的「个人中心」旁也有同步提示；领取后即时消失。
- **顶部提醒横幅**：有待领取的活动时引导「立即领取」并滚动定位到活动卡片；免费用户会看到升级基础版 / 专业版的提示（有折扣时显示「查看折扣」）；付费且没有待办活动时不打扰。
- **订阅卡头部精简**：「余额充值」提为主按钮更醒目，去掉了与左栏重复的版本号文字，操作区不再换行拥挤。
