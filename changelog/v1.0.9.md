# 1.0.9

发布日期：2026-07-30　·　[← 上一版](/changelog/v1.0.8)　·　[下一版 →](/changelog/v1.1.0)

**一句话总结：自进化引擎整体重构成完整的遗传算法系统，并给出新手 / 平衡 / 专家三种模式；新增 DIY 组件定制，AI 能通过对话直接改造界面并打包分享；AI 服务商支持 `notrat://` 链接一键导入；对话上下文、流式回复和一批崩溃问题集中修复。**

---

## 🧬 自进化引擎 V2（全新架构）

- **真正的分代进化**：世代之间清晰隔离，每一代都有独立统计（平均适应度、多样性、收敛率），变体之间有明确的血缘关系，能看出完整的进化谱系。
- **多维适应度评估**：从单一成功率升级为四维评分：性能（成功率、响应时间、token 效率）、可靠性（错误率、稳定性）、用户满意度（采纳 / 修改 / 拒绝反馈）、效率（质量与 token 的比值）。提供 balanced / performance / reliability / user_centric 四种策略。
- **丰富的遗传操作**：
  - **变异**：7 种策略（点变异、插入、删除、替换、放大、重组、LLM 重写）
  - **交叉**：4 种策略（单点、两点、均匀、语义融合）
  - **杂交**：多父本 LLM 融合（专家模式）
  - **回溯**：回到祖先版本（专家模式）
- **智能种群管理**：
  - 精英保留：自动保护高适应度的变体
  - 多样性保护：生态位隔离、拥挤距离、相似度检测
  - 智能淘汰：按适应度、年龄、拥挤度淘汰劣质变体
  - 种群规模控制：10 到 50 个变体（视模式而定）
- **三种体验模式**：
  - **新手模式**：保守变异率（10%）、需要你确认、显示解释、排名选择、用户满意度优先
  - **平衡模式**：自动进化、适度探索、Thompson 采样、多指标平衡
  - **专家模式**：激进优化（变异 30% + 交叉 40%）、锦标赛选择、性能优先、启用杂交与回溯
- **基因系统**：把提示词解析成结构化基因片段（instruction / constraint / example / context），每个片段带重要性权重，交叉时会保护重要片段。
- **选择算法多样化**：锦标赛选择、轮盘赌选择、排名选择、精英保留、Thompson 采样，不同模式用不同的选择压力。
- **新旧并存，可随时升级**：老的 V1 架构继续可用，新工作区默认启用 V2，并提供「升级到 V2」的迁移入口。

## 🎨 DIY 组件定制系统（全新）

让 AI 通过对话直接改造 Notrat 的界面，所有改动都在应用内运行时生效，不碰源代码，打包出去的应用同样可用。

- **两种覆盖方式**：
  - **整组件覆盖**：把整个组件的代码换掉并即时生效，覆盖范围包含界面里的约 200 个组件，适合逻辑级的改造
  - **Slot 覆盖**：按样式 / 属性 / 行为 / 内容四类做运行时注入，立即生效、无需刷新，适合样式与局部调整
- **DIY 面板（设置 → DIY 定制，所有用户可用）**：
  - 「组件覆盖」：挑选组件（带中英文说明与所在位置）、对照编辑代码、查看当前生效的覆盖列表、单个移除
  - 「Slot 覆盖」：可视化新增与删除覆盖，AI 设置的覆盖实时可见；内置链路诊断区（接收日志 + 各环节状态灯 + 一键测试），不用打开开发者工具也能排查
  - 「插件包」：把当前的 DIY 覆盖一键导出为 `.notrat-plugin.json` 分享到别的设备；装上后可以按插件逐个启用、禁用、卸载，插件里声明的 MCP 服务开机自动重启
- **AI 也能直接改**：设置样式、属性、行为、内容以及一键清除这些能力，已经同时开放给内置 AI 和外部 Agent 框架（Claude Desktop 等）使用；工具说明里内置了使用规范（不要带 `!important`、用 HSL 变量格式、注意继承等）。
- **安全边界**：默认放行所有组件，只拦截认证、权限、订阅等级、强制更新这几类模块（防止有人靠覆盖绕过付费）；编辑器与输入区域的 `pointer-events`、`user-select`、`caret-color` 等危险属性会被硬拦截。
- **不用再猜位置**：编辑器、侧边栏、文件树等常用区域都提供了稳定的定位标识，AI 定制时不必再用通配符碰运气。

## 🤖 AI 服务商：一键导入与设置排版

- **`notrat://` 一键导入**：第三方站点可以生成一条 `notrat://import-ai?type=&name=&baseUrl=&apiKey=&model=&models=` 链接，点一下就会拉起 Notrat 并弹出确认弹窗，里面列清服务商名、协议类型、接口地址、模型列表和打码后的 API Key，你确认后才写入配置，不确认绝不落盘。应用没开着、正开着、以及从 macOS 浏览器点开三种情况都能弹窗；检测到同名或同地址的配置时会提示「覆盖导入」。设置页也提供了「导入」按钮，可以直接粘贴链接或 JSON。
- **设置排版重做**：OpenAI 与 Anthropic 提升为全宽大行卡片，「自定义兼容」跨两行放在右侧，其余 24 个厂商收进「其他厂商快速添加」网格；窄屏自动退化为单列。
- **自定义服务商可切换协议**：不再锁死 OpenAI 格式，表单里可以切到 Anthropic 协议（NewAPI、OneAPI 这类 Anthropic 格式的中转站可以直接接入），Anthropic 协议单独成条，不会覆盖官方条目；高级选项默认展开。
- **长对话默认保留最近 8 条原文**：上下文压缩的默认策略从「只保留摘要」改成「摘要 + 保留最近 8 条原消息」，早期历史由 LLM 压缩成摘要、最近几轮保持原文，AI 不会因为摘要损耗而忘掉刚聊过的内容。
- **Claude 模型列表更新**：新增 Claude Opus 4.8（旗舰）、Sonnet 5（均衡）、Haiku 4.5（快速），清理了编造与已退役的旧模型 ID，已有配置会自动迁移到新 ID。

## 🛠 回复与上下文不再出错

- **上下文顺序修正**：编辑器内容、工作区、当前文件、可用工具这些上下文此前会被排在你这条消息之后，部分 OpenAI 兼容网关会报错或直接忽略。现在它们统一排在你的消息之前；正常发送、分支重新生成、继续这三条路径都改了。
- **Anthropic 渠道不再丢上下文**：修复只取到第一条上下文、后面的编辑器内容 / 工作区 / 当前文件 / 工具信息被静默丢掉的问题。
- **历史里的错误占位不再干扰回答**：网络失败时写入会话的「⚠ Error」占位回复、重发产生的相邻重复消息，发送前会自动过滤（界面上仍然保留），AI 不会再误以为「之前的回答全是一堆错误」而给出混乱的对账式总结。
- **裁剪上下文不再切断工具调用链**：一条工具调用和它的结果会作为一个整体保留或丢弃，不再切一半导致 OpenAI 接口报 400；裁剪后还会插入省略说明，模型会如实告诉你「更早的内容已被截断」，不再编造。
- **回复到一半关窗不再丢消息**：流式回复期间关闭窗口、切换工作区或切换会话，已经输出的部分会自动落盘（标记为已中断），重新打开还能看到；主动停止这条路径上有一处从未真正保存的回复也一并修好了。
- **回复结束后状态不再卡住**：服务端或代理漏发结束事件时，读流会永久挂起，加载状态不复位、「正在整理最终回答」和停止图标一直显示。现在等待 120 秒没有新内容就按正常结束收尾，已经收到的内容完整保留。
- **流式各环节都有超时兜底**：连接阶段 30 秒超时，读流 120 秒没有进展就中止，工具执行 60 秒超时，上游模型侧 120 秒没有数据就中止（此前可能一直挂到 1 小时）；发送流程另加看门狗，流内最多 15 分钟、收尾最多 30 秒，到点强制恢复状态并保留已生成的内容。
## 🧯 崩溃与显示问题修复

- **带工具卡片的回复不再把对话打白**：对话里出现工具调用卡片时，整个对话区可能出错变白，表现为回复完之后什么都不显示。现在正常显示。
- **Agent 执行记录卡片不再报错**：Agent 卡片里会显示执行记录时间线，这一块此前一渲染就报错，现在补上了，执行过程可以正常查看。
- **插入图片不再报错**：编辑器的 `Ctrl+Shift+I` 图片按钮和工具栏图片按钮此前会直接抛错，现在正常打开插入图片对话框；`Ctrl+Alt+I` 会打开本地文件选择器。
- **会话重命名改成就地编辑**：原来的重命名弹窗在应用里必崩，现在改成列表内直接改，回车保存、Esc 取消。
- **AI 改完文件，编辑器立刻刷新**：新建、删除、重命名文件的变更通知补齐了，路径写法（正斜杠 / 反斜杠、大小写）也做了归一，不再出现 AI 已经写完而界面还是旧内容的情况。
- **清除 DIY 覆盖后编辑器恢复输入**：清除覆盖样式后，不再留下一个被改坏、打不了字的编辑器。
- **活动领取不再报 invalid token**：活动相关请求改为带自动刷新的鉴权，登录凭证过期或轮换后会自动重试一次，不再直接失败。
- **技能图标不再裂图**：技能卡片里的图标此前会被图片防盗链拦成裂图，现在正常显示。
- **网关平台图标不再发灰**：网关「平台连接」（顶栏与仪表盘两处都有）里 Telegram / WhatsApp / Discord 三个图标在未连接时近乎透明、看不出品牌。现在这三个图标用各自的品牌色显示，连接状态改用透明度与绿点表达；微信、企业微信、QQ、飞书、钉钉、Slack 本就自带品牌色，不受影响。
- **会话标题不再跳回「新对话」**：已经生成好的会话标题偶尔会被写回默认名、来回横跳，现在已生成的标题会被保护住。

## 🎁 活动角落提醒与官方推荐技能（全新）

- **活动角落提醒**：有新活动或可领取的福利时，右下角弹出非模态提醒卡片，不打断你手上的工作。未登录时提示「登录领取」，并直通登录后的活动高亮引导；已登录时多条活动合并成一张卡片，可领取的（免费体验、返现）能直接在卡片上领，不用跳转。弹出节奏也不打扰：新活动立即提醒、首次必提醒，之后每天最多一次；单个活动可以「不再提醒」。官网首页同步新增「活动与福利」区域，不登录也能看到。
- **官方推荐技能**：第一次用 AI 或进入技能市场时（先到先弹，只弹一次），会弹出官方推荐技能，支持单个或全部一键安装，不需要事先配好命令行环境；技能市场里也新增了「⭐ 官方推荐」区块。已经装过的技能会自动过滤，不会再推荐一遍。
- **弹窗看得更清楚了**：角落提醒、推荐技能、服务商导入、全局确认框统一换成深色可见边框加不透明卡片与强投影，不再和背景糊在一起；这些弹窗也都能通过 DIY 面板或 AI 精确定制。
