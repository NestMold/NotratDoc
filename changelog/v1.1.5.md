# 1.1.5

发布日期：2026-08-09　·　[← 上一版](/changelog/v1.1.4)　·　[下一版 →](/changelog/v1.1.6)

**一句话总结：在编辑器下方就能开一个真终端敲命令、跑脚本，AI 还能帮你解释输出；顺带修好了一批回复中途消失、GOAL 模式停不下来的老毛病。**

---

## 💻 内置交互式终端（全新）

不用切窗口，在编辑器下方直接开终端干活：

- **左侧工具栏一键打开**：工具栏新增「终端」入口，面板出现在文件树与侧边栏之间，顶部拖拽条能自由调整高度。
- **完整交互体验**：基于系统真实 Shell（Git Bash / PowerShell / WSL / bash），vim、htop、Python REPL 等交互程序都能正常用，并自动跟随当前工作区目录。
- **右键菜单**：复制 / 粘贴 / 全选一应俱全。
- **常用命令快捷条**：ls、git status、npm run dev 等一键执行。
- **命令建议**（设置中开启）：输入时按常用命令与最近历史给出补全，`Tab` 确认预选、`Enter` 直接执行。
- **AI 解释输出**（付费版）：一键让 AI 解读终端最近输出，遇到报错直接给出原因与修复建议。
- **AI 驱动终端**：AI 助手可直接在你的终端面板里执行命令，结果实时可见。
- **回车更可靠**：修复了 Git Bash 下按回车偶发不执行的问题。

## 🌊 流式回复更稳

- **回复不再中途消失**：修复了侧边栏里 AI 回复输出到一半突然消失、看似结束实则仍在输出的问题。
- **滚动跟随更聪明**：在底部时回复自动跟随输出滚动；你上翻查看历史时不打扰；滚回底部自动恢复跟随；发送新消息时立即跟到底部。

## 🎯 GOAL 模式修复

- **手动停止立即生效**：修复了 GOAL 模式点了停止仍自动续跑的问题，随时可控。
- **与对话压缩不再打架**：AI 正在回复时触发压缩会明确提示，不再产生状态错乱。

## 🎨 沉浸式模式界面焕新

- 去掉大面积玻璃模糊与渐变叠加，界面更干净、层级更清晰。
- 标题、状态条、模式标签等字号整体上调，长时间使用更耐看。

## ⚡ 体验改进

- **文档里的链接点击即开**：http/https/邮箱链接点击直接在浏览器打开，不用手抄。
- **CSV 划词引用**：CSV 表格里选中一段内容，可直接引用到对话。
- **文件树多选复制**：多选文件后 `Ctrl+C` 正确同步到系统剪贴板（此前只有单选生效）。
- **右键菜单对齐**：图标与文字基线对齐，不再歪歪扭扭。
