# 1.2.9

发布日期：2026-09-05　·　[← 上一版](/changelog/v1.2.8)　·　[下一版 →](/changelog/v1.3.0)

**一句话总结：主页聊天会自动认门——聊什么就归到哪个工作区；新工作区第一条消息不再冒出奇怪 JSON；压缩摘要不再半截断；行内公式不再重复；划词引用的按钮终于跟着手走。**

---

## 🏠 主页聊天：聊到哪个工作区，就归到哪个工作区

- **发送时自动认门**：在主页（未打开工作区）发消息时，Notrat 会判断这条内容属于哪个项目——文本里提到某工作区的路径，或与该项目近期聊过的话题高度相似，就自动把对话放进那个工作区开始；两个判断都不达标就留在主页，**宁可不动，绝不猜错**。
- **打开工作区不再「顺走」主页聊天**：之前打开任意工作区，主页当前会话会被悄悄复制一份进去，导致同一段对话「自己跑」到别的工作区。现在各回各家，打开工作区不再带入任何会话。
- **主页会话列表汇总所有对话**：主页现在聚合全局 + 各工作区的历史会话；此前被复制产生的重复对话按同一条去重，一段对话只显示一条。
- **输入框两个顺手的小改进**：按 ↑/↓ 可翻找历史输入（和侧栏共用一份记录，两边互相可见）；窗口太矮时输入框也不再被挤出屏幕。

## 🧬 新工作区第一条消息，不再变成 JSON

之前新建工作区后发的第一条消息，AI 有时会直接回一串看不懂的 JSON（形如 `{"primarySkill":"","matchedSkills":[]...}`）——这是内部「提示词进化」机制误把技能路由的内部提示词当成了你的对话提示词。已修复：**只有你真正的对话参与提示词进化**，所有内部辅助调用（技能路由、记忆压缩、行内补全、连接测试等）一律不再掺和，互相之间也不会串味。

## 🛡️ 修复「主页只发一句『你好』，却被切进工作区、消息还消失」

之前从主页发消息时偶发一连串怪事：AI 突然替你切换了工作区、回复跑进了旧会话、正在打字的内容直接从屏幕上消失。根源是发送瞬间新旧会话的数据「串台」。现在：

- 消息永远发进你真正所在的会话，不会复活旧对话；
- AI 中途确实需要切工作区时，整个对话会跟着一起搬过去，**流式内容不再中途消失**；
- 其他窗口/面板的操作不再会「误杀」正在进行的回复。

## 🗜️ 长对话压缩，三处更可靠

- **摘要不再半句截断**：压缩摘要之前固定 1024 token 上限，长摘要经常写到一半断掉且毫无报错。现在按模型上下文动态放宽；已经截断过的旧摘要可以用 `/compress` 重新生成。
- **不再吞掉 AI 的最终回答**：压缩时最后一条纯文本回答（往往正是结论）此前会被一起压掉，现在完整保留。
- **摘要卡白屏修复**：点开压缩摘要整页白屏的问题已修复。

## 📂 文件夹和公式的小毛病

- **展开文件夹就能看到最新内容**：AI 改过某个文件夹后，第一次展开就是新的，不用再「收起再展开」刷新。
- **行内公式不再复制成好几份**：`$…$` 公式出现在句子中间时被复制多份的问题已修复，编辑器和阅读视图同步生效。

## 🖊️ 划词引用：按钮跟着手走

- 「💬 引用到聊天」按钮现在出现在**你松开鼠标的位置**（不再固定在选词开头）；跨页拖选也不会再飞出屏幕看不见。
- 划词后滚动页面、缩放窗口，按钮会实时贴着选区走；选区滚出视野按钮自动隐藏，滚回来再出现。

## 🔌 其他稳定性

- **发送中的回复不再被「静默取消」**：各种内部状态变化不再误杀在途回复；工具万一被取消，日志会记下具体原因（用户中止 / 过期请求 / 会话切换），排查不再靠猜。
- **打开/关闭工作区说到做到**：AI 调用打开/关闭工作区时，会真正等界面确认后再汇报结果；没切换成功会如实告诉 AI，而不是嘴上说成功。
- **新工作区默认进化引擎 V2**：新建的工作区直接用上 V2 引擎；存量 V1 工作区不受影响，仍可在进化实验室一键迁移。

## 📦 Linux 用户

- 修复 protected 构建的 Linux 包漏注入 AI 提示词的问题。
- FAQ 新增 Linux 启动排障：新版系统沙箱导致启动即崩的临时解法、Fedora 缺依赖一键补齐、AppImage 缺 FUSE2 的运行方法。
